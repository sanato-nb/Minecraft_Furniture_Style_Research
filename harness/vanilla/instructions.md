# Vanilla Harness — 전용 규칙

1. Minecraft 공식 버전별로 원본 JAR/클라이언트·자산·SHA를 구분한다.
2. 새 버전은 신규·수정·삭제 자산과 부모/상태/렌더 코드의 영향 범위를 비교한다.
3. 원본 JSON이 같더라도 엔진 동작 변경 가능성을 독립적인 런타임 검사 항목으로 분류한다.
4. 재검증은 기존 결과를 재검사하고, FRESH는 기존 연구 결론을 분석 입력으로 쓰지 않는다.
5. 특수 렌더 및 실제 배치 검사는 정적 JSON 검증과 별도 기록한다.
6. 기존 `research/vanilla_models/`, `research/vanilla_textures/` 원본·고정 경로는 이관 검증 전까지 변경하지 않는다.
