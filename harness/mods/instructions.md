# Mods Harness — 전용 규칙

1. 모드 식별자·배포처·모드 버전·Minecraft 버전·로더·의존성·원본 SHA를 고정한다.
2. 파일 이름으로 가구 정체를 확정하지 않고 모델·상태·텍스처·런타임 증거로 판정한다.
3. 일반 JSON을 공통 분석하고 동적 렌더/비표준 모델은 별도 어댑터나 보류로 처리한다.
4. 버전 변경시 부모·텍스처·상태·코드 의존 자산을 포함해 영향 범위를 검사한다.
5. 교차 비교는 동일한 단위와 분모를 사용하고 반례·범위 제한을 함께 기록한다.
6. 원저자 재배포 제한 파일은 공개 inbox/연구 폴더에 넣지 않는다.
7. 기존 `research/furniture_mods/` 역사적 연구 원본은 이관 검증 전까지 변경하지 않는다.

런타임 검증의 첫 단계로 `runtime-plan`을 사용해 기존 1-3-D 엔진 검사 경로와 실행 인자를 확인한다. Minecraft 1.21.1과 1.21.11의 고정 모드 조합에서 블록 등록 상태, 상태 규칙 일치, 충돌 상자를 검사하는 도구다. 적용 가능한 모드·버전, Java 21과 Xvfb 실행 조건은 [기존 런타임 안내](../../research/furniture_mods/phase_1-3/runtime_actions/README.md)에 있다. 계획 출력과 게임 실행 결과는 별도로 기록한다. 스크린샷 캡처는 후속 단계다.
