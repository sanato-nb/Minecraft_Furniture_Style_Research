## 첫 회차 A 및 B·C 검증 표본

v24 의자 목록의 신규 19개와 선행 대조 5개를 분리한다. 신규 원본 PNG를 고정 Git 커밋에서 읽고 인계 SHA와 대조한 다음 전체 화소를 측정한다. 해당 39개 의자 leaf에서 이 PNG들을 바인딩한 정적 면을 찾고, 모델·기하 제공자·방향·요소·UV 증거를 원장으로 남긴다. 원본 모델을 다시 열어 면과 대조하고, 면의 UV 영역에서 화소 수, 팔레트 크기, alpha 분포, RGBA 지문을 기록한다.

범위 안에서 양의 면적을 가진 UV의 정수 화소 경계는 하한 floor와 상한 ceil로 정의한다. 이는 UV 영역과 양의 면적으로 겹치는 원본 화소의 집계다. 명시 반전·회전은 원래 UV 및 회전 값에 보존한다. 이 집계에는 실제 렌더의 정점 순서, UV lock, 재샘플링과 atlas 효과가 포함되지 않는다. 애니메이션 메타데이터가 있으면 전체 PNG 화소와 프레임별 면 실측 상태를 구별한다.

선행 PNG 175건과 면 RGBA 4,113건은 기존 근거다. PNG 경로, 텍스처 바이트 지문, 모델별 면 인스턴스와 상태 적용 횟수는 각자 다른 분모다. 결과물에는 원본 PNG·JSON·JAR 대신 출처, 해시와 파생 통계만 저장한다.
