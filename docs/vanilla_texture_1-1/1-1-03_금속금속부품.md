- A–E는 해당 16종 모두 경로·원본·정적 텍스처 실측·의미 있는 모델/UV 연결 여부(해당 없으면 근거와 함께 해당 없음 표시)를 판정.
- F는 **공식 원본과 실제 게임 정적 관찰을 확인한 범위만** `verified`로 표시하고, 확인할 수 없으면 `pending` 유지.
- G 결과 보고서에 본 분류의 실제 분석된 텍스처 수/화소수/면별 UV 근거/미확인 원본/반례를 각각 분리 기록.
- 기존 v4 자료와 최신 v38 선반 데이터를 보존하며 중복 계측 누적 부풀리기 금지. **단계 완성도 % 추정 금지**.
