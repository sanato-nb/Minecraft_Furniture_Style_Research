# 1-1-01 — 목재·원목 (18개)

> **계획 시작 기록**: 기준 v38, 기존 v4 계측 CSV에 파일별 기록 **18/18개 존재**. 이것은 새 A–G 연구 100% 완료가 아니며, **공식 Mojang client.jar 및 인게임 정적 렌더 확인은 미검증**. 애니메이션 연구 보류.

**정확한 원본 목록 근거:** [v4 150개 표본 CSV](../../research/vanilla_textures/v4_150/01_누적150종_픽셀측정.csv). **상위 계획:** [1-1 통합 작업표](README.md).

## 실행 체크리스트

- [ ] **1-1-01-A** 기존 측정·증거 회수
- [ ] **1-1-01-B** 원본 PNG 무결성 및 해상도
- [ ] **1-1-01-C** 색상·명암·알파·패턴 정량 검사

- [ ] **1-1-01-F** 공식 클라이언트 대조·인게임 정적 검사

A, B, C는 과거 분석을 단순 폐기/재반복하지 말고 **기존 측정 출처 확인과 직접 재검사 여부를 분리**하여 기록한다. F 미완료라도 소스 분석 실적을 누락하지 않고 “정적 소스 분석 완료/공식 검증 대기”로 별도 보존한다.

## 완료 조건 / 결과 표기

- A–E는 해당 18종 모두 경로·원본·정적 텍스처 실측·의미 있는 모델/UV 연결 여부(해당 없으면 근거와 함께 해당 없음 표시)를 판정.
- F는 **공식 원본과 실제 게임 정적 관찰을 확인한 범위만** `verified`로 표시하고, 확인할 수 없으면 `pending` 유지.
- G 결과 보고서에 본 분류의 실제 분석된 텍스처 수/화소수/면별 UV 근거/미확인 원본/반례를 각각 분리 기록.
- 기존 v4 자료와 최신 v38 선반 데이터를 보존하며 중복 계측 누적 부풀리기 금지. **단계 완성도 % 추정 금지**.
