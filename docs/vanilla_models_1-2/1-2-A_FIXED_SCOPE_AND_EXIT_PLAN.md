## 3. 실행 회차를 3회로 제한

| 회차 | 수행 범위 | 완료해야 할 게이트 | 종료 시 산출 |
|---|---|---|---|
| **1회차 — 모집단 고정** | 최신 Git tree와 v34 3개 인벤토리 대조; 2,390개 우선도 매핑/세 그룹 검증; 역사194+후속26 원본 파일 목록을 고정 | G1, G2의 기초 색인 | 자산4,669원장·역사/체크포인트 인덱스 |
| **2회차 — 증거 통합** | v65/66/69 누적 원장의 중복·출처와 기존 역사 기록을 합쳐 P1 544개 상태표와 P2/P3 경계 설정, B~G 후속 큐 생성 | G2 완성, G3, G4 | 표준 P1 증거원장544·후속 큐·미확인목록 |
| **3회차 — 최종 종료감사** | 별도 검증 스크립트로 다섯 게이트, 이전 값 보존, 문서 간 모순·증거 링크를 검사. 오류는 해당 회차에서 1회 정정·재감사 | G5 및 전체 5/5 | `A_AUDIT.json`·`A_FINAL_REPORT.md`·완료 또는 차단 판정 |

- **정해진 회차를 끝내면 멈춘다.** 성공 시 `A_COMPLETE_SOURCE_SCOPE` 판정 후 **A에서 더 모델 연구를 하지 않고** 1-2-B로 인계한다.
- 3회차 종료 후에도 치명적 조건을 만족하지 못하면 `A_BLOCKED`와 **정확한 미달 수치/원인/권한·원본 문제**를 보고하고 **자동으로 4회차·5회차를 무한 반복하지 않는다**. 범위 변경이나 추가 작업은 사용자 지시에 따라 별도 확정한다.
- 조기 종료 허용: 기존 증거가 충분해 G1~G5를 더 일찍 모두 통과하면 그 즉시 A 종료. 회차를 채우려고 추가 파일·모델을 억지로 조사하지 않는다.
- **버전 번호(v70, v71 등)나 CSV 열 수 증가는 목표가 아니다.** 기존 내용의 재실측·증거 재등장은 신규 연구량으로 계산하지 않는다.

## 5. 범위 제외 및 변경 통제

A의 필수 조건이 아닌 항목:
1. 공식 Mojang 압축 client.jar SHA 인증과 실제 인게임 런타임 렌더 확인 (원래 1-2 계획에서 필수 조건 제외; 성공했다고 거짓 주장 금지).
2. 모든 2,390개 모델의 원본 geometry·UV·PNG 픽셀 일괄 정밀 분석.
3. P1 544개 전체 렌더 출력, 틴트·애니메이션·특수 renderer 공식 인증.
4. Project Zomboid 가구 변환 또는 실제 마인크래프트 가구 모드 모델 제작.
5. 1-2-B~G의 모든 검증 결과를 A 완료의 선행 조건으로 끌어오는 행위.

A 완료의 의미는 **범위 내 '소스 목록과 과거 증거·상태·미확인 작업을 100% 정리하고 다음 단계로 정확히 넘겼다'는 것**이다. **전체 1-2 완료** 또는 **모든 블록의 구조를 마스터했다는 뜻이 아니다**.

## 6. 결과 저장·검수 약속

- 최종 산출은 `research/vanilla_models/phase_1-2-A_completion/`에 통합 원장·감사·이슈·보고서를 고정한다. 사용자 승인 없이 완료 기준을 수정하지 않는다.
- 기존 v1~v69 연구 파일·원장 **수정/삭제 금지**, 새 통합 결과에서만 연결. 잘못된 이전 기록은 별도 errata로 정정.
- GitHub `main` 갱신 전에 최신 HEAD lease 확인, 별도 원격 readback SHA 검증과 종료 보고서 커밋. 유효한 출처 없는 완료 주장 금지.
- A 종료 판정 후 상태는 **`1-2-A COMPLETE (source/inventory scope)`, `1-2-B IN_PROGRESS`** 등으로 분리해 기록. 1-2 전체는 B~G 완료 전까지 계속 미완료.
