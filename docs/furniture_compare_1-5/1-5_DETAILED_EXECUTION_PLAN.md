# 1-5 바닐라와 가구 모드 비교·검수 실행계획

입력 기준은 `34d892916618be8ea89bbf2ad686fdcbb7e11b61`이다. Minecraft 1.21.11 바닐라 원본과 1-3에서 고정한 Another Furniture, Handcrafted, Macaw’s Furniture 버전의 모델 구조·블록상태·원본 PNG·UV를 비교한다. 중심 비교 표본은 [1-3-E의 9개 유형·47개 상태](../../research/furniture_mods/phase_1-3/E/E_SAMPLE_SELECTION.csv), [1-4-E의 52개 모델 적용](../../research/furniture_mods/phase_1-4/entry04/1-5_TEXTURE_UV_HANDOFF.csv) 및 1,610개 연결 면이다. 표본 통계를 모드 전체 분포로 일반화하지 않는다.

## 실행 순서와 완료 기준

| 단계 | 작업과 완료 기준 |
|---|---|
| **A. 비교 범위·출처 고정** | 47개 상태와 52개 모델 적용, 1,610개 면의 키와 분모를 SQLite·인계표에서 독립 대조한다. 아래 바닐라 대조군 15개 구성의 원본 블록상태, 선택 모델 및 부모·텍스처 연결을 읽고 경로·SHA·비교 목적을 원장에 기록한다. 선행 연구의 승인 상태와 별도 확인이 필요한 항목을 명시한다. |
| **B. 바닐라↔모드 동기화 측정** | 로컬 좌표 16을 1블록으로 통일한다. 요소·표면 수, 로컬 두께·조립 경계, PNG 크기·화소 밀도·알파, 명시/기본 UV, 구성 상태·회전·UV lock 선언을 공통 스키마로 연결한다. 선행 실측은 경로·SHA와 계산 조건이 일치할 때 재사용한다. |
| **C. 유형별 교차 비교** | 9개 유형별로 바닐라 대조군과 가용한 모드 사례를 같은 조건에서 비교한다. 근거 판정은 `VANILLA_SHARED`, `MULTI_MOD_SHARED`, `MOD_SPECIFIC`, `UNVERIFIED_OR_COUNTEREXAMPLE`을 쓴다. 단일 모드·유사 구조·기능 비교가 가능한 범위를 행마다 명시한다. |
| **D. 반례·런타임 예외 검수** | 동일 형상/다른 PNG, 동일 PNG/다른 형상, 입자·아이템·특수 렌더, 회전·연결·다중 블록을 독립 검토한다. 모드 PNG 경로 미확인 8건, 선언 전용 77건, 미해결 부모·블록상태 참조는 관련 범위에 한해 근거와 함께 남긴다. |
| **E. 비교 DB·2단계 인계** | 원본·산출물 지문과 비교·판정의 연결 키를 정규화 SQLite와 비교표에 저장한다. 2단계에 넘길 관찰값·조건·반례·미확인 목록을 작성한다. |
| **F. 독립 종료 감사** | 원본 구간과 분모, 비교 키, 복합 상태 분해·예외, 중복과 비교 보고서를 독립 재현한다. GitHub 저장본의 SHA·행수와 1-1~1-4 보호 경로를 확인한다. 1-2 전체 심사 및 1-4-F의 공식 판정을 확인한 뒤 별도로 1단계 총괄 종료를 판정한다. |

1-2-G 소스 감사와 1-4-E 인계 근거를 착수에 사용한다. 현재 1-2 전체 종료 심사와 1-4-F 종료 감사가 남아 있다. 게임 내 렌더·충돌·상태 전환, 실제 PZ 가구 모델 제작·월드 변환은 각자 별도 실행 증거가 필요한 범위다.

## 바닐라 대조군 15개 구성

대조 대상은 구조·표면·상태 중 열에 명시한 비교 축이다.

| ID | 고정 구성 | 비교 축·연결 유형 |
|---|---|---|
| V01 | 오크 계단, 북향·하단·직선 | 의자 단차 실루엣, 소파의 좌대와 후면 높이 차 |
| V02 | 오크 반 블록, 하단 | 소형·대형 테이블 판재와 소파 좌대 두께 |
| V03 | 오크 울타리, 북쪽 연결만 | 테이블의 기둥과 결합 부품, 회전 multipart |
| V04 | 오크 압력판, 비작동 | 테이블의 얇은 상층 부품 |
| V05–V06 | 통, 북향 닫힘과 열림 | 수납장의 상태와 전면·몸통 |
| V07 | 책장 | 책장 면의 표면 패턴과 부피 |
| V08 | 조각된 책장, 북향·왼쪽 위만 채움 | 선반·책장 슬롯과 multipart 오버레이 |
| V09 | 하얀 양털 | 쿠션·소파·침대의 밝은 원본 표면 |
| V10 | 오크 판자 | 테이블·수납·선반 등의 목재 표면 |
| V11 | 흰색 침대, 블록상태의 기본 선택 | 침대 특수 렌더 경계 및 Handcrafted 단일 모드 사례 |
| V12–V13 | 빈 가마솥과 물 가득 찬 가마솥 | 싱크대의 빈 용기·수면과 별도 상태 |
| V14 | 랜턴, 바닥 설치 | 조명 외형과 PNG·UV |
| V15 | 빈 화분 | 장식용 용기의 벽과 내부 |

15개 구성은 비교 설계를 위한 고정 대조군이다. 바닐라 가구 기능과의 일대일 대응은 사례별로 확인한다. V11의 특수 모델은 형상·UV 수치 비교 전에 일반 요소와 엔진 렌더 근거를 구분한다. 최종 보고서는 바닐라 버전과 각 모드의 Minecraft 버전을 행별로 유지한다.
