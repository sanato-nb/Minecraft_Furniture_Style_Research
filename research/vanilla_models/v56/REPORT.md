# v56 — 1-2-A 남은 37개 원본 텍스처의 실제 SHA·PNG·UV 소스 픽셀 검증

> 2026-11-14 KST · 연구 시작 `main` HEAD `a6775d9513614b5571642aa82274c1c73420db2d` · Minecraft Java Edition 1.21.11 제공 추출 원본. v1~v55 연구 파일은 삭제하거나 덮어쓰지 않았다.

## 1. v55에서 인계받은 정확한 범위

v55의 P1 모델 544/544 `(asset_type,full_source_path,git_blob_sha)` 원본 식별 근거 유지. v53 신규 175모델의 유효 면 참조 3,413건 중 PNG 경로 해석 **3,393면**, 추상 피스톤 템플릿의 독립 슬롯 미해결 **20면**이 있었다. 해결된 고유 PNG 경로 49개 가운데 v54~v55에서 실제 원본 RGBA·UV를 측정했던 12개는 **그대로 계승**하고, 남은 **37개를 정확한 신규 검증 집합으로 선별**했다.

37개 경로는 색상별 촛불 텍스처 26종과 양털 11종이다. 기존 v55 경로별 검증 범위 원장을 재확인하여 이 37개가 참조하는 기존 원본 모델 면 **2,926건**과 서로 다른 원본 `(PNG 경로, 명시 UV 네 좌표)` 조합 **204개**를 기존 v53의 3,413면 원장에서 가져왔다.

## 2. 원본 PNG 바이너리 직접 분석 — v56 신규 37개

GitHub `1.21.11/assets/minecraft/textures/block/*.png` 원본 파일을 Base64 바이너리로 직접 가져와, 독립 JavaScript 계산으로 각 원본 전체 Git blob SHA-1을 재계산하고 GitHub 반환 SHA와 맞는지 확인했다. 모든 PNG 청크 CRC32, IDAT zlib/DEFLATE 해제 결과 Adler32, PNG 스캔라인 필터 및 RGBA 복원도 확인했다.

- **신규 원본 PNG 37개**: 전부 **16×16**, 총 **9,472개 실제 소스 RGBA 픽셀**을 복원했다.
- **Git blob SHA1 대조 37/37, PNG CRC32 37/37, zlib Adler32 37/37 검사 통과**.
- 이번 37개 중 **촛불 PNG 26개**는 원본 투명 영역과 불투명 촛불 영역이 공존하고, **양털 PNG 11개**는 원본 16×16 전체가 불투명하다. 원본 세부 RGBA·알파 통계는 [파일별 37개 증거](03_ORIGINAL_PNG_BINARY_RGBA_37.json) 참고.
- **이 연구에서 만든 순수 JavaScript 검증기** [REPRODUCE_ORIGINAL_PNG_SOURCE_RGBA_AUDIT.js](REPRODUCE_ORIGINAL_PNG_SOURCE_RGBA_AUDIT.js)를 함께 저장했다. v55의 Pillow 기반 원본 검사와 별개이며, 이번 37개의 **독립 Pillow 교차 검증 또는 실제 인게임 렌더러 실행을 수행했다고 주장하지 않는다**.

## 3. 모델 원본 명시 UV → 실제 PNG 픽셀

위 37개 PNG의 원본 명시 UV 204종 영역을 RGBA로 읽고 **2,926개 상속 적용 면 참조**에 연결했다.

| v56 신규 항목 | 측정 |
|---|---:|
| 원본 PNG 경로 | **37개** |
| 원본 자체 16×16 RGBA 픽셀 | **9,472개** |
| 서로 다른 원본 PNG+명시 UV 영역 | **204종** |
| 실제 소스 PNG 픽셀로 확인한 모델별 면 참조 | **2,926건** |
| 중복 포함 소스 RGBA 픽셀 관측 | **21,416건** |
| 중복 제거한 원본 PNG별 픽셀 좌표 | **3,362개** |
| 위 UV 표본의 alpha=255 / alpha=0 / 부분 투명 | **21,416 / 0 / 0** |

이 21,416은 **서로 다른 픽셀 수가 아니라 같은 원본 픽셀을 여러 모델 면이 사용하는 횟수까지 포함한 관측량**이다. 이 결과는 원본 명시 UV의 사각형 범위를 정렬해 픽셀을 측정한 것이며 **U/V 반전·면 회전·게임 엔진의 텍스처 아틀라스·보간·조명·렌더 출력**은 검증하지 않았다.

## 4. v54 + v55 + v56 누적 소스 UV 범위

| 항목 | 이전(v54~v55) | 신규(v56) | 누적 |
|---|---:|---:|---:|
| 원본 모델 face에 대한 실제 소스 PNG UV 픽셀 대조 | 467 | **2,926** | **3,393** |
| 반복 포함 원본 RGBA 픽셀 관측 | 29,812 | **21,416** | **51,228** |
| 중복 없는 (PNG 경로, 픽셀 좌표) | 1,498 | **3,362** | **4,860** |
| 해당 175모델 코호트의 PNG 경로 중 소스 UV 측정 | 12/49 | **37개 추가** | **49/49** |

누적 **3,393개 원본 PNG 경로가 해결된 적용 면 전부**의 소스 텍스처 UV 영역은 실제 RGBA 픽셀과 대조됐다. 이 가운데 **원본에 명시된 UV로 측정한 face 3,225건**과 **원본 UV 키가 없어 기하 기반 계산 후보를 쓴 케이크 face 168건**은 구분돼 있다. 후자의 계산 결과는 케이크 PNG 알파 마스크와 일치한다는 v55 근거를 계승하지만 **엔진 내부 UV 계산 규칙과 동일하다고 인증된 것은 아니다**.

v53 신규 모델 175개 중 **159개는 모든 경로 해결 면의 소스 PNG 픽셀 대조가 가능**하다. **2개 피스톤 부모 템플릿**은 독립 슬롯 placeholder 20면을 유지하고, **셜커13 + skull1 총 14개**는 모델 JSON 자체에 기하가 없어 실제 renderer 형상을 확인하지 못했다. 이 16개가 단순히 오류나 가구 형상 부재라는 뜻은 아니다.

v53~v56 관련 원본 바이너리 SHA/RGBA 검사는 누적 **50개 PNG**(v53의 4개 + v55의 9개 + 이번 37개)다. 이 중 49개는 이번 175모델 코호트에서 참조하는 PNG 경로이며, 나머지 v53 `lightning_rod.png` 한 개는 v53 175모델의 적용 면이 직접 참조하지 않는다.

## 5. 한계 및 다음 연구

**49/49**는 *v53 신규 175모델과 연결된 텍스처 경로 중, 경로 해석에 성공한 PNG의 소스 UV 픽셀 확인 범위*이지 P1 544개나 전체 2,390개 모델의 모든 텍스처/형태/렌더러 연구 완료가 아니다. 이전 v1~v55에서의 역사적 의미론 근거 통합도 아직 전수 완료하지 않았다. 과거부터 남은 암시 UV 엔진 인증, 기타 P1 모델의 실제 픽셀 검증, 색상별 셜커·skull 특수 렌더러, 전체 정적 블록상태, 스타일 규칙 도출 등이 다음 우선 조사다.
