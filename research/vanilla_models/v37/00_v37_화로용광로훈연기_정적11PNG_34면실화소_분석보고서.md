# v37 — 화로·용광로·훈연기 정적 PNG 11종 전 화소·34면 UV 참조 실제 RGBA 검증

> 2026-11-13 KST. v36의 6개 정적 모델/36개 재질 적용 면에서 실제 원본 PNG 화소 검증을 확장. **사용자 지시에 따라 애니메이션 프레임은 분석하지 않았음.**

## 분석 대상과 정확한 분모

- 사용자 연구 저장소의 Minecraft 1.21.11 리소스에서 **정적 텍스처 11 PNG 원본의 바이너리(Base64) 직접 조회 및 전 화소 디코딩**. GitHub blob SHA를 기존 v34 1,111 PNG 목록과 **11/11 교차 확인**.
- v36에서 식별된 고유 텍스처 경로 13종 중 **정적 11종만 원본 전체 RGBA 검사**. `blast_furnace_front_on`(원본 16×32)과 `smoker_front_on`(원본 16×48)은 다중 프레임 텍스처이므로 **PNG 픽셀/프레임 시퀀스·키프레임·색상 변화 모두 분석 보류**. 두 경로의 원본 블록 모델 선택·재질 슬롯은 v36에 이미 존재하는 정적 소스 기록만 보존.
- PNG 바이너리 검사: signature/IHDR/PLTE/tRNS/IDAT, **모든 청크 CRC32**, zlib **Adler32**, DEFLATE 블록, scanline 역필터, RGBA 복원 및 각 PNG 면적 대비 alpha 합 검사. **단일 JavaScript 해독기 검사**로, 이번 회차의 독립 Pillow 재확인 또는 공식 Mojang client.jar 검증은 수행하지 않음.
- 11 PNG 모두 16×16 정적 소스. 원본 **11×256 = 2,816 RGBA 픽셀**(불투명 2,816, 완전투명 0, 반투명 0).

## 원본 면×재질 연결 및 UV 주의사항

- v36 [6 leaf 36면 상속 경로](../v36/03_six_leaf_36_inherited_faces_material_bindings.csv)를 실제 PNG SHA 및 각 픽셀과 결합. **총 36 face×material 중 정적 34개 면 이미지 확인**, 나머지 **2면은 다중 프레임 텍스처라 보류**.
- 정적 34개 면은 공통 source `cube`의 전체 16×16면에 매핑한 **추론된 암시 UV**라서, **8,704 texel-uses**(불투명 8,704, 완전투명 0, 반투명 0)는 유도 UV 사각형으로 원본 화소를 참조한 **중복 포함 원시 사용 횟수**. Minecraft 런타임 winding/UV lock/실제 화면에 이 값이 그대로 적용됨을 검증한 것은 아님.
- 각 leaf 자체 0요소 / 공통 부모 `cube` 1요소·6 선언면이라는 v36 정적 기하 수치 유지. 34개는 새로운 **고유 선언면**이 아닌 **면×재질 인스턴스 중 PNG 검사 가능한 행 수**.

## 화로 정면의 lit false/true 텍스처 직접 비교

- 원본 `furnace_front.png`와 `furnace_front_on.png`의 동일한 16×16 위치별 픽셀을 대조: **RGBA 차이 36/256 픽셀, RGB 차이 36/256, 알파 차이 0/256**.
- 변경 영역의 원본 픽셀 bounding rectangle (x 최소, y 최소, x 최대, y 최대): **3, 11, 12, 15**. 이것은 **고정된 두 텍스처의 공간별 차이**이며 애니메이션/점화 움직임/실제 화면 재생 분석이 아님.
