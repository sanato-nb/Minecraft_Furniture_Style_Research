## 1. P1 544개 과거 기록 대조

- [P1 544개 v5~v34 선택 근거 SHA 교차 대조표](01_p1_544_historical_sha_evidence_crosswalk.csv): **v35 직접 원본 확인 15개**, v5~v34의 선정된 근거 CSV 18개에 정확한 SHA가 남아 있는 **83개**(그중 v25~v34 기록 62, v5~v8 기록 21), 이 18개 CSV에서 직접 매칭되지 않은 **446개**.
- 446개는 **과거에 일절 조사하지 않은 모델 수가 아니다**. 보고서/기타 CSV/SQLite에 있는 기록을 전수 교차한 것은 아니므로 역사적 대조 결과는 1차이며 최종 완료율 계산 불가.
- 역사 자료에 두 이름의 충돌하는 SHA 기록이 존재: chiseled_bookshelf, oak_shelf. 두 이름 모두 다른 자료에서 현재 목록과 맞는 SHA 기록도 존재한다. 충돌은 v7 CSV 검토 과제로 표시하고 이 자료로 원본 오류를 확정하지 않음.
- v34 모델 2,390 / P1 544는 파일 경로 인벤토리·파일명 휴리스틱 후보이고 전체 내용 정밀 분석 완료가 아님.

## 2. v36 신규 원본 직접 확인: 정적 화로/용광로/훈연기

- 원본: 사용자 GitHub 1.21.11/assets/minecraft/models/block 의 **6 leaf JSON 직접 조회**, v35 P1 후보 SHA와 **6/6 동일**. 관련 3개 부모 JSON 및 3개 blockstates JSON도 직접 읽음.
- 화로 furnace + furnace_on: 각 자체 요소 0, **orientable → orientable_with_bottom → cube** 부모 상속.
- 용광로 blast_furnace + blast_furnace_on: 각 자체 요소 0, **orientable → orientable_with_bottom → cube** 상속.
- 훈연기 smoker + smoker_on: 각 자체 요소 0, **orientable_with_bottom → cube** 상속.
- 부모 cube는 **1개 요소 [0,0,0]→[16,16,16], 원본 선언 6면**. leaf 6개는 이 공통 구조를 반복 적용하여 **36개 face×material 기록**을 만든다. 고유 원본 기하 선언면이 36개라는 의미는 아님.
- cube 원본 면의 UV 좌표는 모두 미기재. 36면에 기록한 전체면 [0,0,16,16]은 **기하 기반 암시 UV 추론**이며 공식 로더의 정확한 면 회전·winding 검증이 아님.
- 원본 JSON의 texture slot을 끝까지 상속 추적한 결과 **13개 서로 다른 텍스처 경로**를 식별했지만, **13개 PNG 원본 바이트·RGBA 픽셀을 새로 디코딩하지는 않음**. 따라서 투명·불투명 텍셀 수와 렌더 색상은 미확정.
- 각 블록의 꺼짐/켜짐 leaf를 6면씩 비교하면 **북쪽 정면 1면의 texture 경로만 다르고 나머지 5면은 동일**. 이는 lit 값에 따라 고정 모델이 선택되는 정적 소스 구조만 조사한 것.

[6개 leaf SHA·부모 원장](02_six_furnace_smoker_static_leaf_geometry_sha.csv) · [36면 재질 바인딩](03_six_leaf_36_inherited_faces_material_bindings.csv)

## 3. 원본 blockstate JSON 세 개 / 총 24 variants

- furnace, blast_furnace, smoker 상태 원본 JSON을 각각 직접 확인. 방향 4개(north/east/south/west) × lit 2개 = 블록마다 8개, **합계 24개의 원본 source variants**.
- 원본 상태 y 속성은 east=90, south=180, west=270이며 north는 미기재. 모든 24 variants에서 x·uvlock도 미기재. 키 부재를 explicit false/0과 혼동하지 않음.
- [24개 원본 상태 및 SHA](04_three_blockstates_24_static_variants.csv). 실제 게임 렌더/UVlock 효과는 확인하지 않음.

## 4. 검증 경계와 이어갈 작업

- **v35 15 + v36 신규 6 = 21개 P1 leaf를 두 회차에서 직접 SHA·JSON 확인**. 이는 조사한 회차의 직접 원본 검수 수이며, P1 완료율이나 전체 학습 진도가 아님. 이전 기록 83개는 별도 역사적 근거 등급.

- 공식 Mojang 1.21.11 client.jar 독립 해시/출처, 실제 인게임 정적 UV·컬링·광원, 종의 특수 본체 renderer는 **미검증**.
