## 4. 실제 PNG 바이너리·모든 3개 프레임의 source UV 픽셀 검사

해당 6개 원본 `textures/block/*_lantern.png`를 GitHub에서 바이너리 Base64로 읽고 **별도 Python/Pillow**로 직접 디코드했다. 각 PNG의 독립 Git blob SHA1 및 SHA256, RGBA SHA256, 원본 16×48 크기, 알파 픽셀·고유 색을 확인했다. **6개×16×48 = 전체 4,608개 원본 RGBA 픽셀** (불투명1,908, 완전투명2,700; 부분 알파0). 16×16 크기의 3개 프레임 밴드를 각각 계산하여 모든 6파일에서 세 프레임의 내용이 서로 다름을 확인했다.

기존 `face.uv`에 선언된 좌표를 **그대로 사용**하고, U가 반전된 경우에는 위치를 min/max로 정규화하여 사각형 영역의 원본 RGBA를 추출했다. 각 이미지에 대해 설치형 템플릿 **15면×3프레임**과 매달린 템플릿 **16면×3프레임**을 각각 원본 PNG에서 직접 crop해 SHA256을 계산했다.

| 샘플 범위 | 실제 원본 소스 측정 |
|---|---:|
| PNG 6개 × (설치15면+매달림16면) | **186개 리프 face 적용** |
| 3개 프레임을 포함한 면·프레임 샘플 | **558회** |
| 중복 포함 원본 소스 RGBA 텍셀 관측 | **12,168회** |
| 그중 불투명 / 완전투명 관측 | **11,736 / 432회** |
| 중복 제외 (파일경로,x,y) 좌표 | **2,088개** |

파일당 설치형 15면·3프레임은 936회 RGBA 소스 관측, 매달림16면·3프레임은 1,092회다. 각 타입/파일에 대해 **모든 3프레임의 원본 face 순서대로 이어 붙인 RGBA crop SHA256**를 `03_LANTERN_SOURCE_PNG_6_RGBA_3FRAMES.json`에 보존했다. 각 PNG의 투명 마스크 비율과 실제 face UV 부분별 투명·불투명 관측량을 구분했다.

주의: `UV`의 원본 U반전 여부는 보존했지만 픽셀 crop 자체는 **방향이 없는 소스 사각형**으로 취급했다. **마인크래프트 게임 엔진의 면 방향·보간·UVLOCK·오브젝트 가림·애니메이션 시각 재생·렌더러 공식 인증을 하지 않았다.** `REPRODUCE_PILLOW_LANTERN_AUDIT.py`는 전체 1.21.11 Git checkout용 재현 스크립트로 GitHub에 저장했지만, 완전 체크아웃에서 파일 전체를 다시 실행하지는 않았다. 원본 PNG 6파일과 위 총 558개 face/frame crop 분석은 Python으로 직접 실행해 별도 검사했다.

## 5. 스타일 연구에서 확인할 수 있는 제한적 관찰

(1) 같은 4요소 원형이 PNG만 바뀐 6개 재질 계열에서 재사용된다. (2) 설치형·매달림형의 몸통·부품 Y좌표가 다르고 교차 평면의 길이도 다르다. (3) 교차 평면은 0두께, 45도 회전, shade=false로 기하 디테일을 구성하며 색·광원 느낌의 세부 표현은 애니메이션 PNG에 맡긴다. (4) 원본 명시 UV의 U반전을 텍스처 정체/회전과 구별하여 기록한다. **모든 가구에 일반화할 최종 스타일 규칙은 아직 아니다.**
