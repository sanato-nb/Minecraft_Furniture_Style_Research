# v55 — 원본 PNG 9종·케이크 암시 UV·피스톤/피뢰침 소스 면 검증

> 2026-11-14 KST · Minecraft Java 1.21.11 추출 원본. 작업 시작 main SHA `9ff78606528a0324b76830ef97ea82d6076f3427`. v1~v54 원본·인수인계 근거 및 P1 544개 모델 식별을 보존.

## 1. 원본 이미지 파일의 실제 바이너리 검증

GitHub에 있는 원본 PNG 9개를 바이너리(base64)로 읽어 SHA1 Git blob 해시를 직접 재계산하고, Pillow로 각각 16×16 원본 RGBA 픽셀 256개를 직접 복원했다. **9개 모두 Git blob SHA 일치**. 신규 파일은 `cake_side`, `cake_top`, `cake_bottom`, `piston_side`, `piston_top`, `piston_top_sticky`, `exposed_lightning_rod`, `weathered_lightning_rod`, `oxidized_lightning_rod`이며 모두 `assets/minecraft/textures/block/*.png` 원본이다.

| PNG 그룹 | 신규 소스 파일 | 상속 적용 face 참조 | 반복 포함 실제 RGBA 픽셀 관측 | 원본 UV 상태 |
|---|---:|---:|---:|---|
| 케이크 side/top/bottom | 3 | 168 | 23,520 | **원본 UV 키 없음: 기하 기반 계산 후보** |
| 피스톤 side/top/sticky | 3 | 40 | 3,968 | **원본 명시 UV** |
| 피뢰침 exposed/weathered/oxidized | 3 | 33 | 588 | **원본 명시 UV** |
| **v55 합계** | **9** | **241** | **28,076** | **명시73 + 추론168** |

새로 확인한 9개 PNG의 실제 전체 RGBA 이미지 크기는 9×256=2,304픽셀이다. 표의 28,076은 모델별 면 참조가 동일한 픽셀을 반복해서 사용하는 것을 **중복 그대로 합산한 소스 텍셀 관측**이며 서로 다른 픽셀 28,076개가 아니다. 새 원본 PNG 9개의 UV 영역에 포함된 고유한 PNG 픽셀 좌표는 1,200개다. 이번에 추출한 21개의 `(원본 PNG 경로, UV 네 좌표)` 영역에서 측정한 모든 픽셀은 alpha=255였다.

## 2. 케이크 원본 모델의 암시 UV 검증

원본 부모 모델 `template_cake_with_candle.json`의 Git SHA는 `82a6ee824a3657a9d3080dbec303a83171f1baf2`이다. 첫 케이크 몸체 요소는 `from=[1,0,1]`, `to=[15,8,15]`이고 여섯 면 모두 원본 JSON에 `uv` 키가 없다. 큐브 기하의 좌표를 이용해 기본 UV를 **추정 계산한 후보**는 측면 네 방향 `[1,8,15,16]`(14×8=112픽셀), 위·아래 `[1,1,15,15]`(14×14=196픽셀)이다.

원본 `cake_side.png`의 alpha=255인 픽셀 집합은 정확히 위 계산한 112픽셀 영역과 같았다. `cake_top.png` 및 `cake_bottom.png`도 각각 원본 alpha=255 픽셀 집합 196개가 계산한 UV 사각형과 **좌표 단위로 완전히 일치**했다. 따라서 케이크 형상의 사각형 비례와 PNG 투명 여백 구성은 소스 근거 수준에서 일관된다.

**주의:** 계산 UV는 실제 원본 모델 JSON에 기재된 UV가 아니다. 해당 계산식과 Minecraft 클라이언트 엔진의 내부 UV 생성 알고리즘이 정확히 같은지, 게임에서 면의 좌우 반전·회전·방향·텍스처 아틀라스·라이팅이 어떻게 적용되는지는 검증하지 않았다. 168건의 케이크 면은 CSV에서 반드시 `computed_implicit_UV_candidate_not_in_source`로 표시한다.

## 3. 피스톤·피뢰침: 원본에 명시된 UV를 실제 PNG와 연결

원본 피스톤 헤드 leaf 4개에 대해 텍스처 슬롯이 해결된 40개 face 참조의 명시 UV를 실제 `piston_side`, `piston_top`, `piston_top_sticky` PNG에서 읽었다. 피뢰침 3종은 `template_lightning_rod`의 원본 UV를 상속받는 각 11면, 총 33면의 소스 영역을 확인했다. U·V 좌표 순서가 역순인 UV도 **원본 네 좌표를 보존**하되 픽셀 추출 시 최소/최대 범위를 사용했다. 이는 원본 영역에 색상/알파가 존재한다는 증거이고, 인게임 텍스처 방향·모델 표시가 맞다는 인증은 아니다.
