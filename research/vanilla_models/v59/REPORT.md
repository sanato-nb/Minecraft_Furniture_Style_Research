## 3. 원본 blockstates의 모든 **유효** 조합 정적 검사

`oak_shelf`, `spruce_shelf`, `birch_shelf`, `cherry_shelf` 원본 `blockstates/*.json`을 직접 재조회했다. 각 multipart **24규칙**, 합계 **96규칙**. 각 목재 4 `facing`(north/east/south/west) × 2 `powered`(false/true) × 4 `side_chain`(unconnected/left/center/right) = **32가지**, 4종 총 **128가지**에 대해 조건을 평가했다. 128/128에서 **본체1 + 전면1 = 정확히 2개** apply 참조 선택, 총 참조 사용256회. `powered=false`이면 side_chain과 무관하게 `_unpowered`이고, `powered=true`이면 chain에 따라 `_unconnected/_left/_center/_right`가 선택된다. facing에 따라 Y회전 0/90/180/270. 35모델 중 실제 blockstate에 나오는 리프는 인벤토리 제외24모델이고 직접 apply규칙 96건.

**이는 원본 JSON의 정적 조건 검사다.** Minecraft 공식 클라이언트 런타임 상태 전환, UVLOCK, 회전·면 가림 결과를 검증한 것이 아니다.

## 4. 원본 PNG 바이너리→Pillow RGBA 4종과 **원본 명시 UV** 전면20면

4종 `oak_shelf.png`, `spruce_shelf.png`, `birch_shelf.png`, `cherry_shelf.png`의 **원본 PNG 바이너리**를 GitHub에서 조회하고, Python/Pillow로 원본 Git blob SHA1, 독립 SHA256, RGBA 전픽셀을 직접 재검증했다. **4/4 SHA 일치**. PNG가 **모두 32×32**, 4,096소스 RGBA 픽셀 전부 alpha255. 원본 모델 `uv`는 일반적으로 0..16 단위이므로 좌표 경계에 **2픽셀/UV단위**를 적용했다. 특히 0.5 UV 경계는 원본 텍스처의 정수 픽셀 경계에 대응한다.

나무별 전면 변형 `unpowered,unconnected,left,center,right`의 **직접 선언된 UV5면**을 재조회하고, 각 텍스처에서 5개 영역을 Pillow로 실제 crop했다. 4종×5면 = **20면**, 각 UV 8×4가 이미지에서 16×8=**128실픽셀**, 총 **2,560 source RGBA 텍셀**이다. 모든 crop의 픽셀 SHA256과 alpha255=128/128을 파일 `04_SHELF_PNG_4_RGBA_AND_20_FRONT_UV.json`에 보관했다. 같은 PNG 내 이 5개 전면 crop은 서로 겹치지 않으므로 중복 제외 `(파일경로,좌표)`도 **2,560개**다.

**구분:** 상속 적용 152개 리프 face는 원본 `#all` 텍스처 원본 파일까지 연결했지만, **직접 Pillow crop한 면은 그중 전면20면뿐**이다. 다른 132면의 게임 엔진 색상 샘플링·UV 역방향·UV 회전은 미검증. 부모 템플릿 독립38면의 `#all`은 실제 PNG로 해결되지 않으므로 pixel sample로 계산하지 않았다. `REPRODUCE_V59_SHELF_PNG_AUDIT.py` 재실행용 코드를 저장했으며, 이 완성 스크립트 전체를 원본 Git checkout에서 재실행한 것은 아니다(각 PNG와 20 crop은 Python으로 직접 검증).

## 5. 모델링 스타일 관찰 (4종 선반 범위)

- 선반은 앞쪽까지 깊은 직육면체가 아니라 `z=11..16`의 뒷면 쪽 얕은 깊이와 판재3개를 사용한다. 이는 **해당 원본 모델**에 대한 관찰이지 모든 바닐라 가구의 규칙은 아니다.
- 0두께 전면 한 장과 상태별 명시 UV 텍스처가 본체를 그대로 두고 표현을 바꾼다. 나무 종류별로 공통 기하 원형을 재사용한다.
- 원본 UV의 부분 반전과 0.5 경계를 지키면 고해상도 32×32 PNG의 텍셀 경계와 맞는다. 실제 렌더러의 방향 해석·텍스처 보간 방식은 별도 검증이 필요하다.
