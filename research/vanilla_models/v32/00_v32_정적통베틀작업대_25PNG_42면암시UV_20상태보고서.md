### 암시적 UV의 범위

부모 `cube`의 `faces`에는 `uv` 값이 명시되어 있지 않다. 16×16×16 완전한 정육면체이므로 원본 기하에서 일반적으로 유도되는 각 **전체 면 UV 0–16 범위**를 **추론한 암시적 UV**로 기록했다. `[0,0,16,16]`의 256픽셀 *영역*은 각 면에서 동일하지만, 실제 엔진의 면 방향별 UV 순서/반전·블록상태 회전 후 UV 보정은 검증하지 않았다. **source-declared explicit UV라고 표기하면 안 된다.**

## 2. 25개 원본 PNG 실제 전체 RGBA 분석

사용자 저장소의 leaf 모델 7개에서 실제 참조하는 **중복 제거된 PNG 25경로**를 직접 조회하여, 4/8비트 인덱스 팔레트 및 8비트 RGB 원본을 바이트 단위로 풀고 **전 25종×16×16 = 6,400픽셀**의 RGBA를 조사했다.

| 항목 | 직접 측정 수치 |
|---|---:|
| 원본 PNG 고유 경로 수 | **25** |
| PNG 전 화소 | **6,400** |
| 완전 불투명 | **6,400** |
| 완전 투명/부분 알파 | **0/0** |
| 7 leaf의 면별 암시적 UV 선택 | **42면×256 = 10,752 texel-uses** |
| 그 중 불투명 참조 | **10,752** |
| 150종 기존 v4 표본과 겹치는 PNG | **12경로** |
| v4 선정 150종 표본 밖 PNG | **13경로** |

- 위 **10,752**는 **42개 leaf-specific face×material**이 전체 16×16 PNG 영역을 참조한다는 암시적 UV 기반 **추론 픽셀 사용 횟수**다. 10,752개의 서로 다른 원본 PNG 픽셀이나 실제 화면 렌더 결과가 아니다.
- 개별 이미지 RGBA 색상 종류는 다양하다. 예: `cartography_table_top` 27색, `fletching_table_side` 41색, `loom_bottom` 4색. 이는 **원본 이미지 색 수**로 실제 카메라 방향별 밝기/조명 수준과 혼동하면 안 된다.
- [03 앞의 PNG12 전 화소 통계](03_png_12_full_rgba_metrics.csv) · [04 나머지 PNG13 전 화소 통계](04_png_13_full_rgba_metrics.csv) · [05 42면에 대응하는 PNG 전체면 RGBA 및 평균 RGB](05_42_inherited_faces_png_full_rgba_evidence.csv).
- 기존 v4 **150선정 표본 중 12경로**의 **PNG 파일 바이트 길이·크기·전체 픽셀·가시 픽셀 수 모두 12/12 일치**. [06 원본 v4 표본과 교차검사](06_v4_overlap_png_byte_pixel_crosscheck.csv). SHA-256 전체 25파일을 별도로 재계산하지 않았다. 또한 **v4 표본 밖13경로=프로젝트 전체에 새로 등장한13경로**라는 뜻은 아니다(기존 v25–31 연구에 재검사된 원본 텍스처 있음).

- `barrel`은 여섯 방향을 **동일한 `cube_bottom_top` 원형**으로 공유하면서, 열림과 닫힘이 **다른 윗면 텍스처를 가진 두 leaf**를 선택한다. 한 프레임에서 다음 프레임으로 변하는 애니메이션을 나타내는 자료가 아니다.
- 지도 제작대·화살 작업대·대장장이 작업대·제작대는 별도 방향 상태 없는 **한 가지 모델 선택**이지만, `cube` 템플릿의 동서남북에 서로 다른 front/side PNG를 대응하여 정적 방향성이 있는 디자인을 구성한다. (예: 지도 제작대는 side1/side2/side3 3경로 사용.) 이것은 **모델의 로컬 면 별 재질 선언**이며 사용자가 실제 게임에서 블록을 놓았을 때 회전 가능한지에 대한 추가 검증은 아님.

## 4. 통 정적 열림/닫힘 — 실제 PNG 픽셀 단위 직접 차이

`barrel_top.png`와 `barrel_top_open.png`를 추가로 **독립 Python/Pillow`verify()`+RGBA 디코딩**하고 Git blob SHA-1 및 SHA-256을 각각 재계산했다. 업로드된 사용자 GitHub 원본 Git SHA와 **2/2 정확히 일치**.

| 통 로컬 윗면 텍스처 | 전체 픽셀 | 고유 RGBA |
|---|---:|---:|
| 닫힘 `barrel_top` | 256 | 7 |
| 열림 `barrel_top_open` | 256 | 8 |

**두 이미지의 대응 위치 256픽셀 가운데 132픽셀이 서로 다르고, 124픽셀은 동일**하다. RGB 각 채널 절댓값 차이 합은 **25,405**(8비트 채널 원본 RGB 수치 차이의 합, 시각적 품질 점수 아님). 모델 상속 최종 형상·6면은 바뀌지 않고 **로컬 `#top` 텍스처만 교체되는 정적 모델 상태**이다.
