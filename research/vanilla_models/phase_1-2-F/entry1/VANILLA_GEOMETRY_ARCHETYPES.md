# 1-2-F Entry1 — 원본 관찰에서 얻은 가구 모델링 원형

**고정 표본 150모델.** 원본 JSON/SHA 150개, C/B 기하 142개, E 예외 8개를 구별했다. 원본 PNG **195종 첫 프레임**을 접촉 시트로 직접 보았고 그중 **141모델**에 소스 이미지가 연결된다. 9개는 자기 슬롯이 바인딩되지 않은 템플릿이므로 색·패턴을 판정하지 않는다. 애니메이션의 뒷 프레임과 게임 렌더는 관찰하지 않았다. 각 모델의 근거와 제작 가설은 `STYLE_OBSERVATIONS.csv`에서 분리한다.

| 원형과 원본 모델 | 직접 확인한 구조·이미지 | 가구 제작에 적용할 **가설**과 한계 |
|---|---|---|
| 얇은 전면 판 — `acacia_shelf_unconnected.json` | 상속 요소 `[0,4,13]→[16,12,13]`, 북쪽 한 면의 0두께 판. 32×32 `acacia_shelf.png`에 칸과 가로선 무늬 | 얕은 선반 전면은 한 평면과 칸 무늬로 간략화 가능. 내부 깊이나 양면 가시는 증명되지 않음 |
| 지지 기둥·열린 프레임 — `birch_fence_gate.json` | 8요소, 좌우 기둥은 X 0~2와 14~16, Y 5~16. `birch_planks.png` 첫 프레임에 밝은 가로 띠 | 가구 다리/틀을 가는 직육면체 여러 개로 나누는 후보. 실제 가구 정체를 뜻하지 않음 |
| 낮은 상판 — `bamboo_slab.json` | 한 요소 `[0,0,0]→[16,8,16]`, 16×8×16 비례. `bamboo_planks.png`에 가로 띠 | 상판/받침의 높이를 8단위로 간략화 가능. 다리는 이 원형에 없음 |
| 두께 있는 세로 판 — `cherry_trapdoor_open.json` | 한 요소 `[0,0,13]→[16,16,16]`, 깊이3. PNG에 테두리와 투명 구멍 | 문짝 전면처럼 두께와 개구부 무늬를 분리할 후보. 인게임 투명 처리 미검증 |

| 상태별 재사용 — `blackstone_stairs_inner.json` | 상속 3요소. 원본 16 variant 선택에서 일부 X=180/Y=270/uvlock=true 명시 | 소수 모형을 방향·절반 상태에 재사용하는 후보. 상태 조합은 원본 정적 규칙 범위 |
| 특수 표현 경계 — `purple_shulker_box.json` | 일반 elements 없음, 보라 계열 particle PNG 첫 프레임만 관찰 | 색상 참고만 가능. 실제 renderer 표면·뚜껑 구조는 미확인 |

원형 태그는 중복 허용이다. 주 원형 33 전체 큐브/13 얇은 판 우선/36 회전 우선/27 다중요소 우선/33 단순 직육면체/8 특수 소스다. 0두께 52·얇은 요소 57·다중요소 61은 주 원형 집계와 별개의 중첩 태그다. 이 표본은 경로 균일 분산으로 선택되었으므로 전체 2,390개 바닐라 스타일의 분포를 대표한다고 주장하지 않는다.

정적 접촉 시트는 `visual_contact/contact_01.png`~`contact_05.png`; 원본 경로/번호와 픽셀 근거는 `visual_contact/index.json`, `F_PNG_DIRECT_VISUAL_OBSERVATIONS.csv`에 있다. 접촉 시트는 원본 이미지의 첫 정방 프레임을 확대해 보인 자료이며 Minecraft 게임 장면이 아니다.
