# 1-2-F Entry6 — 원본 PNG 332종 첫 프레임 실물 시각 접촉시트 검수

검수일: **2026-11-17** · 기준: 사용자 제공 Minecraft Java 1.21.11 추출 원본. **실제 PNG 바이너리에서 생성**한 첫 프레임 접촉시트 8장을 이번 회차에 직접 열람했다. 최초 `F3` 차단 원인은 원본 PNG 픽셀 미열람이었으며 이번에는 출처·픽셀 SHA를 대조한 자료로 해결했다. 다만 **모델별 물체 정체·게임 렌더러·애니메이션 전체·공식 JAR 인증은 하지 않았다.**

## 원본·시각 증거
- 원본 블록 모델에서 C 근거로 연결된 **고유 PNG 332개**를 읽음. Git 원본 blob SHA **332/332 일치**; C가 이전에 기록한 **원본 RGBA SHA-256 332/332 일치**. 중복 내용 SHA를 제외한 고유 이미지 본문은 **328개**.
- 332개 **첫 프레임을 실제 이미지 접촉시트 8장**으로 직접 열람(42+42+42+42+42+42+42+38). 검수 PNG 8개와 개별 원본 경로·blob SHA·첫 프레임 RGBA SHA·알파 픽셀 비율은 [visual_contact/](visual_contact/)의 PNG·CSV 및 [F3_PNG_FIRST_FRAME_332.csv](F3_PNG_FIRST_FRAME_332.csv)에 고정.
- **332 첫 프레임 모두 가시 픽셀 존재**. 200개 첫 프레임 알파 빈 영역 0, 132개는 빈/부분 알파 영역 있음. 16개 원본은 프레임이 수직으로 이어진 PNG이며 **첫 프레임만** 판독함. 32개에 대해서는 시각적으로 구분되는 대표 무늬·윤곽을 관찰 기록으로 추가; 다른 300개는 이미지 전체 열람+알파·색상·크기 객관 지표까지만 기록했다.
- 모델 378개 중 **340개에 직접 매핑된 PNG 첫 프레임 근거가 존재**(고유 PNG→모델 참조 **474개**), **38개 모델은 직접 바인딩된 C PNG가 없는 일반 템플릿/미직접 모델·일부 E 예외**로 보존. 38개를 “이미지를 보고 확정한 모델”이라고 주장하지 않으며 [F3_UNBOUND_OR_TEMPLATE_38.csv](F3_UNBOUND_OR_TEMPLATE_38.csv)에 정체·스타일 **미결정**으로 기록.
- 원본 PNG를 실제 열람한 것과 **개별 모델의 완성 렌더**를 본 것은 구분한다. 자동 원본 이미지 픽셀 검수는 **실제 게임의 회전·블렌딩·색상 틴트·입체 화면** 증명이 아니다.
