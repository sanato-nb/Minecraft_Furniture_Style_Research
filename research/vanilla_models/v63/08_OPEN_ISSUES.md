# v63 남은 문제 및 연구 오류 구분

1. **V63-E01 — 역사 파일 170개 이번 회차 내용 미검수:** 실제 Git 트리로 v5~v43의 21폴더 194파일 인벤토리를 확보했지만, v62 선택 역사21 CSV + v63 신규3 CSV = 24 CSV만 이번 선별 분석에서 직접 내용 재조회. 나머지 170파일은 **v62~v63 통합 작업에서 내용 미검수**로 분리. 과거 v1~v61의 연구가 전혀 없다는 뜻이 아님.
2. **V63-E02 — SQLite 4개 재판독 미실시:** 역사 v5-v8 DB는 Git tree 경로 SHA 식별; 이전 v47 DB 직접 분석 기록이 있으나 이번 회차 SQLite 레코드 본문 재검증은 하지 않음. 다음에는 v47 결과와 원본 schema/table SHA 재대조.
3. **V63-E03 — v30 historical 3 leaf row SHA 복원:** `chipped_anvil`, `damaged_anvil` 선택 과거 v62 자료상 근거 없음 2건은 이번 v30/08 및 원본 JSON 대조로 해결. source identity 544/544는 기존 완료 실적이므로 신규 신원 링크0. `anvil`은 과거부터 직접 검토된 모델이며 새로 고유한 direct1개로 세지 않음.
4. **V63-E04 — v44 역사 증거 CSV SHA 오기6건:** v62의 v27 옛 CSV Git SHA 마지막 글자 누락 6링크 정정표 유지. 모루 역사 근거와 별개 이슈, 모델 SHA 충돌 아님.
5. **V63-E05 — UV/Pillow/게임 런타임:** 모루 원본 템플릿 명시 UV 21, leaf 적용 63 face와 4개 원본 PNG Git SHA/IHDR 직접 증거. PNG 전체 픽셀 v63 신규 Pillow 검증0, 공식 엔진 방향·UVLOCK·실게임 렌더 검증0. 다른 모델의 계산된 암시UV는 여전히 엔진 공식 인증 아님.
6. **V63-E06 — 완료 기준:** P1 544개 중 v35~v63 직접 모델 JSON 판독 플래그 결합516, 나머지28은 선택 역사 CSV 원본 모델 SHA 행 보유. **1-2-A 전체 모델 모든 세부 근거 검수 완료 아님**, 실질 완료율 미산정.
