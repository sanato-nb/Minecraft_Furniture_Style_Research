# v44 — 1-2-A 첫 원장: P1 544모델 연구 중복·SHA 출처 재대조

> 2026-11-14 KST · 고정 main `241ceaad5b0fb832a4bed6ef2292809e70616d51` · **새로운 대조/집계 연구 수행**, 원본 JSON 픽셀·geometry 신규 실측은 0. 역사적 v5~v43 보고서·CSV는 보존.

## 결론

- v34 `models/block` Git tree **2,390 JSON 경로·Git blob SHA 2,390/2,390**를 v34 전체 파일 인벤토리에 대조하여 일치.
- v34 우선 P1 **544개**를 `(asset_type=block_model_json, 전체 원본 경로, Git blob SHA)`로 재인덱싱; v35와 v36의 각 544행도 **544/544 SHA·경로 일치** 확인.
- v36 역사 교차표의 과거 모델 **83개**가 P1 원본 SHA 일치 근거에 연결됐으며, 17개 원본 연구 CSV에서 역사 참조 **144건**을 행별 SHA·모델 유형·경로로 별도 재조회해 일치 확인. 일부(84번째) v35 모델에도 과거 참조가 하나 있어 83+1 중복을 분리함.
- 최근 선택 회차 v35 직접15, v36 직접6, v38 직접7, v43 직접4는 합계 **32개**이지만, v38 선반 7종 중 기존 역사와 **5개 중복**. **역사83+최근32−중복5=고유 SHA 연결 모델 110개.**
- **나머지 434개는 '이번에 확인한 선택 근거에서 SHA 미연결'** 상태. v5~v34 모든 과거 문서를 완전히 검수하지 않았으므로 '아예 미분석' 또는 '소스 미확인 확정'이라고 선언하지 않음.
- v36 `chiseled_bookshelf`·`oak_shelf`의 두 SHA 충돌은 [v43 재검증](../v43/04_v36_sha_conflict_path_type_audit.csv)과 v7 원본 행을 대조해 `blockstates/*.json` 대 `models/block/*.json` **서로 다른 자산 타입을 basename으로 합친 오탐**으로 확인, **2건 해결**. 진짜 같은 소스 경로 SHA 상충 2건이 아님.
