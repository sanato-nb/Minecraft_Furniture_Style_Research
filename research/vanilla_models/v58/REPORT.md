## 3. 원본 블록상태의 전 조합 정적 평가

`chiseled_bookshelf.json`의 **원본 multipart 52규칙**을 JavaScript로 그대로 조건 평가했다. 4방향 × 슬롯6개의 참/거짓 조합 `4 × 2^6 = 256`개 모두에서 정확히 **본체1 + 슬롯6 = 7모델 선택** 확인. 전체 모델 선택 기록 **1,792건**은 서로 다른 모델 1,792종이 아니다. 방향별 Y 회전 0/90/180/270이 일치하며, 본체 규칙은 `uvlock:true`, 슬롯 규칙은 `uvlock` **미기재**였다. 이를 슬롯 `uvlock:false`의 엔진 출력 검증으로 바꾸지 않는다.

`composter.json` 원본 multipart **9규칙**을 level 0~8 전부 평가: level0 본체만, level1~8 본체+일치하는 내용물 한 개. 총 9상태, 중복 포함 **17개 모델 적용**. 이 두 블록상태 파일은 v57 이전에 경로를 확인한 **기존 소스 파일**이며, 신규 수치는 전 조합 정적 평가에 대한 것이다.

## 4. 실제 원본 PNG 바이너리 및 Pillow 실화소 측정

4개 원본 `1.21.11/assets/minecraft/textures/block/*.png`를 GitHub에서 Base64 바이트로 직접 읽어 Python `hashlib` Git blob SHA1/SHA256 대조 + Pillow RGBA 전픽셀 디코드했다. 모두 **16×16**, 총 **1,024 픽셀**, Git blob SHA 일치 4/4.

| 원본 PNG | 전체 RGBA 픽셀 | alpha=255 | alpha=0 |
|---|---:|---:|---:|
| `chiseled_bookshelf_empty.png` | 256 | 256 | 0 |
| `chiseled_bookshelf_occupied.png` | 256 | 256 | 0 |
| `composter_compost.png` | 256 | 144 | 112 |
| `composter_ready.png` | 256 | 144 | 112 |
| **합계** | **1,024** | **800** | **224** |

조각 책장 빈/채워진 PNG에서 여섯 원본 명시 UV 사각형이 각각 픽셀 256개를 겹치지 않게 나눠 쓴다. 해당 leaf12 face + inventory 북쪽1 face = **원본 명시 UV 13면, 반복 포함 768회 PNG 소스 픽셀 대조**. 인벤토리 전체면과 빈 슬롯 6면은 같은 빈 책장 PNG 텍셀을 사용하므로 고유 픽셀로 중복 집계하지 않는다.

퇴비통 PNG는 두 파일 모두 **중앙 12×12=144 불투명, 나머지 112 투명**. 원본 UV 없는 8면의 기하 계산 후보 [2,2,14,14]로 각 144 픽셀을 조회해 **계산 후보 8면, 반복 포함 1,152회 소스 픽셀 대조**. 원본 명시 UV로 승격시키지 않는다. 전체 21면의 중복 제외 (PNG 경로, 좌표)는 **800개**다. 소스 이미지 알파 마스크 일치는 엔진 UV 방향·회전·UV 계산의 직접 인증이 아니다.

재현용 `REPRODUCE_V58_ORIGINAL_PNG_AUDIT.py`는 원본 checkout과 Pillow가 있으면 SHA·RGBA·UV 사각형 합계를 검사한다. 이 회차에서 각 이미지와 UV 픽셀은 직접 Pillow로 측정했으나, 제공한 최종 재현 스크립트 자체를 전체 Git 체크아웃에서 한 번 더 실행한 것은 아니다.

## 5. 모델링 스타일에 대한 지역별 관찰 (확정 규칙 아님)

- 한 개의 얇은 평면 요소+실제 색상 텍스처로 조각 책장의 수납 표현을 만든다. 6위치별 기하 원형과 빈/채움 텍스처 override를 분리한다.
- 가구의 내부 채움 정도는 내용물 요소 높이를 3→15로 조절한다. PNG 2종이 표면을 표현하며 기하/이미지 역할이 분리된다.
- 정확히 16단위 전체 격자를 사용한 원본 UV 사각형, 0두께 평면, 부모 템플릿 상속 및 반복적 상태 규칙이 이 샘플에 확인된다. **다른 가구에 대한 일반 법칙은 확정하지 않았다.**
