# 1-5-A · 비교 범위와 원본 출처 검증

[1-5 실행계획](../../../../docs/furniture_compare_1-5/1-5_DETAILED_EXECUTION_PLAN.md)을 먼저 반영하고 그 계획의 대조 구성 15개를 조사했다. 입력은 1-4-E 종료 커밋 `34d892916618be8ea89bbf2ad686fdcbb7e11b61`에서 고정했다.

| 범위 | 검증 결과 |
|---|---:|
| 가구 모드 | 3모드 · 9유형 · 대표 상태 47개 |
| 모드 모델 적용과 면 | 52건 · 1,610면. 정적 실측 1,521, 애니메이션 실측 1, 영면적 UV 88 |
| 바닐라 Java 1.21.11 | 대조 구성 15개 · 모델 적용 22건 · 요소 인스턴스 55개 · 면 인스턴스 234개 |
| 바닐라 원본 직접 해시 | 블록상태 14개 · 모델/부모 41개 · PNG 19개. 1-2-G 원장과 **74/74** 일치 |

모드 표본은 1-3-F와 1-4-E SQLite를 모델 적용 키와 면 키로 양방향 대조했고, 1-5 인계 CSV 52행의 모델·기하 제공자·상태 SHA와 회전·UV lock 및 면 집계도 확인했다. [모드 표본 원장](MOD_CASE_SCOPE.csv)

바닐라 고정 JAR에서 상태 선택을 해석하고, 부모 체인과 텍스처 슬롯을 직접 따라갔다. V03은 울타리 기둥과 북쪽 연결 모델을 선택했다. V08은 조각된 책장의 몸체와 슬롯 모델 6개를 선택했다. 기존 1-2-G 상태 옵션 원장에도 있는 11건은 모델 경로, 블록상태 SHA, 회전·UV lock 및 가중치가 일치했다. [대조군 상태·모델 원장](VANILLA_CONTROL_OPTIONS.csv) · [원본 SHA 원장](VANILLA_SOURCE_PROVENANCE.csv)

V11 흰색 침대의 블록상태 모델은 일반 요소가 0개이며 파티클 PNG를 참조한다. 1-2-E 보고와 같이 파티클을 가시 면으로 집계할 근거는 없고, 실제 침대 렌더는 별도 범위다. V12 빈 가마솥은 13요소·58면, V13 물이 가득 찬 가마솥은 14요소·59면이었다. 이 분모는 B에서 싱크대의 용기·수면 조립을 비교할 때 사용한다.

## 재현과 다음 단계

저장소 루트에서 아래 명령으로 A 원장을 재생성한다. JAR의 SHA-1을 1-3-F 출처 핀과 비교하고 각 ZIP 엔트리의 Git blob SHA·크기를 1-2-G 원장과 대조한다.

```sh
entry=research/furniture_mods/phase_1-5/A
python "$entry/verify_scope.py" --jar CLIENT_1_21_11.jar --out OUTPUT_DIR
```

다음은 **1-5-B 동기화 측정**이다. 22개 바닐라 모델 적용과 52개 모드 모델 적용의 기하·면·UV·알파·밀도를 같은 단위와 키로 정리한다. 1-2 전체 종료 심사와 1-4-F 종료 감사의 공식 판정은 총괄 종료 전에 확인해야 한다.
