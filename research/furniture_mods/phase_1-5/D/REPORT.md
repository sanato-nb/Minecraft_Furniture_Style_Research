# 1-5-D · 반례와 런타임 예외 검수

기준은 [1-5-C 교차 비교](../C/REPORT.md) 종료 커밋 `84c213f24b942151359c9591df74e47cc2dce7a5`다. 고정된 모드 소스·JAR에서 예외 원본을 다시 읽고, 모델 선택과 부모 계보를 1-3-F DB 및 1-5 표본과 대조했다.

## 자산 및 상태 참조

| 예외 | 재검수 결과 |
|---|---|
| 부모 누락 48개 모델 | 원본 모델 본문 SHA와 부모 선언을 전부 확인했다. 누락 대상은 Macaw `desk` 22건, `drawer_base` 22건, AF의 `lantern` 4건이다. AF 원문은 네임스페이스 없는 `lantern`이고 기대 경로와 바닐라 `block/lantern` 후보를 구분해 기록했다. 고정 블록상태에서 선택되는 모델의 계보와 1-5 표본 계보에 해당 예외 모델은 0개였다. |
| 미해결 모델 선택 4건 | AF `unused/white_awning`의 네 방향 `type=double`이 같은 `white_double` 모델을 가리킨다. 고정 원본에 정확한 대상 파일은 없었다. 1-5 표본 밖이다. |
| 의자 변형 반례 2건 | AF 자작나무·가문비나무 의자의 남향 `variant=3`·`tucked=false`가 각각 `birch_1`·`spruce_1`을 선택한다. S03·S04 비교는 선택된 원본 모델을 유지한다. |
| PNG 경로 미확인 8건과 선언 전용 77건 | 누락 PNG는 고정 원본에서 정확한 경로가 없고 총 139개 면에 연결된다. 이 중 12개는 아이템 모델 면이다. 85건은 해당 Minecraft 버전으로 연결했을 때 비교 표본 면에 등장하지 않았다. 예를 들어 `white_wool`은 1.21.1 선언 전용과 1.21.11 모드 표본 면 66개를 구분한다. 파티클 및 아이템 레이어 표시는 별도 확인 항목이다. |

## 정적 원본으로 확인한 반례

- **침대** — 바닐라 V11의 월드 블록상태는 파티클 전용 JSON을 선택하고, 아이템 정의에는 `minecraft:special` 아래 `minecraft:bed`가 선언된다. HC S37·S38은 북향 조립에서 머리 모델을 Z−16만큼 옮겼을 때, 머리 요소의 꼭짓점 8개가 발치 모델 요소 11번과 일치했다. 실제 표시 중복, 가림, 충돌은 런타임 확인이 필요하다.
- **램프** — AF S44·S45는 동일 PNG에서 네 개 면의 UV와 화소가 바뀐다. 원본 Java에는 점등 상태에서 레벨에 5를 곱하고 꺼진 상태에서는 0을 반환하는 광량 선언이 있다. 점등 레벨 1·2·3의 소스 값은 5·10·15다. 실제 표시와 전파는 별도 확인이 필요하다.
- **UV lock·가림·색조** — 고정 표본에서 UV lock 설정이 켜진 모델 적용 10건, cullface 선언 면 322개, tintindex 선언 면 1개를 확인했다. 원본 화소의 알파와 정적 면 선언은 원장에 보존했다. 렌더러가 적용한 월드 색상이나 최종 가시 면에는 별도의 관찰 증거가 필요하다.

```sh
  --mc1211 CLIENT_1_21_1.jar --mc12111 CLIENT_1_21_11.jar --out "$entry"
```
