## 유형별 핵심 판정

| 유형 | 확인한 차이와 비교 범위 |
|---|---|
| 의자·스툴 | 바닐라 계단과 AF 오크 의자는 높이 1블록, HC·Macaw 오크 의자는 1블록을 넘는다. AF 의자의 넣은 상태는 Z축 위치가 바뀌며 46면의 PNG·UV·화소는 같다. HC는 쿠션 요소 12의 6면에서만 PNG를 교체했다. C01–C03 |
| 소형 테이블 | 바닐라 반 블록과 Macaw 커피 테이블 중앙형은 1블록 폭·깊이의 단일 판재이며 높이는 각각 0.5, 0.125블록이다. HC 사이드 테이블의 실측 면 11개에서 완전 투명한 화소 영역을 확인했다. C04–C05 |
| 식탁·대형 테이블 | 세 모드 오크 테이블의 지지 요소가 감소하는 상태에서 상판 높이가 각각 **3/16, 4/16, 5/16블록**이었다. AF 지지부와 오크 울타리에는 상태 조건으로 모델을 조립하는 공통점이 있다. C06–C07 |
| 수납장 | 바닐라 통과 AF 서랍은 열림 상태에서 경계와 UV가 같고 각각 한 면의 PNG와 화소가 달랐다. AF·HC 기준 서랍은 1요소이고, Macaw 기준 서랍은 5요소로 별도 손잡이 모델 요소가 있다. C08–C09 |
| 책장·선반 | 바닐라 책장과 Macaw 기본 책장의 `bookshelf.png` SHA-256은 동일하며 요소는 1개와 10개다. 조각된 책장과 HC 선반은 0두께 표면을 별도로 조립한다. Macaw 연결형은 같은 PNG 경로를 유지하며 면 배치가 달라진다. C10–C12 |
| 소파·벤치 | HC와 Macaw 코너 소파는 PNG 경로 집합이 같고 요소 수가 각각 8→6, 11→7이었다. AF 벤치는 등받이 제외 시 3요소가 빠진다. C13–C14 |
| 침대 | 바닐라 침대의 일반 블록 모델 요소는 0개다. HC 발치 모델은 깊이 2블록이며 발치·머리맡에는 정적 모델 면이 각각 72개·6개 있다. 바닐라의 실제 침대 렌더 및 HC의 결합 표시를 확인해야 등가 비교가 가능하다. C15–C16 |
| 주방 | 바닐라 가마솥과 Macaw 싱크대는 물 상태에서 경계와 마른 상태의 면 서명을 모두 유지하고 상향 애니메이션 면 하나를 추가한다. HC 조리대의 하부 PNG 경로 여섯 면이 바뀌지만 RGBA 지문 변화는 다섯 면에서 확인했다. C17–C19 |
| 조명·장식 | AF 램프는 점등 전후 같은 PNG에서 4면의 UV와 화소가 바뀐다. 광량 효과는 정적 원장으로 판정하기 어렵다. 바닐라 빈 화분, AF 화단 상자, HC 화분은 서로 다른 크기와 요소 조립을 갖는다. C20–C21 |

모델 한 개씩 적용되는 상태쌍은 로컬 요소 번호·면 방향으로 경로·UV·화소를 대조했다. 물 추가 및 책장 연결은 요소 번호가 바뀔 수 있어 조립 경계, 로컬 방향, PNG·UV, cullface·tint 선언 및 RGBA 지문의 다중집합을 비교했다. 이 서명 비교는 모델 면의 정적 근거이며 게임 내 가림, UV lock 결과, 조명, 충돌, 배치 동작에는 별도 증거가 필요하다.
