# 1-5-E · 비교 SQLite와 2단계 인계

[1-5-D](../D/REPORT.md) 종료 커밋 `85f2336a59c09b5507b9cca31f8d5c030795a608`의 비교·판정·예외를 정규화했다. 연구 DB는 버전과 출처가 같은 원본 경로를 한 자산 키로 연결하고, Git blob SHA-1과 SHA-256을 해시 종류별로 보존한다.

| 연결 범위 | 건수 |
|---|---:|
| 비교 유형 / 표본 상태 | 9 / 62 |
| 모델 적용 / 요소 / 면 / 애니메이션 프레임 | 74 / 390 / 1,844 / 109 |
| 원본 자산 / 해시 / 모델 적용의 출처 역할 연결 | 272 / 346 / 221 |
| 교차 비교 판정 / 2단계 인계 조건 | 21 / 21 |
| 부모 / 상태 / 텍스처 예외 | 48 / 6 / 85 |
| 인게임 확인 항목 | 10, 실행 0 |

모델 본체와 기하 제공자의 출처를 별도로 연결했다. HC 서랍 S22의 본체는 모드 Git 원본이고, 기하 제공자인 바닐라 1.21.1 `cube.json`은 JAR 기반 SHA-256으로 연결된다. 모드 모델이나 PNG 본문은 DB에 포함하지 않고 경로, 해시와 측정값을 사용한다. 바닐라 침대 V11에는 정적 기하 제공자 링크가 없으며 파티클 PNG와 아이템 특수 렌더 근거를 보존했다.

## 2단계 인계

[2단계 인계표](PHASE2_HANDOFF.csv)에서 관찰·적용 범위·재검수 조건을 함께 확인할 수 있다. 판정 **14건**은 규칙서 검토 후보로, **7건**은 반례 또는 적용 범위 제한으로 인계했다. 후보는 확정 제작 규칙이나 권장 치수로 승인하기 전에 해당 조건에 따라 재검수한다. 런타임 확인 결과가 필요한 판정은 D의 확인표 ID에 연결했다. 등록 누락과 파티클·아이템 레이어는 D의 공통 범위 예외로 유지했다.

| 인계 예시 | 다음 검수 조건 |
|---|---|
| 통·서랍의 열림 표면 | PNG가 바뀐 면과 실제 개방 공간·충돌을 구분한다. |
| 책장의 공통 PNG | PNG 해시와 샘플링 UV, 본체 형상을 각각 대조한다. |
| 가마솥·싱크대의 수면 | 추가 면, 프레임·tint 및 월드 수면 위치를 확인한다. |
| 바닐라·HC 침대 비교 | 특수 렌더 및 머리·발치 조립의 실제 표시를 확인한다. |
