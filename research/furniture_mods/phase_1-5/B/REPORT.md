# 1-5-B · 바닐라와 모드의 형상·UV·화소 동기화

기준은 [1-5-A](../A/REPORT.md)에서 고정한 Minecraft Java 1.21.11 대조군과 가구 모드 3종의 대표 상태다. 바닐라 원본 JAR에서 모델·부모·PNG를 다시 읽어 직접 측정했다. 모드의 형상은 1-3-E, 면의 UV·색·알파는 1-4-D, PNG 원본 경로와 해시는 1-3-F·1-4-C에서 키를 맞춰 연결했다.

| 공통 원장 | 바닐라 | 모드 |
|---|---:|---:|
| 상태·대조 구성 | 15 | 47 |
| 모델 적용 | 22 | 52 |
| 요소 인스턴스 | 55 | 335 |
| 모델 면 | 234 | 1,610 |
| 기본 UV / 명시 UV | 147 / 87 | 6 / 1,604 |
| 정적 실측 / 애니메이션 면 / 영면적 UV | 218 / 16 / 0 | 1,521 / 1 / 88 |
| 애니메이션 면별 프레임 원장 | 77 | 32 |

V11 흰색 침대는 모델 적용 한 건을 유지했다. 일반 요소가 없는 특수 렌더 사례라 경계·면·픽셀 밀도는 비워 두었다.

## 공통 단위와 비교 예시

좌표 16을 1블록으로 환산하고 요소의 로컬 두께와 상태 회전 후 조립 경계를 기록했다. 면의 축별 밀도는 연속 UV 폭·높이를 PNG 프레임 픽셀로 환산해 대응하는 모델 로컬 면 길이로 나눴다. 면 UV 회전이 90°·270°인 경우 로컬 축을 바꿔 대응시켰다. 정수 화소 경계는 기존 C 방식에 맞췄고, 애니메이션은 PNG 시트와 개별 프레임의 치수를 함께 기록했다.

- 바닐라 하단 오크 반 블록 V02의 높이는 **0.5블록**, 비작동 오크 압력판 V04는 **0.0625블록**이다. 판재·얇은 상층 부품의 비교 기준으로 사용한다.
- 바닐라 V12→V13에서 가마솥의 조립 경계는 **1×1×1블록**, Macaw S42→S43 싱크대는 **1×1.25×1블록**으로 각각 유지된다. 두 비교쌍 모두 물 상태에서 요소 하나와 애니메이션 면 하나가 추가됐다. 유형별 공통점과 적용 한계는 C에서 판정한다.
- 상태 회전·UV lock·cullface·tint 선언은 원장에 보존했다. 면 UV와 RGBA 수치는 모델 로컬 좌표 및 원본 PNG 프레임 기준이다. 인게임 아틀라스·조명·보간·UV lock 효과는 별도의 실행 근거가 필요하다.
