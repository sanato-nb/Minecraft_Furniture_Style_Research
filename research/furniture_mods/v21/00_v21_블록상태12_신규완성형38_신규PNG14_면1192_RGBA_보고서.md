# v21 — Another Furniture 블록 상태 12개 재검증·신규 완성형 38개·새 PNG 14종·1,192면 실화소

> 2026-11-12 KST. 이전 v20의 **원형 69개 원본 직접 검증**에서 이어진 실제 원본 분석. 제작자 원본: `crispytwig/AnotherFurniture`, Minecraft 1.21.1 소스, Git 고정 커밋 `57eb624cbb7f408d43398c7434b0d38d312cb55d`. **모드 전체 또는 Minecraft 1.21.11 버전 호환성 검증이 아님**.

## 1. 수행 작업과 원본 SHA

- 제작자 원본 **블록 상태 12개 JSON**을 고정 커밋에서 다시 읽고 이전 v11 기록의 Git blob SHA 12/12 및 항목/참조 수와 일치 확인. `variants`/ `multipart`의 각 **802개 적용 레코드**를 하나씩 읽어 **서로 다른 114종 모델 경로**를 추적했다. **`minecraft:block/air`이 2개 적용 레코드에 등장**하므로 이 114종이 모두 모드 가구 JSON은 아니다. 12개는 선택한 블록 상태 표본으로, 제작자 저장소의 약 177개 전체 상태 파일과 혼동 금지.
- v18에서 선정해 상세 검사한 **완성형 leaf 33개** 및 이번 12 상태 참조를 비교하여 아직 상세 검사하지 않은 새로운 **38개 완성형 leaf 모델**을 선별했다. `shutter/variant_*` 계열의 미측정 43개 경로는 **이번 38개 선정에서 제외**하여 향후 과제로 보존했다.
- **38/38개 모델 JSON을 제작자 원본에서 직접 읽고 Git blob SHA를 기록**했다. 모델 **38개 모두 자체 `elements`는 0개**이고 원형 템플릿을 부모로 상속한다. 추가로 **97건의 텍스처 override 슬롯**을 원본에서 직접 확인. 서로 다른 부모 원형 **21종** 가운데 **19종은 이전 33 leaf가 사용하지 않았던 원형**이라 v20에서 조사한 추가 원형을 실제 가구 상태에 연결하는 증거가 생겼다.
- 부모 원형의 각각의 `elements[*].faces` 선언, 원본 UV, leaf override와 부모의 기본 텍스처를 재귀적으로 해석해 새 38 모델의 **1,197개 면 인스턴스**를 계산했다. 그중 **1,192면은 모드 자체 PNG**, **5면은 `minecraft:block/dirt`**를 사용하며, 해석 불능 면 0. (1,197은 원형 중복 상속이 포함된 *면 인스턴스*, 서로 다른 1,197개 원본 작성 면이 아님.)
- 이번 38개 leaf에서 참조한 **고유 모드 PNG 경로 34종**을 제작자 원본에서 모두 다시 읽어 SHA 및 PNG 화소를 확인했다. 기존 v19 실측 **53종 안에 있는 PNG 20종**은 다시 검증했고 **이전에 없던 14종**은 새로운 원본 화소 표본으로 추가했다.
- 대상 **1,192/1,192개 모드 면 전부**에 대해 원본 PNG 사각형 **UV→정수 픽셀 좌표**, 이미지 크기 경계, PNG 바이트 SHA 및 해당 사각형 내부의 원본 **RGBA 색/알파 전수 픽셀**을 실제로 확인했다. 모든 면의 정수 픽셀/PNG 범위 검증 성공, 얼굴 키 `leaf+element_index+direction` 1:1 일치, RGB/알파 수 합계 일치.
- **Macaw's Furniture** 공식 [Minecraft 1.21.11 Fabric 3.4.2 배포](https://modrinth.com/mod/macaws-furniture/version/xhmciaUD)는 확인했지만, 이 환경에서는 `api.modrinth.com` DNS 응답 실패로 JAR 파일 바이트를 받지 못했다. **Macaw 원본 모델·UV·PNG 실측 0건**을 유지한다.

## 4. 근거가 있는 가구 디자인 관찰

- **의자 디자인은 등받이 재질/무늬의 변형과 같은 부모 형태를 분리한다.** `chair/oak_2`~`oak_11` 계열의 모델들은 원형 `chair` 혹은 `chair_tucked`를 참조하고, leaf는 `bottom/seat/back`의 텍스처 슬롯을 덮어쓴다. 서로 다른 형태 또는 실제 시각적 디자인 전체를 확인했다는 의미가 아니다.
- **연결 가구 부품이 실제 블록 상태에서 선택된다.** `oak_bench`, `white_sofa`, `white_curtain`, `oak_flower_box`의 블록 상태 적용 목록과 이번 실측 leaf·부모 원형을 연결했으며 left/right/middle/outer 같은 연결 상황에 대해 별도 JSON 모델/면이 존재한다. **실제 게임의 연결 판단 논리와 컬링**은 별도 검증이 필요하다.
- **커튼은 평면 요소와 부품별 UV/투명 PNG를 조합한다.** v20에서 `curtain_left_bottom` 원형의 0두께 요소를 확인했고 v21에는 그 leaf의 UV와 PNG 실제 화소를 연결했다. 단, 소스 PNG 알파만으로 투시 렌더 순서나 실제 게임 비주얼을 판정할 수 없다.
- **꽃상자는 바닐라 재질에 의존한다.** 이번 확장 5개 leaf의 흙 면 5개는 `minecraft:block/dirt`의 원본 PNG를 직접 읽은 것이 아니므로, Another 자체 모드 PNG 실화소 1,192면에 포함하지 않았다. 이전 v19 선정 꽃상자의 3면과 합해 현재 **Another 조사 leaf의 바닐라 dirt 의존 총 8면 미검증**이다.
- **블록 상태의 air 대체 모델을 가구로 세지 않는다.** 12개 상태 원본 중 2개 적용 레코드는 `minecraft:block/air`를 가리킨다. 이것은 기존 114종 모델 경로 안에 포함되지만 Macaw/Another 자체의 새로운 큐브 형태가 아니다.
