# 1-3 종료 후 인계

1-3의 고정 원본 정적 기하·상태 검증은 M1~M6 6/6을 통과했다. 모델과 상태의 고정 Git 경로 또는 JAR 해시는 [G 원본 재집계](G_SOURCE_RECOUNT.json), [F 모델 출처 원장](../F/MODEL_SOURCE_INDEX.csv.gz), [F SQLite](../F/furniture_research.sqlite.xz)에서 확인한다.

## 1-4 PNG·UV

- [텍스처 인계 원장](../F/1-3_TEXTURE_UV_HANDOFF.csv)에서 원본 경로와 파일 해시가 확인된 후보 1,996건의 픽셀·투명도·UV 영역을 검증한다. [v24 의자 우선 원장](../F/F_V24_CHAIR_PNG.csv)의 19건도 포함된다.
- 확정된 경로가 없는 8건은 출처와 적용 버전을 먼저 확인한다. 실제 면에 적용되지 않은 선언 슬롯 77건은 적용 근거를 확인한 뒤 실측 범위를 정한다.
- 선행 PNG 175개와 면 RGBA 4,113건은 실측 출처를 유지한다. 애니메이션과 런타임 렌더는 필요한 경우 별도 증거로 기록한다.

## 1-5 구조 비교

- [구조 비교 후보 52건](../F/F_1-5_COMPARISON_CANDIDATES.csv)을 C 기하·D 상태·E 표본 및 바닐라 근거와 대조한다.
- [E 반례 원장](../E/EXCEPTIONS.md)의 단일 모드 표본, 상태에 따른 차이와 재질 차이를 보존한다. 미해결 부모 48경로와 상태 모델 선택 4건은 게임 동작을 확인할 때 원본 경로별로 다시 판정한다.

실제 가구 모델링, 게임 동작 검증, 좀보이드 맵 변환은 각 작업의 실행 증거가 확보되면 별도로 기록한다.
