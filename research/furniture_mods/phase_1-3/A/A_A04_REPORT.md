# A-04 Handcrafted·Macaw 이전 근거 조사

Handcrafted 고정 원저자 트리에서 authored **120/120** 경로·SHA, generated 표본 **16/16** 경로·SHA 교차. v12/v16 generated 16 SHA도 일치. 원저자 JSON 본문을 직접 재해시한 표본 2/136(나머지 `FILE_SHA_ONLY`). 

Handcrafted 선행 PNG **24개**, UV RGBA 면 구역 **784개**, 두 모드 누적 PNG **175**, 면RGBA **4113**는 1-4 별도 분모. 이번 A 신규 PNG 픽셀 디코딩 0.

Macaw 공식 JAR 미확보 및 원본 모델 검증 0건은 **이전 연구 상태로만 기록**하며, 현재 원본 접근/현행 버전·라이선스 및 전체 모델 모집단은 1-3-B에 인계. Handcrafted 120 authored 모델을 전체 현행 모집단이라 단정하지 않음.

A4 선행 소관 교차대조: **일치**. 원본 JSON/PNG/JAR 재배포 없음.
