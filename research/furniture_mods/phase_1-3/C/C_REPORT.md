- 모델 파일 16,572개의 경로·크기·해시를 B 원장과 대조했다. 모델마다 부모 경로와 소스 해시를 연결했다. 최대 부모 깊이는 4, 부모 순환은 0건이다.
- 바닐라 부모는 Mojang 공식 1.21.1·1.21.11 클라이언트의 배포 SHA-1과 파일 크기를 확인하고 같은 버전에서 추적했다. 보조 JSON은 총 6경로이며, 바닐라 `block/cube`의 요소 1개와 면 6개가 계측 원장에 추가됐다.
- 가장 가까운 비어 있지 않은 `elements` 선언을 기하 제공자로 사용하고 모형별 자체·상속 요소와 면을 구분했다. 제공자 300경로에서 순서를 보존한 형상 지문 289종을 확인했다. 지문에는 좌표·요소 회전·면 방향을 넣었다. 모델별 적용을 반복해 세면 **요소 105,383개·면 592,312개 인스턴스**다.
- 선언 좌표, 회전 중심·축·각도, 두께, 0두께·역좌표·0~16 경계 초과를 기록했다. 회전 AABB는 각 요소의 8개 모서리를 변환해 계산했다. 가장 가까운 요소와의 AABB 간격도 기록했다. 양수는 분리, 0은 접촉, 음수는 AABB 겹침을 뜻한다. 경계상자 계산에는 blockstate의 X/Y 회전, 아이템 display 변환, 게임 충돌 정보가 적용되지 않는다.
- 공식 1.21.1 기본 역직렬화 규칙과 달리 Handcrafted의 `BlockElementMixin`은 각도·좌표 범위 제한을 해제한다. 기본 각도 범위를 벗어나는 선언 요소 100개는 4,238개 모델 경로에 적용되고, 기본 좌표 범위를 벗어나는 선언 요소 5개는 2개 모델 경로에 적용된다. Mixin의 Fabric·NeoForge 설정과 Crockery의 별도 아이템 렌더러 등록을 소스에서 확인했다. Java/Kotlin 175경로 및 Macaw 클래스 53경로의 해시 원장도 남겼다.
- 면 방향·텍스처 슬롯·명시 UV·UV 회전·컬링·tint 선언을 기록했다. 슬롯 미결합은 187개 모델 경로의 6,202면 인스턴스에 남았다. 이 수치에는 개별 leaf가 슬롯을 채울 수 있는 템플릿도 들어 있다. PNG 화소와 런타임 그리기는 후속 범위다.

## 예외와 인수인계

- Another 4개 경로의 부모 `lantern`은 기본 네임스페이스의 `minecraft:lantern`으로 해석되며, 공식 1.21.1 JAR에 그 경로의 모델이 없다. 자체 요소는 계측했고 해당 모델의 계보는 부분 해석으로 표시했다. `minecraft:block/lantern` 파일의 존재도 확인했으나 선언을 바꿔 해석하지 않았다.
- Macaw 44개 경로는 JAR에 없는 두 부모 `block/parent/desk`와 `block/parent/drawer_base`를 참조한다. 44개 경로에는 계보에서 얻을 수 있는 정적 요소가 없다.
- 정적 형상을 산출할 수 없었던 108경로는 위 Macaw 44개, 런타임에서 형상을 생성하는 아이템 계열 58개, 명시 요소가 없는 Handcrafted 기반 모델 6개다.
- [독립 검산](C_INDEPENDENT_AUDIT.json)에서 모델·부모 계보 16,572행과 요소 회전 경계상자 1,911행을 다시 확인했다. 경계상자는 꼭짓점 변환과 별도로 중심·반폭 계산을 사용했다. 오류는 0건이다.
- **C의 고정 모델 정적 감사 범위 완료.** D에서는 블록 상태 1,158경로를 모델 원장에 연결해 variant/multipart, X/Y 회전, 방향, 연결·다칸 조립을 검증한다. 전체 1-3 종료 게이트 M1~M6의 독립 승인 상태는 0/6이다.
