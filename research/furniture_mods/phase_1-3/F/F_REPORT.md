# 1-3-F 정규화 DB와 후속 분석 인계

기준은 GitHub `main`의 E 종료 커밋 `0897168655cd575075a44556e53e4a22e0d0fbc0`이다. B~E 및 선행 원장의 입력 Git blob SHA를 기준 트리와 대조했다. 세 모드의 모델 원문 16,572개를 다시 열어 B·C의 ID, 경로, SHA와 대조했다. 상태 JSON 1,158개는 B·D의 출처와 규칙 키를 대조했다.

| 원장 | 결과 |
|---|---:|
| 고정 모드 모델 / 보조 바닐라 모델 | 16,572 / 7 |
| 기하 원형의 요소 / 면 | 1,911 / 9,760 |
| 모델에서 상속을 적용한 면 인스턴스 | 592,312 |
| 블록 상태 / 상태 규칙 / 모델 선택 | 1,158 / 78,456 / 78,456 |
| 비교 표본 상태 / 모델 적용 | 47 / 52 |
| 텍스처 ID·Minecraft 버전 고유 조합 | 2,256 |

SQLite 무결성 검사와 외래키 검사를 통과했다. 별도 스크립트에서 B 모델, C 기하, D 상태·선택, E 표본·모델 적용과 DB·CSV의 키를 대조했다. 4개 미해결 모델 참조는 원본 대상 문자열과 함께 보존했다. 부모 누락 48경로와 E의 반례는 후속 검토 대상이다.

## 1-4 텍스처·UV

| 처리 | 건수 |
|---|---:|
| 원본 경로·SHA를 확보했고 면에서 참조하는 신규 검증 후보 | 1,996 |
| 선행 PNG 실측 원장과 SHA 일치 | 175 |
| 면에 적용되지 않은 선언 슬롯 | 77 |

v24 의자 39개의 면 바인딩을 다시 연결했다. PNG 24개 중 Another의 선행 151개 원장과 5개가 겹쳐 재사용 근거로 연결했다. 나머지 19개는 1,996개 검증 후보에 포함되며 우선 목록에 올렸다. 선행 PNG 175개와 면 RGBA 4,113건은 기존 측정 근거다. F의 신규 PNG 화소·면 RGBA 실측은 각각 0건이다.

## 1-5 구조 비교

9개 유형의 E 표본 47개 상태를 52개 모델 적용 후보로 인계한다. 상태 SHA, 모델 SHA, 기하 제공자 SHA와 구조 지문, 회전, UV 잠금, 텍스처 참조를 따라갈 수 있다. 접힘과 연결 상태의 차이, 동일 형상의 다른 텍스처, 단일 모드 침대·조명 범위는 [E 반례 원장](../E/EXCEPTIONS.md)을 함께 사용한다. 실제 게임 렌더와 충돌은 미검증이다.
