## 1. 직접 재현한 데이터 경로

1. v16에서 SHA 검증한 leaf **16개**, 원형 부모 **14개**의 원본 `faces[*].texture`, `textures` 참조 체인을 사용해 `face → #0/#1 → #wood/#cushion/#sheet → handcrafted:block/<PNG>`를 해결했다.
2. 정확한 선언 UV `(u1,v1,u2,v2)`를 원본 PNG 크기 `W×H`에 맞춰 `x=u×W/16`, `y=v×H/16`으로 환산하고 min/max로 사각형의 좌표 순서를 정리했다. 좌표가 정수이고 이미지 경계 내라는 v16 결과를 재확인했다.
3. 해당 파일을 공식 제작자 저장소의 **동일 고정 커밋**에서 GitHub Contents API로 다시 읽고 **Git blob SHA를 저장된 원본 PNG SHA와 비교**했다.
4. PNG IDAT/zlib DEFLATE, 행별 PNG 필터, RGB·RGBA·인덱스 팔레트 `tRNS`를 처리해 실제 RGBA 픽셀 배열로 복호화했다. 24개 파일을 **8개씩 3묶음**으로 측정했다.
5. 각 면의 **반개구간 `[x0,x1)×[y0,y1)`** 내 모든 픽셀에 대해 알파 0/1~254/255, 가시 색상 종류, 가시 RGB 평균을 집계했다. **면적 0 UV의 경우 비어 있는 샘플(0회)**로 분리했다. 역방향 UV와 `face.rotation`은 읽는 픽셀의 순서를 바꾸지만 **직사각형 내부 픽셀들의 집합 자체는 변하지 않으므로** 색상/알파 빈도의 집계와 구분했다.
6. 면 784행을 원본 모델·PNG·사각형 메타데이터 784행과 **leaf/요소 인덱스/면 방향 키**로 1:1 정합 검사했고, 중복·누락·바뀐 해시·좌표가 없는 것을 확인했다.

**중요:** 게임의 실제 텍스처 보간·텍셀 샘플링 위치·투명 혼합/알파 테스트·면 가림(culling)·조명·색 변화(tint)·모델 회전·블록 상태 조합은 여기서 재현하지 않았다. 여기서 `420면이 전부 불투명`은 **해당 면에 매핑된 PNG 영역의 원본 소스 픽셀이 모두 불투명하다**는 뜻일 뿐, 게임 화면에서 420면이 보인다는 뜻이 아니다.

## 2. 원본에서 배운 구체적인 표현 전략

### A. 전체 PNG의 투명도보다 실제 UV 영역이 중요

- `chair/cushion/black_cushion`: 원본 PNG는 64×64=4,096픽셀 중 **372픽셀만 가시(약 9.08%)**. 그러나 `oak_chair_black` 생성형의 쿠션 슬롯 면 **6면**, 합계 **328개의 UV 텍셀 사용 횟수는 모두 불투명**이다.
- `chair/cushion/white_cushion`: 같은 색상 규칙을 쓰는 다른 의자 2개 leaf에서 **12면, 656 텍셀 사용이 모두 불투명**이다.
- 설명: PNG에서 남는 투명 부분은 **사용하지 않는 아틀라스 공간**일 수 있다. `이 텍스처는 90%가 투명이니 의자 면도 대부분 비어 있다`는 결론은 원본 측정과 충돌한다.

### B. 아예 보이지 않는 재질을 텍스처로 지정하는 경우

- `bench/cushion/none_cushion`: 완전 투명 PNG가 **6면**의 UV 영역으로 참조되고, 영역에 포함된 **248 텍셀 사용 모두 알파 0**.
- `shelf/overlay/none`: 완전 투명 PNG에 연결된 **6면 중 2면은 비영 UV(512 텍셀 모두 알파 0)**, 나머지 **4면은 0면적 UV**다.
- **실측:** 구조에 면이 남아 있어도 실제 소재 텍스처에서 알파 0으로 가릴 수 있다는 구현 방식. **추정 금지:** 이것이 성능 최적화나 정확한 게임 렌더링 픽셀 제거량을 증명하지는 않는다.

### C. 동일 모드에서 다른 가구의 면별 알파 전략 차이

- `couch/cushion/white_cushion`에 연결된 **36면** 중 원본 UV 전체 불투명 **9면**, 전체 투명 **8면**, 혼합 **19면**(비영 UV만).
- `couch/oak_couch`에 연결된 **36면**은 전체 불투명 **8면**, 전체 투명 **9면**, 혼합 **19면**.
- `table/sheet/white_sheet`에 연결된 **120면** 중 **80면이 UV 면적 0**이고, 남은 40면은 불투명 6·완전투명 2·혼합 32. 원본 도형 면이 정의돼 있다는 것만으로 해당 면에 넓은 시각적 표면이 그려진다고 해석할 수 없다.
- 이러한 결과는 가구 형태별로 **UV 배치와 실제 페인트된 이미지 영역을 함께 확인**해야 함을 보여준다.
