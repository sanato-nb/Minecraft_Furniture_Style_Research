## 1. 이번 단계에서 실제 읽은 원본과 진행도 분모

- 이전 v11~v22에서 이미 분석한 블록 상태 12개와 겹치지 않는 **새 블록 상태 JSON 10개를 실제 고정 원본에서 열고 각각 Git blob SHA 확인**. 선택 범위는 `birch_chair`, `spruce_chair`, `birch_bench`, `spruce_bench`, `red_sofa`, `blue_sofa`, `red_curtain`, `birch_drawer`, `spruce_table`, `birch_flower_box`.
- 위 원본 10개에 **`variants`/ `multipart` 적용 레코드 386건**, **고유 모델 경로 92개**가 있었다. 이 92경로는 Another 모드 모델 **91개 + `minecraft:block/air` 1개**이다. 원본 상태 자체의 *응답별 모델 적용 기록*과 고유 모델 JSON 경로를 혼동하지 않았다.
- 이번에는 모든 상태 JSON의 SHA·상태 적용 수를 조사했지만, **92개 경로의 모든 모델 PNG를 전수 실측한 것은 아니다.** v18에서 이미 원본 확인된 `chair/birch_1` 1개를 재사용하고, 새 모델 중 비(非)의자 가구 8종 상태의 모든 Another 모델 leaf **47개**, 의자 비교 대상으로 자작나무/가문비나무 등받이 2번 일반형·밀어 넣은 형태 **4개**를 합해 총 **신규 51개**를 골라 원본 JSON을 직접 다시 읽었다. 따라서 **아직 원본 모델 JSON을 직접 검사하지 않은 추가 의자 leaf는 39개**. `minecraft:block/air`는 가구 모델이 아니다.
- 10개 상태는 전체 제작자 저장소(당시 v11 Git tree 조사)의 블록 상태 **177개 중 새 10개**. 이전 12개를 합쳐 직접 본 상태 JSON은 **22/177개(약 12.43%, 당시 트리의 파일 수 기준)**. 모드의 모델·텍스처·게임 렌더 연구 완료율과 구별한다.

## 2. PNG 경로 해결 및 소스 원본 픽셀 확인

- 51개 leaf의 원형 face 1,127개를 상속한 뒤 각 face의 `uv`와 텍스처 슬롯을 원본에 따라 해결. 모드 자체 PNG **1,119면**, `minecraft:block/dirt` **8면**, 텍스처 경로 미해결 **0**.
- 1,119 모드 면이 참조하는 서로 다른 PNG **51종을 제작자 고정 커밋에서 실제 PNG 바이트 재조회/디코딩**했다. v19~v22에서 원본 화소를 확인한 **9종은 SHA·픽셀 분포 교차 검증**, v23에서 처음 확인한 **42종은 원본 PNG 전체 화소 직접 디코딩 및 Git blob SHA 기록**. PNG 크기는 **16×16 49종**과 **64×64 2종**.
- 모드 소유 **1,119면의 원본 UV**를 해당 PNG 픽셀 좌표로 변환하여 정수 화소 경계·원본 PNG 범위 내 여부와 사각형 내부 모든 픽셀의 RGB/알파 통계를 직접 읽었다. **1,119/1,119 실측**, 면 고유키 중복/누락 **0**. `minecraft:block/dirt` 의존 8면은 이 측정에서 명시적으로 제외했다.
- UV 역방향 선언 **347면**, face의 UV 회전 선언 **73면**을 원본에서 확인. 회전/반전으로 무늬가 실제 화면에 어떻게 출력되는지, 가려지는지, 빛이 반영되는지는 인게임 검증이 남는다.

## 3. 동일한 형상과 다른 마감재: 재현 가능한 정량 비교

[선택된 가구 유형/소재별 원본 모델·UV·알파/색상 비교 CSV](new_51_material_variants_pairwise_source_comparison.csv)에는 다음 세 비교의 실제 원본 면 인스턴스 단위 대응을 저장했다.

- **빨간 소파 vs 파란 소파:** 각 6개 leaf에서 **229쌍 면의 부모 원형·원시 UV 선언 229/229 일치**, UV 영역 알파 분포도 229/229 일치. **159쌍은 정확히 같은 PNG 경로를 공유**, **70쌍은 다른 텍스처 경로**를 사용한다. RGB 평균 색의 쌍별 유클리드 거리 평균 약 **53.84**(면 쌍 균등 가중)로 측정됐지만, 이는 실제 렌더 화면 색차가 아닌 원본 PNG 영역 통계다.
- **자작나무 벤치 vs 가문비나무 벤치:** **116쌍의 부모 원형·UV 및 알파 분포가 전부 일치**하고, **116쌍 모두 서로 다른 PNG 경로**를 사용한다. 같은 형태·UV에 서로 다른 목재 질감 PNG를 입히는 소스 패턴을 확인했다.
- **자작나무 의자 vs 가문비나무 의자(등받이 2번 및 tucked):** **92쌍 모두 부모 기하·원시 UV 및 면 알파 분포가 일치**하지만, **92쌍의 PNG 경로는 모두 다르다**. 같은 의자 기하를 목재별로 재사용하는 근거다.
- 각 사례는 이 51개 선정 leaf의 **원본 구조가 같다는 정량 결과**이지, 소파 색이 항상 모든 가구에서 동일한 UV 전략을 사용한다거나 사용자 눈에 똑같이 렌더된다는 전체 모드 일반화가 아니다.
- **서랍 open 모델의 2단계 상속**, **벤치의 multipart 연결**, **커튼의 공기 모델 참조**는 원본의 선택적 상속/상태 전략으로 남겼다. 게임에서 실제 부품이 언제 연결되는지는 블록 상태·게임 논리와 렌더링 검증이 필요하다.
