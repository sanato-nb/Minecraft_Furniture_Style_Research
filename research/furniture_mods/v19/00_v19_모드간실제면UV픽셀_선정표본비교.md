# v19 — 서로 다른 선정 표본에서 관찰한 Another Furniture와 Handcrafted의 가구 면/PNG 대응

> 직접 원본 기반 수치: [Handcrafted v17 감사 JSON](../v17/v17_pixel_region_summary.json), [Another Furniture v19 감사 JSON](v19_original_png_face_rgba_audit.json), [교차 비교 수치 CSV](another_vs_handcrafted_face_rgba_selected_cohorts.csv). **완성형 모델 33개 vs 생성형 모델 16개**라는 서로 다른 표본 구성이며 두 모드의 전체 모집단 비교나 제작 품질 평가가 아님.

| 부모를 상속해 계산한 전체 면 인스턴스 | 807 | 786 |

*표의 퍼센트는 표본 내 ‘모드 PNG를 참조하는 면 인스턴스’를 분모로 했다. 실제 화면상 보이는 표면의 비율이 아니며, 재사용한 모델과 PNG 면의 중복이 포함된다.*

## 근거로 지지되는 후보 스타일 규칙

1. **공통 원형/부모로 입체 형상을 정의하고, leaf에서는 재질 슬롯만 바꾸는 방법이 실제로 사용된다.** Another v18의 33 leaf는 자체 `elements`가 0개이고 원형 30개의 요소를 상속한다. Handcrafted v16 16 leaf도 자신만의 `elements`가 0개였다. 단, leaf가 기존 모델을 참조하는 소스 조직 구조는 모든 모드에 일반화할 수 없다.
2. **실제 면에서 사용하는 UV 사각형을 검사해야 색/알파를 제대로 판단할 수 있다.** Another 53 PNG는 원본 파일 전체 **17,408 픽셀 중 11,536가 가시(66.27%)**이지만, 선정 804면에서 실제 참조한 **32,531 텍셀 사용 중 31,545 (96.97%)가 가시**였다. 전체 PNG에 투명한 여백이 많아도 면이 참조하는 영역은 대부분 불투명할 수 있다. *서로 다른 중복 가중치 기준을 비교한 것이므로 전체 이미지와 실제 UV 사이의 동일한 샘플링 분포를 뜻하지 않는다.*
3. **면이 존재한다고 반드시 실색 사각형으로 칠해지는 것은 아니다.** Handcrafted 표본에는 0면적 UV 172면과 알파0 사각형 47면이 확인됐고, Another 표본에는 0면적 UV 4면·전부 알파0 사각형 0면이다. 이것은 각각 소스 데이터의 표현 양식이지 3D 렌더 결함 또는 의도적 성능 최적화의 증거는 아니다.
4. **UV 반전·텍스처 공유는 시각적 면의 형태를 좌우하므로 별도로 다뤄야 한다.** Another에서 reversed UV 221면/804 모드 면, Handcrafted 251면/784 모드 면. 실제 화면에서 방향/안쪽/바깥쪽의 시각 효과를 단정하지 않고 원본 선언을 보존한다.
5. **가구 표현의 선택을 모델링 규칙으로 승격하기 전 인게임 검증이 필요하다.** 3D 바운딩박스 원시 확장, 블록 상태 연결, 조명/컬링, 텍스처 필터링, 모델/UV 회전, 투명도와 블록 상태별 표시 방식은 현재 소스 PNG 영역 분석만으로 검증되지 않는다.
