### 원본 PNG 53종 실화소

- v13 기존 **12종**, v18 신규 **12종**, **이번 v19 신규 29종**으로 합계 **53종**.
- **52종**은 16×16 원본 PNG, **1종 `bench/oak`**는 **64×64 PNG**. 이를 일률적으로 16×16인 것으로 가정하지 않고 `x=UV_u×PNG_width/16`, `y=UV_v×PNG_height/16`으로 좌표를 계산했다.
- 53개 원본 PNG의 전체 **17,408픽셀** 가운데 알파 255 **11,536픽셀**, 알파 0 **5,872픽셀**, 부분 알파(1~254) **0픽셀**. 고정 Git blob SHA/원본 치수/이전 기록의 전역 가시·투명 수치를 교차 대조했다.
- `sofa/wood_2`, 일부 바닥 텍스처 등 **4비트 인덱스 팔레트 PNG**를 포함하고, `RGBA`, `RGB`, `8비트 인덱스 팔레트` 등 제작자 원본 그대로 해독했다. 픽셀 원본은 저작권으로 재배포하지 않았다.

### 원형 30종 → 완성형 33개에 적용한 실제 면

- 원형 30종의 독립 명시 face 선언은 v18에 **709면**으로 기록됨. 일부 원형이 두세 leaf에서 반복 사용되므로 **33 leaf에 상속 적용한 면 인스턴스는 807개**.
- 이 가운데 **Another 자체 PNG를 참조하는 804면** 전부 UV 사각형이 원본 PNG의 **정수 화소 좌표 경계에 맞고**, **사각형 전체가 PNG 경계 내**였다. UV 면적이 0인 면 **4면**, 비영 면 **800면**.
- **모드 소유 804면 가운데 역방향 UV 221면** (바닐라 dirt 참조 3면을 포함한 전체 선언 역방향은 224면). 역방향/회전은 픽셀 순서와 표면 방향에 영향을 줄 수 있으므로 원본 값이 CSV에 보존돼 있다.

## 3. 가구 스타일에 기여하는 실측 근거

**(A) PNG 전체의 투명한 배경과 실제 사용 UV 영역을 구별해야 한다.** 이번 선정 원본 PNG 53종의 파일 전체 가시 비율은 **11,536/17,408=66.27%**, 반면 804개 면의 UV 사각형에서 재사용을 포함해 집계한 가시 텍셀 사용 비율은 **31,545/32,531=96.97%**다. 일부 PNG의 투명 배경은 실제로 면이 참조하지 않는 영역일 수 있다. 두 비율은 표본 가중치가 다르므로 동일한 확률적 수치로 비교하거나 실제 렌더링 화면 비율로 해석하지 않는다.

**(B) 적은 수의 PNG를 재질 용도별로 공유한다.** 의자 좌석/등받이/프레임, 소파 나무 프레임/쿠션/등판, 꽃상자 흙/나무 테두리 등을 서로 다른 재질 참조로 구분하고, 33 leaf가 동일 원형을 상속한다. v18에서 실제 원본 검증한 **재질 override 사용 면 588개와 원형 기본 재질 유지 면 219개**의 전략과 연결된다. 53 고유 PNG 경로는 **v18에서 선정한 33개 leaf의 면이 참조하는 경로**라는 범위만 보증한다.

**(C) 알파/UV 전략은 가구와 모드마다 다르다.** Another 표본에서는 비영 UV 중 완전 투명인 사각형이 0개이고 면적 0 UV가 4개다. Handcrafted v17 선정 표본에서는 각각 **완전 투명 사각형 47개, 면적 0 UV 172개**가 관찰됐다. 후자의 의자·쿠션·선반과 전자의 의자·램프·차양 등이 **동일한 가구/모델 표본이 아니라는 점** 때문에 두 모드의 전체 제작 스타일 차이 또는 우열을 단정하지 않는다. [동일 지표 정의의 비교표](another_vs_handcrafted_face_rgba_selected_cohorts.csv).

**(D) 면 UV 방향은 실제 렌더링 확인이 남는다.** 모드 면 인스턴스 중 Another는 221면, Handcrafted는 251면의 UV 역방향 좌표가 있었다. UV 픽셀 영역 안의 **색상/알파 분포**는 사각형의 픽셀 순서가 뒤집혀도 동일하지만, 실제 무늬 방향·텍스처 보간·Cull·조명 등은 게임에서 추가 검증해야 한다.
