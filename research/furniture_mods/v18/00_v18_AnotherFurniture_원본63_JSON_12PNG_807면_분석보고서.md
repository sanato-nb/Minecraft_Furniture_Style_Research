## A. 이번 실제 원본 재검증

1. 제작자 GitHub의 **고정 커밋에서 완성형 leaf 모델 JSON 33개**를 직접 가져와 파싱했다. 과거 v11 CSV의 **33개 Git blob SHA, 부모 참조, 텍스처 슬롯 수와 전부 일치**한다. 생성형 33개 모두 자체 `elements`를 추가하지 않은 **원형 상속+재질 재지정**이다. 완성형 모델의 **93개 텍스처 슬롯**을 실제 경로로 새로 수집했다. 기존 v11 CSV는 슬롯 개수만 보존하고 경로 내용을 남기지 않았다.
2. 이 33개 leaf가 가리키는 **서로 다른 원형 템플릿 30개**의 제작자 JSON을 같은 고정 커밋에서 다시 직접 읽어 이전 v11 모델 CSV의 blob SHA와 **30/30 일치**시켰다. 원형 30개는 각각의 `elements[*].faces[*].texture` 지정 수가 기존 v11 `faces` 수치와 맞았다. 30개 원형의 명시적 면 선언은 **709면**이며, 원형별 면 슬롯 참조 집계는 **104그룹**이다.
3. **원본 JSON 63개를 직접 재접근**했고, 33개 leaf에 템플릿 30개의 각 면을 적용한 인스턴스 기준으로 **807면**의 `face → #texture_slot → leaf override or template default → 최종 경로`를 해석했다. **113개의 leaf×raw-face-slot 그룹**, **미해결 참조 0**, **모드 자체 PNG 경로 연결 804면**, **Minecraft 기본 흙 텍스처 연결 3면**이다.
4. 3개의 Minecraft 기본 텍스처 참조는 모두 꽃상자 `flower_box/oak`, `flower_box/oak_middle`, `flower_box/oak_attached`의 `#dirt`이다. `oak_middle` 소스는 `block/dirt`로 네임스페이스를 생략했으므로, Minecraft 리소스 경로 해석 규칙에 따라 `minecraft:block/dirt`로 **정규화하되 원문 값도 보존**했다. 이 3개는 이번에 Minecraft 공식 PNG 픽셀을 확인한 것이 아니다.
5. **완성형 leaf의 텍스처 재지정이 실제로 쓰이는 면은 588면 인스턴스**, 템플릿의 기본 재질을 유지해 쓰는 면은 **219면**이다. 덮어쓰기 슬롯 93개가 모두 동일한 면 수를 차지하는 것은 아니다.
6. 이 807면은 **고유 원본 모델 면 807개가 아니라 33개 leaf 각각에 부모 템플릿을 적용한 인스턴스 수**다. 같은 의자 템플릿을 다른 목재에 적용하면 해당 면 수가 다시 집계된다. 동일한 총면 수를 모델별 품질 우열로 사용하지 않는다.

## B. 이전에 없던 Another Furniture PNG 12종의 원본 픽셀 직접 검사

- 면 참조 빈도가 높은 텍스처 경로부터, **v13에서 이미 픽셀을 조사한 12개를 제외**하고 우선순위가 높은 새 PNG **12종**을 제작자 고정 원본 커밋에서 바이너리로 직접 읽었다.
- **12/12개 PNG 해독 완료**, 전부 **16×16**, 총 **3,072개의 원본 픽셀**. 이 중 **가시(알파 255) 2,156**, **완전 투명(알파 0) 916**, **부분 반투명 0**. 가시/투명은 파일 원본 픽셀 수이며 해당 텍스처를 사용하는 면의 최종 화면 픽셀이 아니다.
- `sofa/wood_2`는 기존 v17 8비트 전용 PNG 해독기에서 **4비트 팔레트 PNG**라 첫 시도에 실패했다. 이번에 [4비트 팔레트 지원 복호화기](../../../scripts/v18_png_rgba_4bit_helper.js)를 작성하여 **16×16 전부 256픽셀 불투명**을 실제로 디코딩했으며, 실패 상태 기록도 정상 값으로 갱신했다.
- 12개 중 `stool/legs`는 가시 **28/256픽셀(10.94%)**이고 `sofa/wood_2`는 **256/256픽셀(100%)**이다. 원본 텍스처 전체의 알파 분포만 보고 어느 면이 실제로 그려질지는 판단할 수 없다.
- 새 실측 텍스처 12개는 **453면 인스턴스의 재질 경로**로 참조된다. 이전 v13 실측 12개는 230면 인스턴스에서 참조된다. 둘을 합해 Another Furniture 원본 PNG **24종/경로 기준 53종 중 24종(45.28%)**의 실화소 근거를 확보했고, **29종은 원본 경로만 확인되어 픽셀 미측정**이다.
- 기존 Handcrafted **24종** 및 Another Furniture **24종**으로 이 연구 저장소의 **모드 PNG 고유 실화소 표본 합계는 48종**. 이는 모델, 마인크래프트 전체 텍스처 전수나 인게임 검증 완료를 뜻하지 않는다.

## C. 새 관찰로부터의 조건부 디자인 원칙

- **재질 교체와 형태 재사용:** 완성형 33개가 원형 템플릿 30개를 부모로 참조하며 자체 요소 0개를 유지한다. 실제 의자·벤치·소파·등·꽃상자 등에서 공통 구조+재질 지정 패턴이 존재한다. `chair/oak_1`의 면 46개 가운데 `bottom` 29면, `seat` 5면, `back` 12면처럼 **역할별 텍스처 슬롯이 구조를 분리**한다.
- **외형 분업:** leaf 재정의 슬롯만 실제 면에 쓰이는 것이 아니라, 템플릿 기본 목재·꽃상자 흙·램프 부품 텍스처를 그대로 남긴다. 807면 중 588면은 leaf override를, 219면은 template default를 사용한다.
- **투명 이미지와 3D 면의 관계:** 일부 텍스처는 대부분 투명하나 일부는 완전히 불투명하다. 실제 **면별 UV 사각형 내부의 알파/색상 검사** 없이는 알파 PNG 전체 통계로 모델의 가시 부위를 결론 낼 수 없다. v17 Handcrafted에서 확인한 방식과의 유사한 연구 방향이지만 **같은 표본 모집단의 동일한 제작 스타일이라는 결론은 아니다**.
- **원본 네임스페이스 확인:** `block/dirt` 같은 생략 표기는 `minecraft:` 네임스페이스 규칙과 연결되므로, 모델 면 재질 추적에서는 반드시 raw 값과 정규화값을 구분한다.
