# v13 — 가구 모드 PNG 실화소 및 UV 좌표·픽셀 격자 분석

- **기록 날짜:** 2026-11-12 (Asia/Seoul)
- **상위 목표:** 마인크래프트 가구의 디자인을 재현 가능하게 이해하는 1단계 학습
- **진행 항목:** 04 가구 모드 텍스처·UV **실측**, 03 모드 모델 구조의 추가 검증
- **직접 입력:** 제작자 공개 GitHub에서 읽은 PNG 24개와 모델 JSON 13개
- **저작권:** 모델·텍스처 원본을 이 저장소에 복사하지 않는다. 공개 출처 경로·SHA와 **측정 수치**만 기록한다.
- **버전:** Another Furniture Minecraft 1.21.1 계열 / Handcrafted 소스 `1.21.x`; 바닐라 연구는 1.21.11 (서로 다른 버전을 임의로 통합하지 않는다)

## 1. 이전 체크포인트와 이번 작업 차이

v11과 v12는 **PNG 헤더(IHDR 등) 24개**만 검사했으므로, 실제 투명 픽셀·색상 개수·밝기 분포는 미측정이었다. v13은 **PNG 원본의 압축 IDAT를 해제하고 PNG 필터를 역적용해 전체 화소를 직접 디코딩**했다. 색상 유형 2(RGB), 3(팔레트+tRNS), 6(RGBA)을 처리했다.

출처의 **Git blob SHA-1과 원본 크기**가 v11/v12의 해시 및 해상도 기록과 모두 일치했다.

| 대상 | 실화소 분석 PNG | 실제 모델 UV 조사 |
|---|---:|---:|
| Another Furniture | **12/12개** | **6개 모델** |
| Handcrafted | **12/12개** | **7개 모델** |
| **합계** | **24/24개** | **13개 모델, 571면** |

**이번 완료의 분모는 이전에 고른 표본 24개 및 13개 모델에 한정**된다. 각 모드 전체 텍스처 전수 조사나 인게임 UV 확인 완료가 아니다.

### 색상 수와 명암 계산 정의

- `unique_rgba`: **알파값이 0보다 큰** 화소가 가진 서로 다른 RGBA 튜플 수. 투명 화소의 RGB는 집계 제외.
- `luminance`: 알파가중 평균 `0.2126R+0.7152G+0.0722B` (0~255). **감마 선형화하지 않은 sRGB 바이트값 기준**; 물리 조도나 실제 게임 엔진 조명값이 아니다.
- `coverage`: `(alpha>0인 화소 수)/(PNG 전체 화소 수)`의 백분율.
- `bounds`: 한 PNG 안에서 보이는 화소의 최소/최대 x,y. **UV가 사용한 영역이나 렌더링된 면의 외접 범위와 동일하지 않다.**
- `top_colors`: 알파>0인 화소에서 가장 빈도가 높은 RGB 목록 (알파는 별도로 집계).
- **관찰:** 이번 24개 표본에서는 반투명 화소 없이 이진 알파만 사용. **추론:** 가구 스타일 텍스처에 선명한 픽셀 경계가 선호되는 사례로 볼 수 있으나, 전 모드 또는 전체 PNG의 보편 규칙으로 확정하지 않는다.

## 3. 모델 UV가 실제 픽셀 격자에 정렬되는지 확인

[모델 13개 UV 좌표·픽셀 정렬 실측 CSV](uv_to_pixel_alignment_13_models.csv)

| 항목 | 결과 |
|---|---:|
| 모델 JSON 실제 직접 읽기 | **13개** |
| 명시적 UV가 있는 face | **571면** |
| 참조 텍스처 시트 크기를 적용한 뒤 **픽셀 경계에 정렬된 face** | **571 / 571 (100%)** |
| UV 좌표가 `0~16` 범위를 벗어나는 face | **0** |
| UV 좌표의 u/v 시작·끝 순서가 역방향인 face | **190** |
| UV 사각형 가로/세로 길이가 0인 face | **64** |

**픽셀 정렬 계산:** Java 블록 모델 UV는 `0~16` 좌표계이고 실제 PNG 크기는 16·64·128픽셀로 다르다. 따라서 텍스처 픽셀 좌표는 `uv×(texture_width/16)`, `uv×(texture_height/16)`로 변환한다. 각 face의 네 경계 좌표가 **정수 픽셀 위치**에 놓이면 정렬 판정한다. 소수점 UV도 `0.125×8=1픽셀`처럼 정확히 정렬될 수 있다.

**반드시 구분:** `uv_flipped_faces`는 음수 방향으로 지정된 UV 폭·높이를 뜻하며 **의도된 미러링일 수 있다**. `uv_zero_area_faces`는 입력 JSON 상 UV 사각형의 면적이 0인 경우이고, 렌더링의 가시성/오류 여부까지 뜻하지 않는다. 원본 모델 전체의 텍스처 참조·연결 여부도 게임 엔진에서 검증되지 않았다.

### 두 모드 스타일의 중간 가설

1. **정수/분수 좌표 차이는 픽셀 격자를 벗어난다는 뜻이 아니다.** Handcrafted 128×128 시트의 0.125 UV 단위는 실제로 1픽셀에 대응한다.
2. **상세 형상 표현 방식은 다양하다.** Another Furniture의 기존 템플릿은 연결형/부품 조합이 두드러졌고, Handcrafted는 회전된 큐브가 여러 모델에 나타났다. v13 픽셀 실측은 이와 다른 축의 근거다.
3. **색상 수가 적은 픽셀 아트는 두 모드 모두에서 확인됐지만**, 모드 전반의 색조·재질 규칙을 결론내리기 전에 목재 종류·쿠션 색·형태별 더 큰 표본이 필요하다.

## 4. 검증 등급 / 아직 하지 않은 일

**검증됨:** 고정 Git 커밋 원본 PNG 내용 직접 해석, 기존 SHA 일치, 각 표본의 알파·색상 계량, 모델 JSON UV 수치 계산.

**추가 검증 보류:** 실제 모드가 게임에서 각 모델에 바인딩하는 정확한 텍스처, UV가 원본 PNG에서 읽는 면별 화소의 전체 구성, 인게임/Blockbench 미리보기, 모드 전체 텍스처 및 원형 전체 UV 검수.

**Macaw's Furniture:** 원제작자의 공식 JAR/원본 모델 에셋 직접 확인이 이전과 같이 미완료, 모델 실측 0건. 불확실한 제3자 저장소를 원본으로 취급하지 않는다.

**기존 바닐라 공식 JAR 직접 대조 및 인게임 렌더 검증**도 미완료. **단계 최종 완료 0/5**, 04의 **표본 24 PNG 실화소 분석 + 13 모델 UV 571면**은 수행했다.
