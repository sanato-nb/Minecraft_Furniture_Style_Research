### 제작자 원본 대조 절차

1. v21의 [12 블록 상태 802 application/114 고유 모델 경로 기록](../v21/another_12_blockstates_applied_models.csv)에서 `shutter/variant_1~11/oak_{single,top,bottom,middle}` **44개 원본 모델 경로** 추출.
2. 이 중 v18이 이미 실제 읽어 검사한 `shutter/variant_1/oak_single` 1개를 중복 신규 카운트에서 제외하고 **43개 원본 JSON을 제작자 고정 커밋에서 각각 직접 읽음**. 각 SHA 저장.
3. 43개에 원형 4종의 [v20 제작자 고정 원본 69 템플릿의 face](../v20/another_69_templates_1362_original_faces.csv)를 결합하여 **214면**에 정확한 leaf texture slot을 재귀 적용. **0개 미해결**. UV 반전 **75면**, face UV 회전 **42면**, UV 0면적 **0**.
4. 43 고유 PNG 경로의 제작자 원본 PNG 바이트를 각각 다시 읽어 RGBA 해독·Git blob SHA 기록. 모두 **16×16 RGBA 8비트**, 픽셀은 **43×256=11,008개**.
5. face `uv`는 원본 Minecraft 모델 UV 단위이므로 `pixel_x=UV_u×PNG_width/16`, `pixel_y=UV_v×PNG_height/16`. 모든 **214면** 원본 사각형이 **정수 픽셀 경계에 정렬**되고 실제 PNG 범위 안임을 확인한 뒤, UV 영역 안의 RGBA 모든 픽셀을 검사.
6. 214 고유 face key(leaf/element_index/direction)와 214 source declaration은 1:1 대응, 픽셀 불투명+투명 합계는 모두 원본 UV 픽셀 영역 너비×높이와 일치. [v22 원본 감사 JSON](v22_shutter_source_original_complete_audit.json)으로 재검산.

## 3. 11가지 셔터 패턴의 재질·모델 구조

- 11개 `variant_1`~`variant_11` 모두 **single/top/bottom/middle**의 4가지 모델 역할을 원본 12 blockstate 기록에서 갖는다. v21 이전에 읽은 variant 1의 `oak_single`을 제외한 이번 신규 43개의 구성은 **variant 1에서 3개**, variant 2~11 각 4개다.
- 원본 4개 **부모 템플릿은 변하지 않고**, 각 leaf가 `middle`과 `single/top/bottom`의 슬롯을 바꾸어 텍스처 경로를 결정한다. 이렇게 반복되는 동일 구조에 11가지 셔터 무늬/재질 리소스를 배치하는 패턴을 실제 확인함.
- 이번 43 leaf는 원본 블록 모델 PNG **43개 경로**를 참조하며, v18에서 이미 읽은 `shutter/variant_1/oak_single`이 사용하던 옛 PNG와 겹치는 경로는 1개다. 새 PNG **42개**는 실제 16×16 전체 픽셀을 읽은 근거로 count한다.
- v22는 실제로 사용한 UV 좌표와 PNG 화소를 계량한 **정량 분석**이지 11가지 무늬의 디자인 주관적 명칭, 실제 렌더의 좌우 방향/애니메이션, Minecraft와의 1:1 시각 비교를 수행한 것은 아니다.

## 4. v21 이전 조사 범위와 연결한 완성도

v21에서 원본 블록 상태 12개의 802 application 기록에 나타난 **서로 다른 모델 경로는 114개**였고, 이를 실제 원본 기준으로 다시 분해하면:

| 경로 종류 | 고유 참조 경로 수 | 현재 증거 |
|---|---:|---|
| Another Furniture 실제 **완성형 leaf** | **111** | v18 원본 선정에서 **30개**, v21 신규 **38개**, v22 신규 **43개** → **111/111 경로 원본 JSON 증거** |
| Another Furniture **template 직접 참조** | **2** | 기존 v20 원형 69 SHA 직접 검증에 포함 |
| `minecraft:block/air` | **1** | 바닐라 공기 모델 경로만 기록; 바닐라 1.21.11 공식 JAR 실측은 아직 아님 |
| **합계** | **114** | |

**12개 블록 상태 표본이 참조하는 Another 모델 경로 113/113개는 제작자 원본 JSON 근거를 확보**했다. 단, 상태 파일과 전체 모델은 이 12/177개 표본을 훨씬 벗어난다. 기존 v18 완성형 33개 가운데 3개는 이 12개 상태에 나타나지 않으므로, 그 3개도 합해 직접 연구한 완성형 누적은 **114개**다(111+3). 이는 114개의 *블록 상태 고유 경로*와 단위가 우연히 같지만 서로 다른 지표다.
