## 2. 16 생성형 모델 × 14 부모 원형 — 원본 JSON 직접 참조

원본 leaf의 `parent`를 따라 부모의 `elements[*].faces[*].texture` 값을 조회하고, 부모 `textures`의 간접 참조(`#0 → #wood` 등)를 leaf `textures`의 구체적 텍스처 경로로 재귀 해결했다. 그 결과를 v13과 이번 v16에서 **원본 픽셀을 직접 측정한 PNG 24종의 크기·Git SHA**와 결합했다.

| 검증 단위 | 실제 결과 |
|---|---:|
| 직접 확인·SHA 일치 원본 JSON | **30개** = 16 leaf + 14 parent |
| 직접 다시 확인한 leaf texture 슬롯 | **51건** |
| 상속된 부모 `faces`를 16 leaf에 적용한 **면 인스턴스** | **786개** |
| Handcrafted 원본 PNG 경로·SHA·해상도까지 연결된 면 인스턴스 | **784개** |

| PNG 크기 기반 환산 UV 픽셀 좌표가 정확히 정수 격자에 정렬된 면 | **784/784** |

| 전체 면 인스턴스의 **역방향/뒤집힌 UV** | **251개** |

**주의:** 786은 원본 기하 면의 독립 개수가 아니라 **16개 생성형 모델에 부모의 면을 각각 적용한 누적 면 인스턴스 수**다. 같은 부모 원형을 여러 leaf가 공유해 중복 집계된다. 또한 원본 `faces`의 숫자 좌표를 이미지 너비·높이/16으로 환산한 결과의 정수 격자 정렬과 범위 내 위치를 확인한 것이다. **실제 그 사각형 안의 색·알파가 어떻게 나타나는지, UV 회전·블록 상태·컬링·인게임 조명과 합성한 결과까지 검증한 것은 아니다.**

두 Minecraft 기본 텍스처 의존 면은 `oak_shelf_left_1`에서 나온다. 이번 연구는 **공식 1.21.11 client.jar**를 읽지 않았기 때문에 해당 두 면의 실제 원본 텍스처 픽셀을 검증했다고 기록하지 않는다.

## 3. 관찰에 근거한 모델링 스타일 학습 — 잠정 원칙

1. **형태와 재질 변형을 분리하는 구조:** 의자 `chair/chair`의 원형은 **13요소, 78면**을 정의하지만, `oak_chair_white`, `oak_chair_black`, `cherry_chair_white`는 **자체 요소 0**이고 `wood`·`cushion`의 실제 이미지 경로만 바꾼다. 같은 형태로 다양한 목재/색상 버전을 만들 때 **공통 지오메트리 + 가벼운 leaf JSON** 방식이 실제 사용된다.
2. **면→슬롯→재질의 단계적 연결:** 예를 들어 `chair/chair`는 `#0` 면 72개를 `#wood`에, `#1` 면 6개를 `#cushion`에 매핑한다. 인스턴스 `oak_chair_black`에서 실제 `#wood`는 `chair/oak_chair`, `#cushion`은 이번에 픽셀을 확인한 `chair/cushion/black_cushion`으로 해석된다.
3. **필요 없는 부품의 시각적 생략을 텍스처로 구현하는 사례:** `bench/cushion/none_cushion`, `shelf/overlay/none`은 실제 모든 화소가 알파 0이다. 따라서 면/요소가 존재하더라도 해당 부분은 텍스처 알파로 투명하게 만들 수 있다. **이 방법이 게임에서 실제 최적화 또는 바람직한 렌더 성능을 제공한다는 주장은 아님.**
4. **UV는 원본 PNG 해상도의 픽셀 격자를 우선 맞춘다:** 조사된 Handcrafted 면 784개에서 정수 픽셀 정렬률 100%였다. 다만 이는 **의도적으로 선택된 leaf 16개 표본**이며 다른 모든 가구 모드에 일반화하지 않는다.
5. **겉보기 단순함과 자료 구조의 복잡도는 별개:** 동일 원형의 여러 변형/연결 상태를 세밀하게 표현하면서도 재질 참조를 분리한다. 이 관찰은 이전 v12/v15의 회전·0두께·연결 모양 통계와 함께 해석해야 한다.

## 4. 아직 미검증인 부분

- 상위 1단계 01~05 세부 작업 중 **확정 완료 0/5**. 이번 v16은 **상위 1단계 03/04 직접 원본 검증 진전**이고 상위 2단계 최종 규칙서는 아직 작성 전. 기존 SQLite v10에 이번 CSV 미통합.

- 연구 저장소 및 동일 고정 커밋 `8d21d166...` Handcrafted 원본 저장소가 로컬에 존재할 때 `python scripts/reproduce_v16_handcrafted_originals.py /path/to/Handcrafted` 명령으로 실행하면 PNG 실제 화소, Git blob SHA, 부모·생성형 모델 face→PNG 정합성을 데이터와 비교하도록 작성했다.
