# v15 — Minecraft 가구 모델 표현 방식의 신규 정량 비교

**2026-11-12 · 상위 1단계의 03/04 연구 정량 확장 (05의 사전 근거, 최종 규칙서 아님)**

## 범위·출처·검증 등급

- **신규 수행:** 기존 연구 저장소에 실측 기록으로 보존된 Another Furniture 템플릿 **69종(v11)**과 Handcrafted 원형 모델 **120종(v12)** CSV를 직접 읽고, **모델별 여섯 방향 면의 정의 밀도**, 회전·평면 부품 비중, `0..16` 블록 좌표 범위 밖 경계, Handcrafted 계열별 구성의 통계를 **189개 레코드 전체에서 다시 계산**했다. v13 PNG 24종의 기존 픽셀 결과도 가시 팔레트 표본의 중앙값을 새로 계산하여 교차 점검했다.
- **출처 바이트의 수준:** 제작자 원본 JSON·PNG/JAR 바이트를 v15에서 다시 읽은 것이 아니다. **v11~v13 기존 실측 레코드에서 새로운 통계 항목을 계산한 2차 분석**이다. 임의의 모델·UV·원본 관찰 수를 늘리지 않았다.
- 버전 차이: 바닐라 1.21.11 / Another Furniture 1.21.1 / Handcrafted `1.21.x` 고정 커밋. 둘의 대상 모델 목록도 서로 다른 설계 모집단이므로 무작위/동질 표본처럼 비교하면 안 된다.

### 이 비교에서 새로 드러난 사실

1. **JSON face 생략 방식이 다름.** Another Furniture는 `6×299−1362 = 432`개 방향 face 슬롯이 선언되지 않았다. 69개 템플릿 중 **60개**가 일부 face를 생략하며 **9개**만 전체 여섯 면을 선언한다. 반면 Handcrafted의 자체 요소가 있는 **112개** 모델은 이 측정 레코드상 `6×810=4860`개 face 슬롯이 전부 선언되어 있다. **면 정의 수=실제로 그려질 면 수가 아님.** 투명도·가림·평면·GPU 컬링을 이 수치만으로 단정할 수 없다.
2. **회전과 평면 요소 모두 상세 표현에 동원되지만 사용량이 다르다.** Handcrafted에서 회전 요소는 **283개**, 두께 0 요소는 **183개**다. 두 분류는 서로 겹칠 수 있으므로 더해 별개 요소의 개수로 만들지 않는다. Another Furniture도 회전 요소 **17개**, 두께 0 요소 **34개**가 있어 '완전히 수평·수직 큐브만 사용'한다는 주장은 틀린다.
3. **원시 bbox가 1블록을 넘는 예가 있음.** Handcrafted 60개, Another 3개의 기존 측정 bbox가 축별 `0..16` 밖이다. 이 bbox는 JSON 부품의 **로컬 기하 좌표**이며 모델 회전·블록 위치·충돌 모양과 동일하지 않다. **다칸 설치 또는 월드 공간 크기를 이 기록만으로 확정하지 않는다.**

## 잠정적인 디자인 학습 가설 (규칙 확정 금지)

1. **면 단위의 의도적 생략을 분석해야 한다:** Another Furniture의 432개 비명시 면 슬롯은 실제 렌더/오버드로우/표면 가림 관계와 추가 대조해야 한다. '면이 없는 경우 최적화'라고 바로 판단하지 않는다.
2. **카테고리별 표현 전략이 달라질 수 있다:** Handcrafted `table/*`과 `couch/*` 사례는 동일한 모드 안에서도 회전과 평면 사용이 매우 다름을 보여준다. 가구 유형별 제작 규칙의 후보로 삼되 인게임 비교 전에는 확정하지 않는다.
3. **블록 좌표 상한을 고정된 디자인 규칙으로 착각하지 않는다:** 원시 bbox가 `0..16` 밖인 모델을 왜 확장했는지 실제 부모 상속, 회전 변환, 블록 상태, 충돌형상과 대조해야 한다.
