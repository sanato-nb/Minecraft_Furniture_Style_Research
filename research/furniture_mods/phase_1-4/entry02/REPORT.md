## 측정 근거

- Handcrafted의 UV 생략 면 인스턴스 1,338건은 고정 1.21.1 클라이언트의 `gfx`, `gfx$1`, `ji`, `gga` 클래스에서 대조한 6방향 공식으로 계산했다. [바이트코드 지문과 식](ENTRY02_AUDIT.json)
- UV가 닿는 원본 화소의 하한은 내림, 상한은 올림으로 잡았다. 방향 반전과 90도 단위 면 UV 회전은 모델별 원장에 보존했다. 면별 밀도는 연속 UV 폭을 프레임 폭 또는 높이로 환산한 뒤 모델의 해당 로컬 면 길이로 나눈 값이다. 면 회전이 90도 또는 270도면 로컬 축을 교환했다.
- 애니메이션 이미지 4개는 16×16 프레임 총 45개로 나눠 각 면의 사각형을 측정했다. 메타데이터의 프레임 시간·보간 선언을 함께 기록했다. 런타임 보간과 게임 텍스처 아틀라스 효과는 별도 검증 범위다. [프레임 원장](ANIMATION_FRAMES.csv)
- 영면적 및 범위 초과 UV에는 화소 수와 RGBA 지문을 부여하지 않았다. 경로 미확인 8개 중 7개가 실제 면 139건에 연결된다. 77개 선언 전용 텍스처의 영향 판정은 E에서 이어간다. [예외 원장](UV_EXCEPTIONS.csv)
- 동일 텍스처 ID와 UV 사각형의 화소 집계를 재사용한다. PNG에서 추출한 면별 사각형의 RGBA SHA-256, 알파 분포, 가시 색 수와 상위 색상 빈도를 [UV 영역 분할 원장](./)에 보존했다. 모델별 원장은 아래 명령으로 재생성할 수 있다. 독립 검산에서 중복 면 키 0건이며 모델별 원장과 영역·프레임 집계가 일치했다. [독립 검산](INDEPENDENT_AUDIT.json)

## 재현과 후속 작업

저장소 루트에서 첫 회차와 동일하게 고정 Git 체크아웃 두 곳과 공식 JAR 폴더를 지정한다. `--faces`는 모델별 연결, 명시·기본 UV, 방향, 회전, cullface, tintindex, 밀도를 포함한 상세 원장을 생성한다.

```sh
entry=research/furniture_mods/phase_1-4/entry02
python "$entry/measure_uv.py" --af AF_GIT --hc HC_GIT --jars JAR_DIR \
  --out "$entry" --faces MODEL_FACES.csv.xz
python "$entry/audit_uv.py" MODEL_FACES.csv.xz
```

다음 회차는 1-3-E 대표 상태 표본에서 재질·팔레트·픽셀 밀도·UV 배치를 대조하는 1-4-D다. 상태 회전·UV lock은 1-3의 선언과 연결해 해석하며, 실제 게임의 아틀라스·tint·렌더 효과에는 별도 근거가 필요하다. E의 출처 예외와 DB, F의 전체 종료 감사가 남아 있다.
