# 1-4-D · 가구 모드의 재질과 UV 배치 비교

기준 커밋은 1-4-C 종료 시점인 `15e53cb3530f3d0b2af0b215b4bbac394772bc7e`다. 1-3-E의 **가구 9개 유형, 상태 47개, 모델 적용 52건, 요소 335건**을 같은 키로 이어받았다. 원본 PNG 76개의 해시를 검증하고 기존 UV 영역 650개에서 프레임별 화소 681건을 다시 잘라 RGBA 지문·알파·가시 색 수를 대조했다. 모델 면 1,610건 중 1,521건은 정적 PNG, 1건은 애니메이션, 88건은 UV 면적 0이다.

## 텍스처와 형상의 역할

| 사례 | 원본에 근거한 결과 |
|---|---|
| 의자 S01–S09 | AF 오크 의자는 넣은 상태에서 형상 위치가 바뀌고 46면의 텍스처·UV·화소가 그대로였다. HC 오크 의자는 쿠션 설정 전후 형상 지문이 같았다. 쿠션에 해당하는 6면은 없음 설정에서 완전 투명했고 흰색 설정에서는 가시 화소가 생겼다. 나머지 실측 면 52건의 텍스처·UV·화소는 일치했다. Macaw 오크 의자는 실측 59면이 모두 바닐라 오크 원목과 껍질 벗긴 오크 원목을 참조했다. |
| 소형 테이블 S10–S13 | HC 사이드 테이블은 0두께 요소 5개의 실측 면 10건이 전부 투명했다. Macaw 커피 테이블은 다리 포함과 중앙 상태가 같은 오크 원목 PNG를 쓰고 요소는 2→1, 측정 면은 11→6이었다. |

| 수납 S20–S25 | AF 오크 서랍의 열림·닫힘은 같은 정육면체에서 앞면만 교체한다. 앞면의 가시 RGB 10→12색, 원본 밝기 표준편차 21.8728→39.9912를 측정했다. HC 기준 오크 서랍도 1요소의 정육면체였다. Macaw 독립 오크 서랍은 5요소이며 별도 손잡이 요소의 로컬 크기가 0.1×1×4다. |
| 선반·책장 S26–S29 | HC 선반의 0두께 오버레이에서 면 2건은 유효 UV를 갖지만 모두 투명했다. Macaw 책장은 기본·연결 상태에서 같은 PNG 3개를 사용하며 실측 면 31→19, 서로 다른 RGBA 사각형 지문 11→8로 바뀌었다. |

## 바닐라 대조군과 밀도

- Minecraft 1.21.1과 1.21.11의 고정 JAR에서 오크 판자, 껍질 벗긴 오크 원목, 하얀 양털, 책장 4개 모델과 부모·PNG를 재조회했다. 버전당 24면의 원본 UV가 가로·세로 모두 모델 단위당 1px다. PNG 경로 5개 중 4개는 파일 바이트 SHA가 달랐고 5개 모두 디코딩한 RGBA가 같았다. 책장 옆면은 가시색 29개, 오크 판자 상·하면은 7개였다. [대조군 원장](VANILLA_CONTROLS.csv)
- 모드 측정 면 1,522건에서 1,458건은 두 축 모두 모델 단위당 1px였다. 19개 표본 상태에 걸친 541면은 바닐라 PNG를 참조했다. 이 수치는 E가 고른 표본과 해당 상태의 면 인스턴스에 한정된다. [유형·모드별 집계](CATEGORY_COMPARISON.csv)
- 밝기는 원본 가시 화소의 RGB 코드값에 0.2126·0.7152·0.0722 가중치를 적용해 평균·범위·표준편차를 계산했다. 정적 PNG 및 애니메이션 첫 프레임을 상태별 집계에 사용했다. 면 UV는 모델 로컬 좌표 기준이다. 상태 회전과 UV lock 선언을 원장에 보존했으며 실제 게임의 조명, tint, 아틀라스와 UV lock 적용 결과는 별도 검증 범위다.
