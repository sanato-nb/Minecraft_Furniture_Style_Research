# 1-4-C 후속 검증 — 접힌 UV, 범위 초과와 미연결 슬롯

2026-11-19 KST. 기존 1-4-C의 면 592,312개 원장을 고정 원본으로 다시 생성하고 독립 검산을 통과했다. 이전에 사각형 화소를 측정하지 못한 **80,603면**을 대상으로 원본 PNG, UV의 교집합, 모델 슬롯 상속을 확인했다.

기존 사각형 실측은 **511,709면(86.4%)**이다. 점·선·경계 접점·범위 안 일부에 대한 **보완 실측 74,260면**을 합치면, 원본 화소 근거가 연결된 면은 **585,969/592,312면(98.93%)**이다. 고유 원본 화소가 없는 **6,343면**은 템플릿 슬롯 미연결 6,202면, 원본 PNG 누락 139면, PNG와 겹치지 않는 UV 2면이다. 템플릿의 자식이 이미 측정된 경우에도 해당 화소를 템플릿 자신의 실적으로 중복 계산하지 않았다.

## 측정 방법

- 정규화 UV 0–16을 프레임 픽셀 좌표로 환산했다. 폭과 높이가 있는 UV에서는 영역과 양의 길이로 겹치는 픽셀을 계산했다. 점·선의 접힌 축은 좌표가 닿는 원본 픽셀 셀을 기록했다. 정확히 한 칸과 다음 칸 사이에 놓이면 인접한 원본 양쪽을 후보로 포함했다. 범위 밖 선이 텍스처 경계에만 닿는 8면은 면적·길이 비율 0의 접점으로 구분했다.
- Handcrafted의 일부 책 UV는 U가 −5에서 1까지여서 범위 안에 있는 U=0–1 부분에 한정해 실측했다. 비율은 1/6이다. Another Furniture의 등불 UV 2면은 V=36–60으로 두 끝 모두 범위를 벗어났다.
- 원본 153개 PNG 경로의 해시를 검산했다. 1,298개 UV 예외 그룹에 대해 프레임별 원본 화소 범위·RGBA SHA-256·알파 분포·대표 가시색을 기록했다. 독립 검산은 원본 상태별 그룹 건수와 각 픽셀 셀의 교집합을 다시 계산했다.
- 슬롯 미연결 6,202면과 경로 누락 139면을 포함하는 모델은 고정 블록 상태에서 직접 선택된 근거가 없다. 자식 바인딩은 상속 원장과 해당 자식의 동일 기하 제공자·슬롯·유효 PNG 경로를 대조했다.
- 이 실측은 원본 프레임의 화소에 해당한다. Minecraft 렌더 시 실제로 선택되는 경계 화소, 아틀라스 이웃 텍스처 유입, 필터링·UV 수축·tint는 별도 엔진 검증 범위다.
