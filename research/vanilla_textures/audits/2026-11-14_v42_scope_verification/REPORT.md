## 검수에서 확인된 한계 / 후속 주의

1. **원본 PNG 전량 재디코딩·원본 바이트 기반 SHA-256/PNG CRC 독립 재산출은 이번에 수행하지 못함.** GitHub의 이 연결에서 바이너리 blob은 UTF-8 텍스트 형태로 반환되지 않아 직접 가져올 수 없었음. 이번 검수는 각 단계가 기록한 SHA-256/CRC 분석 근거와 실제 Git 객체 SHA를 교차 비교한 것이다. 기존 SHA 검증 보고서가 `검수 당일 원본 전량 재실측`으로 바뀌는 것은 아니다.
2. **재현 Python 도구들을 전부 재실행하지 못함.** 스크립트 및 수치 원장 존재, 다수 결과 행수/Boolean·정적 모델 참조 대조는 확인했지만, 스크립트가 현 로컬 실행환경에서 재현 가능한지와 픽셀 통계 수치 자체가 전부 정확한지는 별도의 독립 재연 테스트가 필요하다.
3. **초기 작업표 11개에는 A–G와 D1–D3의 예전 미체크 체크박스가 여전히 남아 있음.** 각 파일은 R000 당시 **계획 시작 기록**이고 현재 완료의 근거로 사용하면 안 된다. 또한 `PROGRESS.md`/통합 README에는 v39~v41 당시의 **“현재/최신”** 문구가 과거 단락으로 남아 있다. 항상 최상단 **v42**와 이 감사 보고서, 라이브 `handoff/STATE.json`을 우선할 것. 구 기록은 보존한 것이며 새 검증 요구로 부활시키지 않는다.
4. **작업 범위는 선정 150/150이다.** 게임 `block/`에 존재하는 블록 PNG **1,111종 전체 정밀 검사**가 아니다. 1-2~1-5, 가구 모드 연구·스타일 가이드 연구도 1-1의 분모에 포함하지 않는다.
5. **애니메이션 소스 연구는 9개 단계 재개·2개(석재·벽돌, 잎·식생) 보류**. 해당 2개 단계의 사용자 승인 정적 소스 범위 완료 판정을 전 애니메이션 분석 완료로 확장하지 않는다.

## 다음 과제로 이동해도 되는가?

**지정한 150개 바닐라 재질 텍스처의 소스 기반 자료 조사·통합을 마쳤다는 전제에서 1-2 분석으로 넘어가도 되는 수준**이다. 그러나 요구가 "이미지 원본 150개 SHA-256/CRC와 각 분석 알고리즘을 다른 환경에서 독립 재검산하여 100% 재현"이라면, 그 추가 품질 검수는 아직 완료하지 않았다. **전체 프로젝트 신뢰도를 위해서는 향후 로컬 실행 가능한 독립 재검산도 권장**한다.
