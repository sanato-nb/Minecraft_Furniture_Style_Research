## 3. 색상 통계 해석 시 필수 주의 사항

**확인한 모델 정의 (동일 버전의 추출 미러에서 실제 JSON 내용 확인):**

- `assets/minecraft/models/block/grass_block.json`: 잔디 윗면 `grass_block_top`에 `tintindex: 0` 명시.
- `assets/minecraft/models/block/oak_leaves.json`: 부모 모델 `minecraft:block/leaves` 사용.
- `assets/minecraft/models/block/leaves.json`: 여섯 면 모두 `tintindex: 0` 명시.
- `assets/minecraft/models/block/vine.json`: 양면에 `tintindex: 0` 명시.
- `assets/minecraft/models/block/moss_block.json`: 일반 `cube_all` 상속, 텍스처만 연결.

따라서 `grass_block_top`과 잎 계열, 덩굴의 PNG에 기록된 회색/연한 색을 게임 내 최종 식물 색상이라고 단정할 수 없음. **색상은 렌더링 컨텍스트에 따라 달라질 수 있고**, PNG 색상 분석은 기본 스프라이트의 구조와 명암을 보여줄 뿐이다. 구체적인 생물군계 색상과 게임 결과는 아직 시험하지 않음. `moss_block`은 확인한 모델에서 TintIndex가 표시되지 않지만, 다른 렌더링 효과까지 단정하지 않음.

PNG 알파가 0인 픽셀과 알파가 1~254인 픽셀은 구분해서 기록했다. 알파 값이 있다고 해서 그 블록이 항상 반투명 렌더링된다는 뜻은 아니다.

## 4. 반복 배치 및 픽셀 방향성 실측

`03_100종_반복경계_진단.csv`에 좌우/상하 끝 경계 RGB 차이와 내부 이웃 픽셀 RGB 차이를 기록. 차이는 두 픽셀 색의 채널 절대값 평균이므로 **벽에 이어 붙였을 때의 심미적 자연스러움이나 진짜 심리스 품질을 인증하지 않는다**. UV 매핑, 렌더링, 광원 영향은 포함하지 않는다.

1. 계획 상한 150종까지 가능하면 **부족한 재질/용도 표본**을 추가하되 숫자 맞추기보다 대표성 우선.
2. 사용자가 적법하게 보유한 **실제 Minecraft Java 1.21.11 `client.jar`**의 PNG와 SHA-256을 교차 대조하는 단계 필요.
3. 게임 안에서 색상 변형(잔디·잎), 투명도, 텍스처 반복과 광원 표시 직접 대조 필요.
