# 83종 누적 바닐라 텍스처 조사 — 자료 안내

- `01_누적83종_분석보고서.md` : 발견 및 해석, 한계
- `09_진행도_추적.md` : 1단계 전체와 01의 수량 진행도를 분리
- `00_진행현황.json` : 진행 상태 구조화 데이터
- `02_출처_해시.csv` : 버전 1.21.11, 공개 미러의 PNG 링크 및 SHA-256
- `03_전체83종_픽셀통계.csv` : 실제 PNG 83종의 픽셀 실측
- `04_재질계열_집계.csv` : 8개 계열 요약
- `05_판자12종_무늬상관.csv` : 66쌍의 명암 패턴 상관
- `06_대표_쌍비교.csv` : 대표적인 재질간 실측 비교
- `07_미확정_제외파일.csv` : 확보 중 복사/디코딩 오류로 제외한 3개 항목
- `08_재질통계_비교.png` : 직접 만든 통계 시각화 (게임 원본 이미지 미포함)
- `analyze_vanilla_83.py` : 로컬에서 합법적으로 확보한 Minecraft 1.21.11 텍스처 또는 client.jar로 분석 재현

게임 원본 PNG 파일, 접촉시트, base64 이미지 등은 이 ZIP에 **포함하지 않음**. 자세한 출처와 수치의 한계는 보고서 참조.
