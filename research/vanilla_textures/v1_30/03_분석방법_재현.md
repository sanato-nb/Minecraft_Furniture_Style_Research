# 분석 방법·재현·주의사항

## 입력과 출처

- Minecraft Java Edition **1.21.11**로 표시된 `InventivetalentDev/minecraft-assets` GitHub 버전 브랜치의 개별 PNG 바이트를 수집했다.
- 각 파일을 PIL/Pillow로 열어 실제 RGBA 픽셀 배열을 계산했다.
- 30개 파일 전부 PNG 디코딩 검증에 성공했다.
- 공개 미러 출처이며, **Mojang 배포 JAR와 바이너리 SHA 대조는 아직 하지 않았다**. JAR 검증 상태를 '완료'로 표시해서는 안 된다.

## 세부 지표 정의

- `unique_rgb_visible`: `alpha>0`인 픽셀의 고유 RGB 튜플 수. 투명한 픽셀의 RGB는 세지 않는다.
- `visible_pct`: alpha>0 픽셀 / 전체 픽셀 ×100. **반투명 픽셀도 가시로 포함**한다.
- `fully_opaque_pct`: alpha=255 픽셀 / 전체 픽셀 ×100.
- `mean_alpha`: 전체 픽셀의 alpha(0–255) 평균.
- `mean_luma`: 감마 부호화 sRGB 가중값 `0.2126 R+0.7152 G+0.0722 B`의 가시 픽셀 평균. CIE Lab의 지각 명도(L*)가 아니며 물리적 휘도도 아니다.
- `luma_std`: 가시 픽셀 luma의 모집단 표준편차.
- `adjacent_horizontal_delta`: 가시한 좌우 이웃 두 RGB 픽셀의 세 채널 절댓값 차이 평균.
- `adjacent_vertical_delta`: 가시한 상하 이웃 두 RGB 픽셀의 세 채널 절댓값 차이 평균.
- `direction_ratio_vertical_over_horizontal`: 상하 이웃 평균차 / 좌우 이웃 평균차. 0으로 나누는 경우 공란.
- `left_right_seam_delta`, `top_bottom_seam_delta`: 양 끝 이미지 테두리에서 겹치는 가시 픽셀의 차이. 실제 게임에서 무봉합 여부를 보장하지 않는다.
- `shannon_entropy_colors_bits`: 가시 RGB 색상의 분포 엔트로피(원시 이미지 비트 수와 다름).
- `luma_pearson_r`: 두 16×16 PNG의 동일 좌표 luma 256개 사이 Pearson 상관계수. 높아도 실제 RGB, 팔레트 순서, 파일 바이트가 같다는 뜻은 아니다.

## 재현

1. Minecraft Java Edition 1.21.11의 정상 설치 원본 `client.jar`를 자신이 보유한 설치 파일에서 준비한다.
2. `pip install numpy pillow` (Python 3.10 이상 권장).
3. `python analyze_vanilla.py --client-jar "<path-to-1.21.11.jar>" --version 1.21.11 --output ./rechecked`
4. `rechecked/05_픽셀통계.csv`의 SHA-256을 이 패키지 CSV와 비교한다.
5. 동일 해시가 나올 때만 `공식JAR_바이너리대조_일치`로 검증상태를 올린다.

`--assets-dir`에는 `assets/minecraft/textures/block/`를 입력할 수 있으며, 이 경우에도 반드시 수집 버전은 별도로 확인해야 한다.

## 저작권과 산출물

Mojang/Microsoft 소유의 원본 PNG는 포함하지 않는다. 색상 요약 그림은 각 텍스처의 대표 RGB 색 한 칸과 통계값만 사용하며 원본 무늬, 타일 이미지 배열을 재현하지 않는다.

참고: https://www.minecraft.net/en-us/usage-guidelines
