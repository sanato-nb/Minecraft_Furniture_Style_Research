# 재질 계열별 실제 이미지 관찰 메모 — v1 (30종)

> 각 항목은 분석한 30개의 16×16 실제 PNG를 확대해 관찰한 내용이다. 게임의 모든 가구·모델에 대한 보편적 결론으로 취급하지 않는다.

## 목재 (8종)
- 6종 판자: 모두 긴 수평층이 반복된다. 밝고 어두운 줄을 배치해 넓은 면에서도 판재 방향이 읽힌다. 목재별 색 범위는 크게 다르다.
- `oak_log_top`: 정사각형 단면의 겹겹이 둘러진 고리 무늬; 판자와 나뭇결의 방향이 다르다.
- `stripped_oak_log`: 밝은 긴 수직 줄 결, 미세 색상 변화가 나타난다.
- 측정된 색상 수와 방향별 픽셀 차이의 차이를 별도 기록했다.

## 석재·벽돌 (7종)
- `stone`: 작은 회색 패턴이 비교적 낮은 대비로 분포.
- `cobblestone`: 불규칙 다각 돌덩이의 밝고 어두운 경계가 뚜렷.
- `stone_bricks`, `deepslate_bricks`, `bricks`, `tuff_bricks`: 줄눈과 재료 경계를 이용해 돌 블록 단위 구조를 묘사.
- `polished_andesite`: 경계 프레임보다 잔무늬 중심의 표면.

## 금속 (4종)
- `iron_block`: 밝고 반듯한 금속판의 테두리와 선형 하이라이트.
- `copper_block`: 붉은 구리톤으로 면 방향과 프레임을 구분.
- `exposed_copper`: 산화 초기의 얼룩진 색 혼합.
- `oxidized_copper`: 청록색 계열의 불균등한 색과 경계 음영.

## 직물 (3종)
- `white_wool`, `red_wool`, `blue_wool`: 16×16 한 면 안에 작은 밝기·색상 변화가 여러 개 분포.
- 단색 패브릭처럼 보이지만 실제 픽셀 RGB 단계는 판자보다 많다.
- 방직물/모직의 요철을 실제 3D 형상으로 만든 것은 아니다. (이 관찰은 PNG 자체에 한정.)

## 유리 (2종)
- `glass`: 투명한 내부를 둘러싼 흰색~청록색 테두리 픽셀들.
- `red_stained_glass`: 붉은 반투명 면에 가장자리 알파 차이.
- RGB 색상 수만으로 투명 유리의 실제 표현력을 측정할 수 없으므로 RGBA 값 기준 통계를 병행.

## 도기·색면 (3종)
- `terracotta`, `white_terracotta`, `orange_terracotta`: 넓은 색면 안에 약한 톤 변화가 분포.
- 붉은 점토 면과 흰색 점토 면은 색상·밝기가 다르지만 형태가 단순하다는 공통점.
- 가시 색상 수가 많아도 이미지 대비와 명암 표준편차는 매우 낮을 수 있음.

## 기타·가공면 (3종)
- `white_concrete`, `black_concrete`: 거의 균일한 표면. 장식보다 색면을 강조.
- `crafting_table_front`: 흰색·갈색·진한 선 등의 기하학적 도안으로 기능적 전면을 표현. 재료 텍스처 1장과 혼동 금지.

## 보류 사항
- 외부 조명, 모델의 UV 배치, 사용 면, 인접 블록 연결 효과 등은 아직 확인하지 않았다.
- 텍스처 30종 관찰을 바탕으로 가구 모델의 권장 디테일 수나 픽셀 색 수를 확정하지 않는다.
