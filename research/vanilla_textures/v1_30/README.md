- 7개 재질 계열에서 **30종 PNG의 실제 픽셀·알파 분석**을 완료.
- **이번 완료는 30종 표본에 대한 것**이며 01 세부 단계 전체가 완료된 것은 아님. 전체 프로젝트 1단계(01~05)의 완료를 의미하지도 않음.
