# TEX11-R005 — 공식 원본 JAR SHA-1 인증을 필수 연구 범위에서 제외

**결정일:** 2026-11-13  
**단계:** 1-1-11 목재·구조부품 (고정 PNG 31개)  
**변경 유형:** 사용자 직접 요청에 따른 연구 범위/완료 기준 변경. **신규 이미지 또는 JSON 측정은 없음.**

## 사용자 결정

사용자는 자신이 Minecraft Java Edition 1.21.11을 설치하고 그 설치본의 JAR을 직접 압축 해제하여 업로드한 `1.21.11/` 폴더를 연구 원본으로 제공했다고 설명했고, 이후 **"그러면 그냥 공식 인증 빼"**라고 명시적으로 요청했다.

따라서 이후 이 단계의 연구에서 **Mojang 공식 클라이언트 JAR 전체 SHA-1 인증 및 원본 버전 메타데이터 교차 검증을 필수 작업과 완료 판정에서 제외**한다.

- 원본 `client.jar` 파일의 재업로드를 사용자에게 요청하지 않는다.
- Mojang 공식 버전 메타데이터와 전체 JAR SHA-1 비교를 요구하지 않는다.
- 진행률/완료 판정에서 공식 JAR 인증 여부를 미완료 항목으로 세지 않는다.
- 사용자 제공 `1.21.11/` 추출 폴더를 **사용자가 직접 설치한 게임 원본에서 왔다고 진술한 주자료**로 계속 사용한다.
- 이 결정은 "원본 JAR SHA-1 인증을 했다"라는 주장이 아니다. **인증 미수행**과 **인증 요구 제외**를 명확히 구분한다.
- 과거 R001~R004의 당시 판단·증거·4계층 구분·고정 소스 SHA 데이터는 고치지 않는다.

## 유지되는 검증

1. 기존 완료 결과: **31 PNG** 소스 SHA-256·PNG CRC (R003), **127 leaf JSON** 사용자 추출본 직접 파싱 (R004), **512 blockstate 모델 참조**, **114 템플릿 명시 UV면**, **128 선반 정적 입력 조합**, **31 PNG 모두 실제 모델 재질 슬롯 연결**.
2. 다음 소스 작업: 회전/방향/열림/연결 상태의 **정적 모델 배치 및 UV 투영을 소스 기반으로 추가 재현**, 가능하면 PNG 원본을 적용한 정적 이미지와 오류 후보만 따로 확인한다. 기존 확인 수치를 신규 검증으로 중복 계상하지 않는다.
3. **실제 게임의 정적 렌더링 검증은 유지:** 게임 실행/사용자 제공 실제 스크린샷/정적 테스트의 실측 근거가 있어야 인게임 UV·접합·컬링·빛/투명도를 완료 처리한다. 현재 **0/31**.
4. 애니메이션, Project Zomboid 변환, 실제 가구 모델 제작은 여전히 제외.

## 변경되지 않는 자료 및 범위

- 고정 표본 **31 PNG**, 단계 `1-1-11`, 기존 `TEX11-R001`~`TEX11-R004` 전부 불변.
- 전역 체크포인트 `v38` 및 다른 재질 단계/공통 문서 변경 없음.
- 이번 버전은 실측 증가가 없으므로 **완료 개수/진행률을 인위적으로 올리지 않는다**.
- `STATE.json` 최신 리비전 `TEX11-R005`, 다음 `TEX11-R006`.

## 이후 진행 규칙

과거 보고서에서 공식 JAR 인증을 "다음 작업"이라고 적은 문구는 **당시 기록**이며, 사용자 요청이 반영된 **이 문서 및 최신 `STATE.json`이 향후 우선 적용된다**. `TEX11-R006`부터 원본 JAR 인증을 다시 추진하지 말고, 정적 표현과 게임 화면 검증에 집중한다.
