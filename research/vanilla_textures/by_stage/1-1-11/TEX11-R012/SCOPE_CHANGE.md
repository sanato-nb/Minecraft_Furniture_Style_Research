# TEX11-R012 — 사용자 결정에 따른 인게임 검증 요건 제외 (범위 변경)

**날짜:** 2026-11-13
**단계:** 1-1-11 (목재·구조부품)
**성격:** **관리·완료 기준 변경만 수행. 신규 원본 PNG/JSON 픽셀 측정 0건.**

## 사용자 지시
사용자가 “인게임 검증은 제외해줘 어차피 모델링이랑 텍스텨있는데 필요없을거같아”라고 명시했다. 이에 따라 **실제 Minecraft 게임 실행, 스크린샷, GPU 컬링·조명·표시 결과를 1-1-11 단계의 필수 조건 및 완료 분모에서 제외한다.** 게임 검증을 완료했다고 주장하지 않는다.

## 적용 범위
필수 증거는 사용자 제공 Minecraft Java 1.21.11 원본 `1.21.11/`의 PNG + model JSON + blockstate JSON 및 정적 파일 기반 검증이다.
- 원본 PNG 바이너리·CRC·RGBA·alpha·색상/대칭/경계 확인
- model JSON의 parent/texture slot/geometry/UV/정적 면
- blockstate JSON의 모델 연결·정적 상태·방향·면 회전
- 원본 파일 근거로 관측 가능한 재질별 특성·이음새 후보·근거 보고서
- 기존 결과는 변경하지 않고 불변 보고서로 계승; 동일 원본 연구 수치를 새로 가산하지 않음

**제외:**
- Minecraft 실제 게임 화면 캡처/인게임 정적 렌더·엔진 컬링·조명 검증 **(이번 R012에서 사용자 지시로 제외)**
- 공식 Mojang 원본 `client.jar` 전체 SHA-1 인증 **(과거 R005에서 이미 제외)**
- 애니메이션 연구(유예), 좀보이드 변환, 실제 가구 3D 자산 제작, 타 단계 및 루트 v38 변경(기존 제한 유지)

## 기존 근거로 확인한 새 범위의 완료 상태
- 단계에 고정된 **31개 PNG**의 각 `items[]`에서 `user_provided_extraction_verified` 31/31, `r007_direct_png_crc_sha256_match` 31/31, 그리고 R009/R010/R011 중 **모델 전체 면 실화소 연구 플래그 31/31**을 직접 확인하였다.
- 이전 불변 근거를 결합한 **31 PNG / 596개 모델별 원본 면 RGBA·UV 패치 / 68,960회 소스 UV 텍셀 참조**. R009 trapdoor 12 PNG / 216패치 /25,344참조; R010 shelf 5 PNG /100패치 /6,880참조; R011 door 14 PNG /280패치 /36,736참조. 여러 패치가 같은 물리 source 텍셀을 재사용함.
- `stage_current_analysis_completed_count`를 **31**로 기록하되, 이것은 **이번에 재정의된 source-only 필수 범위의 확인 건수**이지 과거 F 인게임 검사나 공식 JAR 인증을 완료한 건수가 아님. `source_only_completion_status=complete_for_fixed_31_PNG_scope`.
- 인게임 확인 기록은 정확히 **0/31** 유지: `ingame_static_render_verified_count=0`, `ingame_static_render_verified=false`. 다만 **필수 요건 아님 / 완료 분모에서 제외 / 스크린샷 요청하지 않음**으로 표시한다.
- 역사적 v38 oak_shelf 32상태와 127 leaf·512원본 rule·544 정적 상태·672 인스턴스·4,320 회전 면 수치를 증감 없이 유지. 단계 외 전체 프로젝트 완성률은 `null` 그대로 유지.

## 후속 채팅 인수인계
- 사용자에게 게임 캡처/F3/상태 촬영을 요구하지 않는다. 인게임 검증을 미완료 장애물로 간주하지 않는다.
- 사용자 `계속해줘`만으로 같은 고정 원본을 반복 조회·재측정하거나 의미 없는 신규 릴리스를 만들지 않는다. **정해진 31 PNG 소스 분석은 이 완료 정의에 따라 종료**했음을 설명한다.
- 새로운 파일, 새로운 독립 과제, 다른 단계로의 변경 지시가 생기면 그 요청의 범위 안에서 연구를 재개할 수 있다.
- 지금까지 작성한 REPORT/CSV/SVG와 과거 R011 인수인계 기록에 존재하던 인게임 요청 문구는 **역사적 맥락으로만 보존**한다. 실제 작동 기준은 이 R012 변경 및 최신 `STATE.json`/`HANDOFF.md`가 우선한다.
