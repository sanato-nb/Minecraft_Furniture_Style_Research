# TEX11-R010 — 선반 5종 32×32 전체 모델 면 RGBA·정적 연결 상태 원본 분석

**날짜:** 2026-11-13 · **독립 단계:** `1-1-11` · **이전:** `TEX11-R009` · **다음:** `TEX11-R011`

## 1. 원본·범위 및 신규 실측
- 사용자 제공 Minecraft Java **1.21.11 설치본 JAR 추출 폴더** `1.21.11/`의 32×32 shelf **PNG 5개, blockstate JSON 5개, leaf model JSON 30개, template model JSON 6개**를 GitHub에서 직접 열었다. 5 PNG는 직접 바이트 디코딩하여 PNG chunk CRC, IHDR, indexed palette/bit depth(4/8), zlib/DEFLATE, scanline filtering까지 검사하여 **5/5 유효**. 현재 고정 연구 범위에 이미 포함된 5 PNG를 재검사했으며 **PNG 5개를 새로 추가한 것이 아니다**.
- **이번 신규 UV 분석:** material 5×각 6 leaf(본체+5전면) 모델의 실 source `elements[].faces[].uv`로부터 **100 모델·면 패치 / 6,880 PNG 텍셀 참조**를 직접 읽었다. R007이 이미 조사한 각 재질당 본체 south/up 2면 + 전면 5면 = **35 패치/4,720 참조**는 **계승만** 하고, R010에서 직접 추가 측정된 **65개의 본체 면 패치 / 2,160 PNG 텍셀 참조**만 새 조사 단위로 계산한다.
- **정적 원본 상태 관계 검증:** material 5×4 facing×2 powered×4 side_chain = **160 소스 파생 논리 조합**. blockstate 원본 `multipart` 총 **120 조건 규칙(재질당24)**을 실제 매칭하여, 상태마다 항상 **본체1+전면1 = 2 모델 인스턴스**, **16 모델 면**, **864 UV 텍셀 참조 사용**. 전체 상태 반복 참조는 **2,560 상태·면 사용 / 138,240 PNG 텍셀 사용**이며 **고유 신규 texel 수가 아니다**.
- **서로 다른 모델 참조 조합은 정확히 100개**, 나머지 **60개 논리 상태는 같은 facing의 `powered=false` 상태에서 `side_chain` 속성만 달라 동일한 모델 참조 조합을 반복**한다. 이 수는 **모델 선택 signature**의 차이이지 실제 렌더링 화면에서 인간 눈으로 식별 가능한 외형 100개라는 주장은 아니다. 재질당 32 상태, 20 고유 모델 signature, 12 중복.
- 역사적 전역 `v38`의 **oak_shelf 32상태**는 옛 연구로 이미 존재하며, 이번 160상태를 `TEX11-R006`의 새 544정적 상태에 덧셈하지 않는다. 다른 4재질의 128상태도 R006에서 소스 계산했던 값임. R010은 이 **기존 상태 공간에 PNG 패치·조건 signature를 결합한 새 증거**다.

## 2. 실제 PNG 색·알파 및 모델 전체 100면
5개 PNG의 원본 크기는 32×32(총 5,120개 원본 RGBA 텍셀). 직접 측정된 PNG 전체와 **100/100 model-face UV patch에서 완전 투명 alpha0 0건 / 부분 투명 alpha(1..254) 0건**. 대상 PNG들은 모두 불투명한 색상 데이터다. 이 결과는 UV가 투명 구멍을 갖지 않는다는 **소스 사실**이며 게임 내 모든 면이 표시된다는 의미는 아니다.

| wood | 원본 PNG 바이트 | 팔레트 비트 심도 | 완전 투명 텍셀 /1024 | 부분투명 /1024 |
|---|---:|---:|---:|---:|
| oak | 585 | 8 | 0 | 0 |
| spruce | 408 | 8 | 0 | 0 |
| birch | 600 | 8 | 0 | 0 |
| cherry | 417 | 8 | 0 | 0 |
| bamboo | 378 | 4 | 0 | 0 |

- **모델별 원본 구조:** `template_shelf_body`에는 세 요소(shelf_body, shelf_bottom, shelf_top), 총 **15개 표면**. 그중 처음 두 표면(`shelf_body.south` 16×16, `shelf_body.up` 16×3)은 R007에서 이미 샘플링됨. 13개 다른 본체 표면에는 얇은 측면·아랫면·상단 바 등 새 source RGBA 샘플이 포함됨.
- `template_shelf_{center,left,right,unconnected,unpowered}`는 각 요소 1개, `north`면 1개(16×8)의 전면 그래픽이다. 본체 15면의 **736 texel 참조/wood** + 전면 5개×128 = **1,376 참조/wood** = 5재질 **6,880**. 같은 실 PNG 픽셀이 여러 UV 면에서 반복 등장할 수 있으므로 참조 횟수와 원본 텍셀 수를 구분한다.

## 3. 전면 패널·상하 바 공간 일치
- 전면 overlay 25개(5재질×5종)의 실제 원본 template 모델 geometry에서 `from=[0,4,13]` / `to=[16,12,13]`: **Z 두께 0인 north-only 평면**. 본체 뒤쪽 부재의 시작 Z=13과 같고, 아래 막대의 위 Y=4·윗 막대의 아래 Y=12에 정확히 접한다. 주 본체 요소에는 `north`면이 없다는 점도 확인했다.
- 각 overlay에서 geometry 정렬/면/cullface 등 **8개 소스 조건을 검사, 25/25 overlay 모델 전부 통과**. 이로부터 GPU z-fighting, 광원, 음영이 정상이라고 확정할 수는 없다.
- 본체 15면 중 `cullface` 키가 지정된 면 11, 미지정 면 4. 전면 overlay의 `north` 1면은 cullface 미지정. 모든 상태에 중복 투영하면 **cullface 기입 상태·면 1,760개**, 미지정 **800개**. 지정 여부와 실제 runtime 컬링은 별개다.

## 4. 직접 측정한 전면 경계 RGB 후보
- 원본 32×32 PNG에서 UV 영역에 따라 `left`, `center`, `right`, `unconnected`, `unpowered`의 **각 16×8 실화소**를 직접 추출했다(5재질×5패널×128=3,200 패널 텍셀 **참조**). 총 **25개의 역할 인접 후보 비교**마다 왼쪽 패널 마지막 열과 오른쪽 패널 첫 열의 RGB L1, RGBA 일치, alpha 차이를 8행씩 확인해 **200개 경계 행 쌍**을 기록했다.
- 두 번째 패널을 좌우반전하여 연결했다고 가정한 **대안 점수**도 기록했다. 이는 원본 디자인 유사도 후보에 불과하며 실제 `side_chain`의 게임 내 배열/카메라/UV-lock을 검증한 결과가 아니다.

| 재질 | left→center 직접 RGB L1 | 두 번째 패널 반전 RGB L1 | 직접 RGBA 동일 행 |
|---|---:|---:|---:|
| oak | 100 | 0 | 4/8 |
| spruce | 115 | 0 | 2/8 |
| birch | 207 | 0 | 2/8 |
| cherry | 200 | 0 | 2/8 |
| bamboo | 175 | 104 | 4/8 |

- **원본의 흥미로운 규칙:** 참나무/가문비/자작/벚나무의 `left→center` 연결은 두 번째 패널을 좌우반전하면 **RGB L1이 0**, 대나무는 반전 시 104(직접175). 그러나 실제 Minecraft 전면 그래픽이 그 방식으로 회전해서 배치된다는 뜻은 아니다. `SHELF_FRONT_EDGE_CANDIDATES.csv`에 총25 후보의 직접/반전 점수 모두 보존했다.
- `SHELF_SOURCE_FRONT_PANELS.svg`는 PNG 원본 이미지 및 UV로 샘플한 전면 5개 직사각형을 실제 RGB 색으로 보여주는 **소스 근거 SVG**, Minecraft 게임 스크린샷이 아니다.

## 5. 연구 완성 범위와 남은 독립 조사
- **사용자 도움 없이 신규 진행 가능한 작업이 남아 있음:** 기존 7재질 문(상·하 PNG14개)의 서브모델 **전체 5면 RGB/알파 UV 면별 패치**와 회전·가림 후보 정량 비교 등은 아직 stage에서 모든 원본 모델 면을 완전 실픽셀 분석하지 않았다. 다음 R011은 이를 우선한다. 사용자가 이미 제공한 원본만으로 가능하므로 지금 추가 파일을 요구하지 않는다.
- **실제 Minecraft 인게임 정적 검증: 0/31**. 31 PNG, 127 model leaf, 512 규칙, 544 역사적 독립 상태, 672 인스턴스, 4,320 상태·면은 이전 누적 수치를 그대로 유지한다. R010 신규 중복제거 조합 수를 이 과거 수치에 더하지 않는다.
- 공식 Mojang `client.jar` 전체 SHA-1 인증은 사용자 요청에 따라 완료 필수/분모에서 제외(실제 인증 성공이 아님). 애니메이션 보류 유지, 기존 기록 불변. PZ 변환, Minecraft 실제 가구 3D 모델링, 다른 1-1 단계, 루트 `v38`은 작업하지 않았다.
