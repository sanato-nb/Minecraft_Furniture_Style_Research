# TEX03-R006 — 철문·철다락문·구리 격자의 정적 UV 좌우 반전과 알파/색 무늬 분리 검증

**범위:** `1-1-03` 금속·금속부품 16 PNG 고정 표본 · **2026-11-13** · **선행:** TEX03-R005 · **전체 프로젝트 역사적 체크포인트:** v38 불변.

> **R006의 신규 분석 속성:** 사용자 제공 `1.21.11/`의 PNG 3개를 직접 SHA-256·PNG CRC 검사하고 768개 RGBA 텍셀을 재디코딩, *불투명 RGB의 수평 반사 차이*를 새로 계측. 3 blockstate·8 leaf model·9 부모/중간 geometry model = **20개 JSON**을 직접 조회하고, 기존 R005 70개 투명 포함 면에 **UV 반전과 알파 구멍/색상 무늬의 차이**를 새로 매핑했다. 기존 원본 픽셀·상태·면의 총수를 중복 증가시키지 않는다.

## A — 기존 연구 계승·새 측정의 경계

- R001 고유 PNG **16개/4,096개 RGBA**, R002 고유 UV 템플릿 면 **145개**, R003 사용자 제공 원본 파일 **69개**, R004 상태 **63개**와 **406개 상태×모델 면 참조**, R005 투명 원본 좌표 **321행**·PNG 관련 UV alpha 교차검증 **272건**은 모두 **과거 성과**.
- R006에서 재검토한 정적 상태는 **철문 32 + 철다락문 16 + 구리 격자 1 = 49개**. 새로 재독한 23개 파일(3 PNG + 20 JSON)은 기존 파일의 부분집합. alpha0 참조 상태는 **33개**, alpha0 참조 없는 철문 아래 상태는 **16개**.
- 세 PNG의 본문 SHA-256 및 모든 PNG 청크 CRC **3/3 통과**, 원본 크기 각각 **202 / 192 / 227바이트**, 팔레트 PNG를 16×16 RGBA로 디코딩. SHA 값은 `SOURCE_MIRROR_RGB_ALPHA.csv`에 보존.
- 직접 조회한 원본 JSON: `iron_door`, `iron_trapdoor`, `copper_grate` blockstates 3개; `iron_door_top_*` leaf 4개 + `iron_trapdoor_{bottom,top,open}` leaf 3개 + `copper_grate` leaf 1개; `door_top_*` geometry 4개 + `template_trapdoor_*` geometry 3개 + `cube_all` 및 `cube` 2개. `copper_grate → cube_all → cube` 원본 parent 경로 확인.

## B/C/D2 — 16×16 픽셀 색상 반전과 알파 반전의 실제 차이

원본 좌상단 `(0,0)` 기준 수평 반사는 `x → 15-x`. 알파 불일치는 256개 대응 위치의 alpha 값 불일치 개수. RGB 불일치는 **반사 전후 양쪽 모두 alpha=255인 위치만** 비교한 RGB 색상 불일치 개수다. 투명 영역에 저장된 무의미한 RGB 값은 비교하지 않는다.

| 원본 | alpha=0 | 좌우 반전 alpha 불일치 | 양쪽 모두 불투명한 위치 | 이 중 RGB 차이 | 위아래 반전 alpha 불일치 |
|---|---:|---:|---:|---:|---:|
| `iron_door_top` | 48 | **0** | 208 | **114** | 64 |
| `iron_trapdoor` | 36 | **0** | 220 | **56** | 0 |
| `copper_grate` | 77 | **98** | 130 | **116** | 98 |

**의미:** 철문 위쪽의 구멍 48개는 좌우 반전해도 동일 위치이지만 불투명 금속 무늬 114개 픽셀은 달라진다. 철다락문의 36개 구멍은 좌우·상하 모두 대칭이지만 불투명 색 56개는 좌우 비대칭이다. 구리 격자의 77개 구멍은 좌우·상하 모두 비대칭이다(수평/수직 반사 시 alpha 값 다른 위치 각 98/256).

`SOURCE_MASK_GRIDS.csv`는 세 PNG의 16개 원본 행과 좌우 반사 행을 `#`(alpha=0), `.`(불투명)로 보존한다. 원본과 정량 비교는 `SOURCE_MIRROR_RGB_ALPHA.csv` 3행.

## D3/E — 상태별 투명 면의 실제 UV 반전 사용

- R005 406개 정적 면 중 alpha0 포함 면 **70개**(철문 32 / 철다락문 32 / 구리 격자 6)를 새 검증 대상으로 선택. 각 70개 면의 UV는 `0 0 16 16` 또는 `16 0 0 16`, 모델 `face.rotation=0`. 직접 원본 leaf→부모 모델 텍스처 슬롯과 원본 JSON의 blockstate 모델 회전을 확인했다.
- **철문 상부 16 상태 × 2 투명 면 = 32면.** 각 상태에서 원본 `west/east` 두 면 중 **정확히 하나**는 UV 수평 역전 `[16,0,0,16]`, 나머지는 `[0,0,16,16]`. alpha 마스크가 좌우 대칭이므로 역전된 **16면 모두 투명 구멍 위치는 그대로**, 반면 114개의 불투명 RGB 색상 픽셀은 반전 방향에 따라 달라진다. **114×16=1,824는 상태×면의 중복 텍셀 참조 횟수**이며 신규 고유 픽셀이 아님.
- **철다락문 16 상태 × 2 = 32개 투명 면:** 모두 `[0,0,16,16]`, UV 수평 역전 0개. 정적 `open` 값으로 판면의 local/world 방향은 변해도 원본 UV 반전이 발생한 것은 아니다. 철다락문 텍스처 자체를 반전했을 때의 색상 불일치(56개)는 **현 모델에서 사용된 UV 반전 근거가 아니다**.
- **구리 격자 1상태×6면:** 부모 `cube_all → cube`의 전체 16×16 UV, 이 6면에는 소스 선언 UV 반전이 없다. 원본 alpha 패턴은 비대칭이지만 **현 상태의 실제 UV 반전 0개**.
- **70면 총계:** 수평 UV 반전 16면, 알파 마스크 위치가 원본과 달라진 면 **0**, `cullface` 선언 **38면**, 미선언 **32면**. R005 원본 기준 회전 후 방향의 수평 면 **52**, 상/하 면 **18**. 인게임 보이는 면 개수는 아니다.
- `ALPHA_FACE_UV_MIRROR_CENSUS.csv` 70행은 구체적 상태·leaf/parent·world 방향·UV 반전·원본 알파/RGB 대조를 기록. `STATE_MIRROR_RESEARCH.csv` 49행은 각 정적 상태별 별도 기록이다. 70개는 이미 R004/R005에서 존재하던 면을 **새로운 속성으로 추가 조사한 건수**이며 기존 분모에 더하지 않는다.

## F — 미검증 경계

- PNG 픽셀과 UV 참조의 좌우 반전은 소스 기반 실측이지만, **실제 게임에서 어느 시점에 어떤 면이 화면에 표시되며 이웃 블록에 의해 가려지는지, GPU 텍스처 보간/조명/광택**은 미검증.
- `ingame_static_render_verified_count` = **0/16**, 실제 게임 스크린샷 0. 단순히 모델 공간 world 방향을 투영했다고 인게임 검증으로 표기하지 않는다.
- Mojang 공식 client.jar 전체 SHA-1·메타데이터 인증은 사용자가 완료 분모에서 **제외**했다. 성공 판정이 아니다.
- 애니메이션/중간 프레임 분석 전면 보류, 역사적 기록 보존. Project Zomboid 변환 및 실제 3D 가구 제작 제외.
