# TEX03-R005 — 금속 6 PNG 투명 픽셀 좌표 및 63개 정적 상태의 면 방향·UV 재검증

**단계:** `1-1-03` 금속·금속부품 / Minecraft Java Edition 1.21.11 / **연구 기준:** 사용자 제공 `1.21.11/` 압축 해제본 / **날짜:** 2026-11-13.

> **구분:** R005에서 새로 작성한 것은 (1) 6개 PNG에 대한 *alpha=0의 (x,y) 좌표 원장* 321행, (2) 사용자 원본 부모 모델 14개의 `elements.faces`를 R004의 406개 상태별 면 참조와 대조한 **회전 후 면 방향/모델 좌표/UV 속성 투영 406행**, (3) 사용자 PNG 6개에 연결된 상태별 UV 면의 **독립 알파 마스크 교차검사 272건**이다. 같은 기존 픽셀·면을 신규 고유 표본으로 가산하지 않는다. 인게임 렌더 검증은 0/16이다.

## A — 출처·선행 증거와의 중복 분리

- 라이브 `STATE.json`을 확인했을 때 이전 버전 `TEX03-R004`, `next_revision=TEX03-R005`. 원본 16 PNG 고정, 전역 프로젝트 v38 불변.
- `TEX03-R001` 16 PNG/4,096 RGBA 값·`TEX03-R002` UV 템플릿 면 145행·`TEX03-R003` 사용자 추출본 69소스·`TEX03-R004` 63 정적 상태/406 상태×면 참조는 **역사적·계승 근거**다.
- R005에서 원본 사용자 자산을 직접 다시 열어 본 핵심 파일: PNG **6개**, blockstate JSON **14개**, 실제 geometry를 소유한 부모/템플릿 모델 JSON **14개**. 해당 자산은 이전에 존재하던 파일이며 신규 발견 파일이 아니다. 23개 leaf model 전부를 새로 재다운로드했다고 주장하지 않는다.
- PNG의 Git blob SHA-1과 직접 계산한 PNG 바이트 SHA-256·청크 CRC, blockstate/geometry JSON의 Git blob SHA-1을 구분했다. 공식 Mojang client.jar 전체 인증은 **사용자가 완료 기준에서 제외**, 인증 성공으로 기록하지 않는다.

## B/C/D2 — 원본 PNG 6개 정적 alpha 공간 좌표

6개 파일을 직접 읽고 PNG CRC를 확인한 뒤 16×16 RGBA로 디코딩했다. **1,536 RGBA 화소는 이 작업에서 재디코딩되었지만 R001의 4,096 픽셀과 중복되는 화소**이다. R005는 투명도 합계가 아니라 *어느 좌표가 구멍인가*를 신규 데이터로 보존한다. 좌표계는 PNG 좌상단 (0,0), 오른쪽 +x, 아래 +y. 완전 투명 `alpha=0`만 대상으로 하며 6 PNG 모두 부분 투명(0<alpha<255) 픽셀은 없었다.

| 원본 PNG | alpha=0 좌표 수 | 공간적으로 관찰한 패턴 | 하나 이상의 R004 모델 UV에서 사용되는 투명 좌표 |
|---|---:|---|---:|
| `iron_door_top` | 48 | x=3–6,9–12와 y=3–5,8–10의 네 사각형 | 48 |
| `iron_door_bottom` | 0 | 전부 불투명 | 0 |
| `iron_trapdoor` | 36 | x=3–5,10–12와 y=3–5,10–12의 네 3×3 구멍 | 36 |
| `anvil_top` | 96 | x=0–2 및 13–15, 모든 y | **0** |
| `copper_grate` | 77 | 행마다 바뀌는 투명 격자 패턴, 정확한 좌표는 CSV | 77 |
| `heavy_core` | 64 | x=8–15, y=8–15 우하단 | **0** |
| **6개 합계** | **321** | PNG 별 고유 좌표, 과거 R001과 중복 | **161** |

- 321개 좌표 중 **161개**는 선택된 PNG의 실제 정적 모델 UV 어느 한 곳에서 참조되고, **160개**(`anvil_top` 96 + `heavy_core` 64)는 R004 모델 UV 모두에서 제외된다. 이는 실제 엔진의 텍스처 샘플링·조명이나 인게임 가시성을 인증하는 결과가 아니라 정적 UV 영역 교차다.
- `anvil_top` 모델 윗면 UV는 **[3,0,13,16]**을 쓰므로 양쪽 3열의 투명 공간을 참조하지 않는다. `heavy_core`는 [0,0,8,8], [8,0,16,8], [0,8,8,16]의 면 UV가 우하단 8×8 투명 영역을 참조하지 않는다.
- 관련 파일: `PNG_ALPHA_MASK_SUMMARY.csv`(6 원본 SHA·CRC·픽셀 집계), `SOURCE_ALPHA0_COORDS.csv`(321개의 (x,y) 좌표와 UV 사용 여부). 6개 PNG SHA-256은 기존 R003과 일치함을 직접 재검증했다.

## D3/E — 사용자 JSON 원본에 대한 새 기하·UV 대조

- 사용자 `blockstates/*.json` **14개**를 다시 파싱한 **63상태의 leaf model·x/y 회전·uvlock**이 R004 406행의 해당 필드와 **모두 일치**(오류 0).
- 실제 `models/block/*.json`의 **14개 요소 소유자 템플릿**을 다시 읽고, R004 406행의 `element_index`, `local_face`, `uv_original`와 비교: 실제 면 존재 **406/406**. JSON에 **UV 명시 346행**, `cube.json`이 `uv`를 생략한 완전한 16×16 정육면체 면의 **기본 UV 60행**. 후자는 누락 오류가 아니라 *명시하지 않은 좌표를 모델 규칙에 따라 해석*한 것임. 346개 명시 UV 일치, 암시 기본 UV 60개는 0 0 16 16과 일치.
- 상태×면 참조 전체에서 실제 모델 JSON 속성: `cullface` 명시 **272행**, 개별 면 UV `rotation` 비영(非零) **84행**, UV 시작·종료값의 순서 역전(x 또는 y) **148행**. **역전 UV 경계**는 텍스처가 인게임에서 좌우로 뒤집혀 보였다는 관찰과 동의어가 아니다.
- 6개 재디코딩 PNG를 사용하는 **272개 상태별 면의 UV 알파 수를 실제 좌표 마스크에서 재계산하여 R004와 272/272 일치**, 불일치 0. 나머지 134개 면의 alpha 수는 R004/R002에서 계승한다.
- **406개 상태별 원본 local face → 상태 `y` 회전 후 방향**, 원본/회전 `cullface`, 본문 좌표 [from,to]와 x–z 좌표 범위, UV 명시 여부·면별 UV rotation 및 역전 경계를 `STATE_WORLD_FACE_PROJECTION.csv`로 새 기록. 표준 방향 해석은 `y=90`: north→east→south→west→north; up/down 불변. 이는 JSON을 회전시킨 **정적 투영**일 뿐 Minecraft 화면이 그 면을 실제 그렸다는 증거가 아니다.
- `STATE_WORLD_ALPHA_SUMMARY.csv`: 전 **63상태**의 투명 포함 면을 방향별로 묶은 정적 원장. R004 기존 406면 개수를 새 실측 406면으로 다시 합하지 않는다.

### 소스 투영으로 추가 특정한 상태별 차이

- **철문:** `iron_door` 32개 상태 중 `half=upper` 16개에만 투명 UV를 포함한 로컬 `west/east` 2면이 있다. 각 상태에서 회전 후 서로 마주 보는 수평 방향 두 면이 되며, 32개 투명 포함 면은 world north/south/east/west에 **각각 8회**로 분산된다. `half=lower` 16상태는 투명 UV 참조 0. 열림/닫힘에 따른 중간 애니메이션은 다루지 않는다.
- **철다락문:** `open=false`인 8상태에서는 투명 포함 면이 **world up/down**(각 8회), `open=true`인 8상태에서는 **수평 north/south/east/west**(각 4회)로 바뀐다. 이는 원본 `template_trapdoor_bottom/top/open`과 `blockstates`가 지정한 정적 기하·회전 결과다.
- **모루:** 4방향 ×21면 = 84면의 방향은 바뀌지만 `anvil_top`의 96개 투명 픽셀은 어떤 사용 UV에도 들어오지 않는다.
- **구리 격자:** 1상태×6면 모두 같은 77개 투명 좌표를 UV에서 참조한다. 이는 물리적인 속이 빈 3D 벽면이라는 뜻이 아니라 PNG 텍셀 투명 구멍이다.
