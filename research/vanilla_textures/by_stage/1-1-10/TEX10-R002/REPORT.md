# TEX10-R002 — 잎·식생 8개: 알파 마스크·덩굴 32상태·철쭉 차분 정적 심화 검증

> 2026-11-13 · Java 1.21.11 · 대상은 **동일한 8개**(16개 아님). 전체 연구 버전 **v38 유지**, 애니메이션 연구 보류.

## 직접 확인한 근거
- 전 단계 R001 상태와 파일 SHA 재검사 후 같은 8개 PNG 바이너리를 Pillow RGBA로 직접 재검사. 추출본 Git blob SHA 8/8 재확인; 원본 SHA-256 8/8 일치. Mojang 공식 client.jar 인증 아님.
- 8×16=**128개의 16비트 마스크 행**, 총 **2,048개 알파**의 불투명/투명 상태와 16×16 내부의 수평·수직 알파 전환, 60개 고유 테두리 픽셀, 좌우·상하 불일치를 정량화. `PIXEL_MASK_AUDIT.json`은 **bit15=x0**의 4자리 16진수로 행을 보존. 알파가 0/255인지 R001에서 확인, R002는 경계·반복 구조를 추가.
- `SOURCE_LEDGER.csv`는 8개 경로, SHA, 에지/전환/이음새 수를 파일별로 기록. RGB 경계 색차와 **알파 이음새**를 혼동하지 않음.

## D1: 16×16 마스크별 직접 측정
| PNG | 가시/256 | 테두리 투명/60 | 수평+수직 알파 전환 | 좌우 알파 불일치/16 | 상하 알파 불일치/16 |
|---|---:|---:|---:|---:|---:|
| `oak_leaves` | 172 | 19 | 201 | 6 | 9 |
| `spruce_leaves` | 160 | 22 | 250 | 7 | 5 |
| `birch_leaves` | 144 | 29 | 245 | 9 | 6 |
| `mangrove_leaves` | 212 | 9 | 94 | 5 | 3 |
| `azalea_leaves` | 197 | 15 | 135 | 4 | 7 |
| `moss_block` | 256 | 0 | 0 | 0 | 0 |
| `vine` | 146 | 30 | 142 | 7 | 3 |
| `flowering_azalea_leaves` | 205 | 13 | 125 | 5 | 6 |

- 가문비 잎은 내부 불투명↔투명 접경 **250개**, 맹그로브 잎은 **94개**, `moss_block`은 불투명 이미지이므로 **0개**. 위 전환은 2D 픽셀 인접성으로, 실제 게임 움직임이나 3D 면 개수는 아님.
- 테두리는 16×16 이미지의 중복 없는 **60픽셀**. `moss_block`은 알파 이음새가 완전히 일치해도 **색상 이음새도 일치한다고 결론낼 수 없음**.

## D1/D2: 철쭉 잎 두 PNG의 실제 RGBA 대응
- `azalea_leaves` vs `flowering_azalea_leaves` 256 좌표 직접 비교: **완전히 동일 RGBA 217 / 다른 RGBA 39**. 둘 다 불투명 **192**, 일반만 불투명 **5**, 개화만 불투명 **13**, 둘 다 투명 **46**. 192 공통 불투명 위치 중 **RGB 동일 171 / RGB 변화 21**. 
- 변화 좌표 전체를 `AZALEA_PAIR_DIFF.json`에 기록. 변화는 **알파 18 + 공통 가시 RGB 21**, 39개 위치로 분리됨. 실제 생물군계 적용 색은 **인게임 미측정**. 두 모델은 `cube_all` 상속이며 `tintindex`가 미기재라는 R001 소스 판정 유지.

## D3/E: 덩굴 5 boolean → 32 정적 논리 조합
- 실제 `blockstates/vine.json` blob `66222182c58ec387e15134b8e795ad63a67c5ca4`의 **10 multipart 규칙**을 파싱. north/east/south/west/up의 2^5=32 부울 조합을 각각 규칙과 정확히 비교해 `VINE_32_STATIC_STATES.csv` **32행** 생성.
- 모델 선택 수 분포: **1개 5상태 / 2개 10상태 / 3개 10상태 / 4개 5상태 / 5개 2상태**. 모든 방향이 false면 fallback 규칙 **2,4,6,8,10**에서 **5개 평면**; 모두 true면 **1,3,5,7,9**에서 5개 평면.
- 32개 가상 조합 전체 합계는 **85개 모델 인스턴스**, 덩굴 모델 양면 `north/south` 선언 기준 **170면**. 월드 실제 렌더 장면에서 170면 관찰했다는 뜻이 아니며, 32개 상태가 전부 게임에서 도달 가능한지도 미확정.
- 덩굴 북면 UV **[16,0,0,16]** / 남면 **[0,0,16,16]** 를 실제 PNG 16개 texel 표본으로 검증: surface (1,0) 기준 남면 (0,0,0,0), 북면 (170,170,170,255). `VINE_FACE_PIXEL_SAMPLES.csv`로 좌우 반전 기록. 게임 화면의 UV 렌더 결과는 아님.

## F: 공식 인증·인게임·애니메이션 현황
- Mojang 버전 매니페스트 공식 엔드포인트를 확인했지만, 현재 컨테이너에서 `piston-meta.mojang.com` DNS/다운로드 실패. **공식 client.jar 바이트 0, 인증 0/8** 유지. GitHub 추출 미러가 일치해도 공식 인증 아님.
- **인게임 정적 장면 관찰 0/8**, biome tint 실제 RGB, 리프 렌더 경계와 덩굴 회전의 화면 대조 미검증.
- 프레임/키프레임/움직임/흔들림/애니메이션 전면 보류. 기존 동적 기록 삭제·수정하지 않음.
