# TEX02-R005 — 1-1-02 공식 JAR 인증 요구사항 제외 (정책 변경만)

날짜 2026-11-13. 해당 단계: Minecraft Java 1.21.11 / 석재·벽돌 17종. **이 버전은 사용자 명시 요청에 따른 연구 범위·완료 조건 변경이며, 새 PNG/JSON 실측이나 인게임 검증 성과가 아니다.**

## 변경된 1-1-02 검증 기준

**연구 범위 및 완료 조건에서 완전히 제외할 항목:**
- Mojang 원본 압축 `client.jar`의 전체 SHA-1 인증.
- Mojang 공식 버전 manifest/version JSON의 인증·원본 JAR 다운로드 시도.
- 이 공식 인증 누락을 이유로 연구 완료 판정을 가로막는 규칙.
- 다음 버전의 필수 작업으로 공식 인증 자료 취득을 반복 요청하지 않음.

**유지할 필수 검증:**
1. 사용자 제공 GitHub `1.21.11/`의 실제 텍스처 PNG·모델 JSON·blockstate JSON의 직접 조사.
2. 이전 비공식 추출 미러와의 파일 SHA/바이트 교차 검증(필요 시).
3. RGBA·색상·대비·반복·이음새/줄눈, 정적 모델 및 UV·회전·미러 등 A–E의 소스/이미지 분석.
4. 마인크래프트 실제 게임의 **정적 렌더 검증** (가능한 근거를 확보할 때까지 미확인 표시).
5. G 보고서·원장·인수인계 저장. 애니메이션 연구는 계속 보류.

## F 항목 재정의

기존 F `공식 Mojang client.jar·인게임 정적 검증`은 **`F 인게임 정적 렌더·UV·이음새 검증`**으로 바꾼다. 사용자 제공 자료 검증 및 미러 비교는 A/B/E 등에 포함한다.

공식 인증 필드는 과거 R001–R004의 역사적 기록과 충돌하지 않도록 삭제하거나 `true`로 조작하지 않고 **`not_required / excluded_from_completion`**으로 구분한다. 이미 기록된 역사적 `official_client_jar_authenticated_count=0`은 그대로 존재할 수 있으나 이제 연구 완료를 막는 조건은 아니다.

실제 인게임 정적 검증은 **0/17, pending**이며 변경된 조건에서도 **미완료**이다. 따라서 연구의 A–G 최종 완료 개수는 현시점에 임의로 증가시키지 않는다(`0/17`).

## 이전 버전 및 쓰기 경계

- R001: 17종 미러 PNG SHA/CRC/RGBA, A–E 근거 **불변**.
- R002: 끝면 2개 PNG·기본 102면·31개 블록 상태 기록 **불변**.
- R003: 사용자 제공 `1.21.11/` 17종 직접 검증과 미러 교차 확인 **불변**.
- R004: 31상태/186면 소스 연결·deepslate 상태 중복 2개 결과 **불변**.
- 본 R005는 신규 실측 **0건**의 정책 버전. 다음 단계 `TEX02-R006`에서는 **공식 인증을 다시 요구하지 않고** 실제 소스 이미지·정적 UV 또는 인게임 증거의 부족한 부분만 검증.
- 다른 재질 단계 및 프로젝트 전체 체크포인트 `v38` 수정 금지. Project Zomboid 변환/실제 가구 모델링도 보류.
