## 실제 새 작업
사용자 제공 16개 blockstate JSON의 73 variant 및 52 multipart 선언을 읽고, R004 모델 면 원장(39 leaf/template 모델, 8 부모, 143면)과 R006에서 이미 전수 확인한 256개 책장 상태를 상태별로 결합했다. 이번 신규 연구 결과는 329개 상태의 모델 면·UV 참조를 조인한 전수 원장과 21개 대상 PNG별 상태 가중 참조량이다. 기존 규칙/픽셀/모델을 새 고유 원본으로 다시 세지 않았다.

## 21종 전체 커버리지
일반 variant는 고정 21종 중 19종의 모델 face를 포함한다. 나머지 2종인 chiseled_bookshelf_empty 및 chiseled_bookshelf_occupied는 multipart 슬롯에서 연결된다. 256개 슬롯 상태의 총 1,536개 대상 면은 비어 있음 768면/32,768 uses, 점유 768면/32,768 uses로 나뉜다. 각 텍스처가 하나라도 등장하는 상태는 각각 252/256개. 일반 variant 고유 모델 20개와 책장 기본 모델 1개/슬롯 자식 12개를 합하면 실제 선택되는 모델 정의는 33개; 이전 R004 결과와 일치한다.

## 출처·검증 한계
16개 사용자 추출본 blockstate의 고유 SHA-1을 SOURCE_LINK_LEDGER.csv에 기록했고 이번에 원본 JSON을 직접 파싱했다. 이전 R004의 143 model-face rows와 이전 R006의 256 조건 평가 결과는 불변 소스 원장을 재사용한 것으로, 이번 대화에서 39개 모델 JSON을 다시 처음부터 직접 파싱했다고 주장하지 않는다. 원본 21 PNG의 바이트/픽셀 검증은 R001의 미러 직접 디코딩, R003의 사용자 추출본 SHA 21/21 일치, 이후 R005/R006의 해당 PNG 바이너리 재검증 기록을 계승한다. 고유 신규 원본/고유 신규 픽셀 0개.

사용자의 명시적 지시에 따라 마인크래프트 인게임 스크린샷·렌더, 실제 UV winding·uvlock·multipart particle 동작, 공식 Mojang client.jar 전체 인증은 **연구 범위와 완료 조건에서 제외**된다. 소스 JSON의 선언된 particle 링크는 실제 게임 particle 선택 인증이 아니다. 애니메이션, 실제 가구 3D 제작 및 PZ 변환도 진행하지 않았다.
