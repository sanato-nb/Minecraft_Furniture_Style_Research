# TEX05-R006 — 유리 PNG 색상 팔레트와 축소 색상 혼합의 정적 근거

> 2026-11-13 · Minecraft Java Edition 1.21.11 · 단계 1-1-05 · TEX05-R001–R005 불변 · v38 불변

## A / 재진입과 중복 제거
라이브 STATE의 `TEX05-R005 → TEX05-R006`을 기준으로 선행 R005 보고서·요약·원본 결과 CSV·재현 코드를 읽었다. 새 PNG 수는 **0**이고, 이전 6 PNG·1,536개 원본 RGBA·36면 모델 UV·31개 정적 자원 경로는 계승만 한다. 새로 분석한 것은 **원본 20개 고유 RGBA 팔레트 엔트리의 실제 픽셀별 개수**, **6개 PNG별 색상/알파 구조**, **원본 16×16을 2×2 비중첩 블록으로 가정한 수학적 색상 평균의 비교 384건**이다.

## B / 사용자 제공 1차 자료 직접 판독
사용자가 JAR을 풀어 제공한 저장소 `1.21.11/assets/minecraft/textures/block/` 아래 대상 6 PNG를 GitHub에서 base64로 읽었다. 원본 바이트를 별도 Python/Pillow로 디코딩하고 각 SHA-256을 계산했다. **기존 R005 출처 SHA와 6/6 일치**. `SOURCE_LEDGER.csv`에 6개 원본 경로와 SHA/Git blob을 기록. 기존 문서의 CRC 시험은 계승하며, 새로운 PNG 청크 CRC 실측 건수는 추가하지 않는다.

## C / 새 원본 팔레트 결과
- `glass`: 5종 RGBA. `(128,128,128,0)` **191픽셀**; 불투명 프레임/강조부 네 RGB 색의 총합 **65픽셀** — `#D0EAE9` 31개, `#8BC1CD` 19개, `#A8D0D9` 11개, `#7BAEB7` 4개.
- `red_stained_glass`: RGB `#993333`, `black_stained_glass`: `#191919`, `blue_stained_glass`: `#334CB2`, `green_stained_glass`: `#667F33`, `white_stained_glass`: `#FFFFFF`. **5종 각각 256개 픽셀 전부 RGB는 동일**. 각 파일 내 알파와 개수는 102×191, 155×5, 163×60.
- 착색 5종의 **전체 256위치 알파 배열은 서로 일치**. 이것은 R001/R005에서 기록한 마스크·분포와 일치하는 후속 교차 대조이며 중복 픽셀수 증가로 기록하지 않는다.
- 6개 고유 원본 PNG에 존재한 **고유 RGBA 엔트리 수 합계는 20** (무색 5 + 착색 3×5). 원본 전체 픽셀 기록은 추가 1,536개가 아니다.

## D / 수학적 2×2 축소 대조 — *게임의 실제 mipmap 아님*
각 16×16 PNG를 2×2 비중첩 블록 64개로 분리한 **총 384개 실험 셀**. 두 계산을 구분한다:
1. `straight RGB`: 2×2 네 픽셀의 각 RGB를 단순 산술 평균
2. `alpha-weighted RGB`: 각 RGB×알파를 더한 뒤 전체 알파합으로 나눔. 알파합=0이면 정의하지 않음

- `glass`: 64블록 중 **32개**는 알파합=0이며 가중 RGB가 정의되지 않음. 나머지 32블록은 네 픽셀 간 알파값이 혼재하며 **32/32에서 두 RGB 평균의 차이가 발생**. 최대 한 채널 차이는 **79.5**. 예: 블록 (1,1)에서 straight RGB = (148,154.5,154.25), alpha-weighted RGB = (208,234,233).
- 착색 5종: 각각 64블록 모두 알파합>0, 알파 혼합 블록은 각 32개. 하지만 RGB 자체가 일정하므로 두 RGB 평균은 **64/64 동일**(차이 0).
- **핵심 한계:** 이것은 *정확한 색상 수학적 비교만* 증명하며 `glass.png.mcmeta`의 `mean`이 이 공식을 사용한다고 확인한 것이 아니다. 실제 밉맵 생성 수식, 감마·색공간 처리, premultiplied alpha, 샘플러, LOD, GPU 색상은 미검증이다.

## E / 모델·아틀라스·셰이더와 연결 경계
기존 R003 모델 체인과 36개 정적 UV, R004 `glass.png.mcmeta` 및 일반 `block.fsh/vsh`와 atlas `blocks.json` 정적 검증은 **변경·추가 집계하지 않았다**. 투명한 원본 픽셀에 RGB `#808080`이 저장되어 있어도 실제 월드 렌더 결과의 프린지·색 번짐이 발생한다고 단언할 수 없다. `block.fsh`의 `ALPHA_CUTOUT`은 조건부 소스이며 현재 6종에 바인딩되었다는 증거가 아니다.
