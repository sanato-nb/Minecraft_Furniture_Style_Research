# TEX05-R006 — 정적 팔레트와 가상 다운샘플의 증거 경계

- **실제 바이트:** 사용자 GitHub 저장소의 `1.21.11/` 원본 6개. 각 SHA-256을 다시 계산해 R005 자료와 6/6 일치. PNG 수/픽셀 수는 선행 결과의 반복 검산.
- **새로 실측한 정적 데이터:** 각 원본에서 픽셀별 RGBA 출현수, 무색 원본 알파0의 비표시 RGB, 착색 5종의 완전한 알파 위치배열 동일성.
- **수학적 파생 데이터:** 2×2 비중첩 평균 proxy 6×64=384개. `straight`와 `alpha-weighted`를 코드에 명확히 구별하고 alpha sum 0인 weighted 결과를 `undefined`로 기록.
- **증명하지 않는 것:** 실제 엔진의 mipmap_strategy=mean 구현, 텍스처 atlas 실제 픽셀/LOD, 셰이더 유리 바인딩, 포그·조명·블렌드·컷아웃 활성화, GPU·인게임 출력/정렬.
- R004의 `glass.png.mcmeta`는 실제 정적 `mean` 설정을 담지만 이번 임의 평균식과 동일함이 증명되지 않았음. RGB에 관한 proxy 차이 79.5를 실제 게임 프린지로 해석하면 오류.
- 6개 대상 외 유리창·기타 단계 확장 없음. 애니메이션 분석 금지, PZ 변환/가구 제작 제외. Mojang 공식 전체 JAR 인증은 사용자 정책상 범위 제외.
