# TEX05-R005 — 사용자 제공 PNG의 비트 알파·연결 윤곽·축소 평균 정적 측정

> 2026-11-13 · Minecraft Java 1.21.11 · 1-1-05 유리 · 이전 TEX05-R001~R004 불변 · 공통 v38 불변.

## 조사 대상·출처 구분
- 라이브 STATE가 TEX05-R004 / next TEX05-R005일 때 시작. 이전 R004 REPORT/SUMMARY/CSV를 읽고 **기존 미측정 항목**(PNG IHDR 색 유형, 높은 알파 마스크의 연결 성분, 테두리 분리 및 2×2 축소 가상 평균)을 선정.
- 1차 자료는 사용자 제공 `1.21.11/assets/minecraft/textures/block/{glass,red_stained_glass,black_stained_glass,blue_stained_glass,green_stained_glass,white_stained_glass}.png`이다. GitHub fetch_file(base64)로 **6 PNG 원본 바이트를 각각 직접 읽어** Python base64→PNG 바이너리 디코딩을 수행했다.
- 실제 PNG SHA-256을 계산하여 이전 고정 6개 원장 SHA와 **6/6 일치**. IHDR·IDAT·IEND 청크 CRC가 **6/6 정상**. IHDR 해상도 모두 16×16, 비트 깊이 8, 인터레이스 0, 검사 PNG 파일 총 6종(기존 파일 재검사).
- 사용자 제공 원본 Git blob SHA와 SHA-256/실제 바이트 크기는 `SOURCE_LEDGER.csv`, 측정 상세는 `PNG_ALPHA_TOPOLOGY.csv`에 보존. 원본으로 확인한 고유 **신규 소스 경로 0**(기존 31 경로 중 PNG 6 재검사). 과거 PNG 6개/1,536 RGBA, 기존 36 모델면 UV를 새 실적에 더하지 않음.

## B — 새로운 PNG 비트 형식 관찰
- `black_stained_glass`, `white_stained_glass`: IHDR color type **4**(8-bit grayscale+alpha; 디코더 LA).
- `glass`, `red_stained_glass`, `blue_stained_glass`, `green_stained_glass`: IHDR color type **6**(8-bit RGBA).
- 이는 파일 내 픽셀 인코딩의 차이로, 실제 GPU 압축 포맷·아틀라스 표현이나 유리 렌더 레이어 차이를 입증하지 않는다.

## C/D1/D2 — 고알파 윤곽의 4-연결 구성 정량화
- `glass`의 높은 알파 기준은 A=255, 착색 5종은 A>=155로 정의(착색 강조점 155, 외곽 163). **각 원본의 정확히 65/256 픽셀**이 이 조건을 충족.
- 4방향 상하좌우 연결 요소는 모든 6종에서 **[60,1,1,1,1,1]**: 바깥쪽 1픽셀 외곽 테두리 60개가 한 연결 요소, 내부 강조점 5개는 독립된 단일 픽셀 성분. 6개 마스크 쌍차이는 유리 기준 **0/256**.
- 내부 강조점 좌표는 (4,2), (3,3), (2,4), (13,12), (12,13). 좌표 자체는 R001에서 이미 다뤄졌고, **이번 신규 측정은 비트 인코딩과 4-연결 성분 크기 및 세 종류의 명확한 알파 역치**이다.
- 원본 `glass` 픽셀 집합은 RGBA 색 5종, 착색 유리는 각각 고정 RGB + 알파 102/155/163에 따른 RGBA 색 3종. R001의 알파 분포를 새 픽셀수로 가산하지 않는다.
- 높은 알파를 지닌 가장 바깥 테두리는 각 PNG에서 **60/60**. 바로 안쪽 두 번째 고리에서 높은 알파는 0이고, 독립 강조점 5개는 더 안쪽에 배치되어 있다.
- **비트 알파 해석 주의**: 이 PNG는 1-bit alpha 파일이 아니다. 8-bit alpha 채널에 실제로 일부 값만 등장하는 것을 확인한 것이다.

## D — 미프맵 소스 vs 산술 가상 축소를 분리
- R004에서 실제 읽은 사용자 추출 `glass.png.mcmeta`의 `texture.mipmap_strategy="mean"`는 **명시적인 정적 소스 설정**. 5종 착색 유리에는 같은 규칙의 sidecar가 없었음(기존 조회 결과; 새 파일로 가산하지 않음).
- 이번 신규 2×2 산술 알파 평균(원본 16×16의 비중첩 2×2=8×8=64칸): `glass` 최소 0, 최대 191.25, 유일 값 4종; 착색 5개 각각 최소 102, 최대 147.75, 유일 값 5종.
- 이 **임의의 산술 proxy는 실제 게임 밉맵 생성 코드·필터·색상공간·경계 텍셀 처리·LOD·축소 이미지 픽셀을 검증하지 않는다.** 특히 `mean`이 정확히 이 계산이라는 근거가 없으므로 혼동하지 않음. 보조 측정은 서로 다른 알파 모양이 축소 시 다를 수 있음을 드러내는 데만 사용한다.

## E — 기존 모델·UV·셰이더와 연결의 한계
- 기존 R003의 `blockstate→glass leaf→cube_all→cube→block` 정적 자원 연결과 6×6=36 면, R004의 block atlas 규칙 및 `block.fsh`/`block.vsh` 내용은 **계승**하며 신규 정적 자원 경로로 중복 집계하지 않았다.
- 이번 IHDR 저장 형식·마스크 연결 성분·2×2 산술 결과가 블록 셰이더의 실제 선택, 컷아웃 매크로 활성화, 알파 블렌드, 투명 정렬, 실제 프레임의 가시성/컬링을 확정하지 않음. 구체 경계는 `SOURCE_RUNTIME_BOUNDARIES.md`에 기록.
