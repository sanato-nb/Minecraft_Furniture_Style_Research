# TEX04-R007 — 전체 픽셀 명도순위 및 주기적 이동 후속 연구

2026-11-13 · 고정 표본 Minecraft Java Edition 1.21.11 양털 PNG 9종 · 전역 v38 및 TEX04-R001~R006 불변.

## 실제 새로운 소스 검사

사용자가 추출해 GitHub 1.21.11/에 업로드한 9개 기존 PNG 바이트를 직접 재열람해 SHA-256 및 PNG 각 청크 CRC, 16×16 크기·불투명 RGBA를 재확인했다. **신규 PNG 0, 신규 고유 픽셀 0**. 이전 9×256=2,304픽셀과 54 정적 모델 face는 계승만 한다.

R005는 **인접 픽셀끼리** 색상별 밝기 차이 부호를 비교했다. 이번 R007은 **서로 다른 임의 두 위치**의 순서를 36색상쌍 전체에서 비교하므로 서로 다른 검증이며 R005의 16,404 인접 비교를 다시 새 성과로 중복 계산하지 않는다.

명도 정의: 저장된 8비트 RGB 값에 대한 정수 배율값 10000×Y = 2126R + 7152G + 722B. 선형광 휘도나 게임 화면 밝기가 아니라 encoded-sRGB 기반 수학적 비교다.

## 발견 1: 전역 명도 순위 예외

- 256개 픽셀 중 두 위치를 고르는 조합 32,640개 × 색상쌍 36개 = 1,175,040 후보.
- 두 색상 모두에서 두 픽셀의 Y가 서로 달라 비교 가능한 기록 1,130,924건.
- 같은 명도순위 1,130,851건, 순위 역전 **73건**(비교 가능 수의 약 0.006455%).
- 한쪽 이상 동률로 순위 판정 불가 44,116건.
- 73역전은 전부 green_wool이 포함된 7색상쌍에 발생. 역전이 일어난 **서로 다른 좌표쌍은 16개**, 여러 색상쌍에 걸쳐 73회 등장.
- 직접 반례: (x=15,y=0)과 (x=12,y=5)를 비교할 때 white는 Y×10000이 2,170,092 > 2,167,966이지만 green은 856,286 < 857,008. 이 두 위치의 상대 밝기 순서가 반전한다.

따라서 9색 패턴의 명암 배열이 매우 유사하다는 결론은 지지되지만 **완전한 단조 색상 치환**이라고 주장할 수 없다. R005의 1칸 인접부호 일치 100%와도 모순되지 않는다.

## 발견 2: 16×16 순환 평행이동 자기상관

각 색의 명도 행렬을 x=0..15, y=0..15만큼 순환 이동하고 (0,0)을 제외한 255개 이동을 모두 조사. 총 **2,295번**의 원본-이동본 정규화 자기상관을 계측했다.

- 9색 모두 최고 비원점 상관은 이동 (8,8). 해당 Pearson 자기상관 약 **0.484546852846~0.560198840054**.
- 어느 이미지에도 비영점 이동만으로 명도 행렬이 정확히 일치하는 주기는 없음.
- 순환 이동은 수학적 반복성 검사다. 실제 인게임 경계 이음매, 3D 텍스처 방향, 게임 렌더링과 같다고 주장하지 않는다.

## 미검증 및 제외

새 geometry·UV face·blockstates·item refs는 R003~R006에서 계승한 것이며 이번에 새 모델 face 0개. 인게임 정적 렌더링을 실행하거나 캡처하지 않아 검증 **0/9**. 공식 Mojang client.jar 전체 SHA-1 및 공식 버전 메타데이터 인증은 사용자의 요청대로 필수 완료 분모에서 **제외**하되 공식 인증 성공이라고 주장하지 않는다. 애니메이션 전면 보류, Project Zomboid 변환 및 실제 3D 가구 제작 제외.
