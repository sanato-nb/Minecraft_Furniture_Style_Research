# TEX04-R002 — 양털 9색 픽셀 공간 대응·이음매 실측 후속 검증

> 2026-11-13 · 전용 작업 범위 **1-1-04 직물·양털 9개**만 · 원본 **비공식 1.21.11 추출 미러** 재검증. 앞선 **TEX04-R001을 수정하거나 원본 검증 9개를 또 9개 더한 것으로 계산하지 않는다**. 전체 역사적 체크포인트 **v38 유지**.

## R002에서 새롭게 분석한 사항

1. R001과 같은 9개 PNG(각 16×16, 256픽셀)의 **실제 원본 바이너리 SHA-256을 다시 대조**한 뒤 RGB/팔레트 인덱스 데이터를 재추출했다. 9개 모두 R001/v4 저장 SHA-256과 일치.
2. D2 확대: RGB에 BT.709 계수 `Y'=0.2126R+0.7152G+0.0722B`를 곱한 **8비트 비선형 데이터 기반 밝기 대용 지표**로 동일 좌표 256개를 비교, 9색의 서로 다른 쌍 **36개**에 대해 Spearman 순위 상관·Pearson 선형 상관 재산출.
3. PNG 모드 `P` 팔레트 인덱스의 **같은 좌표 일치 수**도 36쌍 별도 계산. 팔레트 인덱스는 파일마다 다른 RGB 팔레트의 위치 번호이므로, 인덱스가 같아도 색 자체가 같다는 뜻이 아님.
4. 반복성 신규 비교: 9개에서 가로 내부 인접 240쌍·세로 내부 인접 240쌍의 **3개 RGB 채널 평균 절댓값 차이**를 구하고, 16쌍의 좌우 끝/상하 끝 RGB 차이를 각각 내부 인접 차이와 나눈 **이음매 대비 비율**을 새로 계산. 추가 원장 `SEAM_REPEAT_AUDIT.csv`.

## 새로운 실측 결론과 반례

- **36쌍 밝기 순위 Spearman = 0.99923735~0.99999140**. 공간적으로 같은 위치가 밝고 어두운 경향이 강하다.
- 반면 **Pearson = 0.90303542~0.99886194**. 밝기 수준 자체가 단일 선형 배율로 완전히 치환되는 것은 아니다. 특히 `white_wool ↔ purple_wool` Pearson은 **0.9030**이므로, 단순히 '색상만 변경한 동일 RGB/동일 대비 이미지'라고 주장할 수 없다.
- `yellow_wool ↔ orange_wool`: 팔레트 인덱스 **254/256개 일치(99.21875%)**; `yellow_wool ↔ purple_wool`: **250/256개** 일치. 별도 팔레트 인덱스 배열이 공유되는 경향은 강하지만 **9개 전체가 같은 인덱스 배열은 아니며**, `white_wool ↔ black_wool`은 같은 인덱스가 **0/256**개였다. RGB 화소 색과 인덱스는 다른 의미.
- **좌우 가장자리 RGB 차이 / 가로 내부 인접 차이 = 1.760824~1.823939**, 9색 모두 **1 초과**. 따라서 좌우로 동일 원본을 그대로 반복할 때 경계에서 내부보다 비교적 큰 픽셀 단계 변화가 발생할 가능성이 있다. 이것이 **인게임에서 반드시 이음매가 눈에 띈다**는 보장은 아니다.
- **상하 가장자리 차이 / 세로 내부 인접 차이 = 0.886389~1.120549**. 9개 중 일부는 상하 경계가 내부 세로 변화보다 작다. 즉 수직/수평 무봉합을 하나의 숫자로 단정할 수 없다.

## 검증 절차·검증 단계 수준

- 파일 SHA-256 재검사 9/9, 디코딩/인덱스 패턴/밝기 36쌍 검사, 이음매 9개 실측. 소스 파일 자체는 동일한 9개뿐이며 독립 텍스처 검사 총수는 **9개를 넘지 않는다**.
- R001 A–E의 정적 블록 모델·암시적 UV 54면 근거는 **그대로 상속**한다. R002에서 54면을 새로 게임 렌더링한 것이 아니다.
- F: Mojang 공식 1.21.11 `client.jar` **바이너리를 확보/해시하지 못함**. 게임 실행 스크린샷도 **없음**. 공식 JAR 인증 **0/9**, 인게임 정적 검증 **0/9** 상태 유지.
- 공식 배포에 관한 추가 조사에서는 공개 버전 인덱스에 표시된 클라이언트 후보 SHA-1 `ba2df812c2d12e0219c489c4cd9a5e1f0760f5bd`와 `piston-data.mojang.com` 다운로드 경로만 찾았다. 이 값은 **이번 실행에서 Mojang에서 직접 읽어 검증한 값이 아니라 제3자 인덱스에서 얻은 후보 지문**이다. `OFFICIAL_VERIFICATION_GATE.md` 참조.
- PrismLauncher의 GitHub 미러 버전 매니페스트에서 2026-11-10 갱신된 `1.21.11` 메타데이터 SHA1 `812ee7fdfdf648bb872f7a1dca33718de4e786b4`를 읽었지만 **이 매니페스트는 공식 Mojang API 실시간 다운로드가 아닌 캐시 사본**이다. 공식 JAR 검증 완료로 격상 불가.

## D3 — 원본 사실과 쿠션·패브릭 지침 가설

- **소스 사실:** 색별 16×16 RGB 명암 패턴은 공간적으로 매우 유사하다. 동일 텍스처를 격자로 반복하면 경계 대비 수치가 좌우/상하 다르게 나타난다.
- **응용 가설:** 후속 가구 디자인 가이드에서는 같은 저해상도 패턴에 팔레트 변형을 적용하는 통일된 패브릭 스타일을 후보로 삼을 수 있고, 가로 이음매가 눈에 띄는 경우 UV 방향·배치나 국부 변형을 실험할 수 있다.
- **미인증:** 쿠션 실제 물성, 직조 구조, 바닐라가 '쿠션은 반드시 양털 팔레트로 제작한다'는 의도, 실제 인게임 이음매 시각 결과는 확인되지 않았다. 실제 가구 제작은 진행하지 않음.
