# TEX04-R008 — 초록 양털 미세 양자화: 순위 역전 73건 전원 추적 및 이중 명도 지표 대조

> 2026-11-13 · `1-1-04` 양털 정적 PNG 연구만 · R001–R007 및 전역 v38 불변.

## 신규 검증의 입력

사용자 제공 Minecraft Java **1.21.11 추출본 PNG 9개**의 GitHub 실시간 blob SHA1을 재열람하고, 로컬에 보존된 해당 원본 바이너리의 Git blob SHA1, 전체 SHA256, PNG 청크 CRC32가 일치함을 검사했다. 모두 16×16 불투명 저장 이미지. 사용자 원본 PNG는 별도 증거이며 새 고유 텍스처를 발견했다는 뜻이 아니다. **새 고유 PNG 0 / 새 고유 픽셀 0 / 새 모델 face 0**. R001의 총 2,304픽셀과 R003의 54면을 계승만 함.

## 첫째: R007 명도 순위 역전은 2종류의 매우 가까운 녹색 RGB값만으로 설명됨

R007의 위치쌍 기반 역전 73건(36색상쌍×256 중 두 지점 선택)을 다시 원본 RGB로 되돌려 14개 위치·16개 위치쌍을 추적했다. **73건 모두에서 초록 양털 두 픽셀은 같은 R·G값을 갖고 B만 1단계 차이**였다.

| 분류 | 초록 원본 RGB 2종 | 픽셀 위치 분포 | 고유 위치쌍 | 색상 비교상 역전 |
|---|---|---|---:|---:|
| G1 | (75,94,34) ↔ (75,94,35) | 각 3곳 | 3×3=9 | 27 |
| G2 | (74,92,36) ↔ (74,92,35) | 7곳 대 1곳 | 7×1=7 | 46 |
| 합계 | 4개 RGB 색상 레벨 | 14개 좌표 | 16 | **73** |

- G1 9개 위치쌍은 `white`·`blue`·`purple`과 초록 간 비교에서 각각 뒤집혀 27회 발생.
- G2 7개 위치쌍은 초록과 `white, red, yellow, purple, cyan, orange`의 6색 비교에서 모두 뒤집히고, 그중 4개 위치쌍에서는 `blue` 비교도 역전한다. 따라서 **7×6+4=46회**.
- 예: 초록 소스 RGB (75,94,34) 대 (75,94,35)는 저장 RGB Y×10000 차이가 **722**, 즉 Y 코드값 **0.0722** 차이. 다른 색상 양털의 동일한 두 위치는 밝기 관계가 반대여서 역전이 기록된다.
- R007의 73건은 이미지가 무작위로 달라서가 아니라 **특정 매우 가까운 원본 팔레트 계단 간 순서 전환**으로 관찰된다. 다만 원본 픽셀의 수학적 설명일 뿐 **제작자 의도·가공 툴·색상 생성 알고리즘**은 확정할 수 없다.

## 둘째: 서로 다른 명도 정의로 36색쌍 전수 재검사

고정된 9색×16×16 저장 RGB를 두 방법으로 각각 처리.

1. **encoded-RGB luma**: `10000×Y=2126R+7152G+722B` (기존 R007).
2. **linear-light relative Y**: sRGB 각 채널에 sRGB EOTF/감마 풀기를 적용한 뒤 `Y=.2126R_lin+.7152G_lin+.0722B_lin`.

36색상 조합, 위치쌍 후보 1,175,040건을 두 방법으로 독립 계산한 결과 **각각 비교 가능 1,130,924건, 역전 73건**, 그리고 **73개의 (색상쌍, 픽셀 위치쌍) 인덱스가 완전히 동일**했다. 선형광 전환만으로 R007의 73개 순위 역전이 사라지지 않음을 확인. 그러나 두 통계 지표가 게임 렌더러 조명·감마 동작을 입증하는 것은 아니다.

## 소스 기반 정적 연구 종료 게이트 — **사용자 도움 필요**

이 9종 16×16 양털에서 이번에 검증한 색상 순위/팔레트 분기 및 기존 패턴/주기성/UV·모델 JSON·아이템 정의 검사는 **소스 정적 연구로 저장 완료**. 그러나 1.21.11 실제 게임에서 **9색 블록이 표시되는 통제된 정적 스크린샷**이 없어 실제 렌더링 검증은 여전히 **0/9**. 따라서 이 단계를 **완료/인게임 검증 완료로 선언하지 않고**, 새 소스 증거 없이 분석 수치만 바꿔 릴리스하는 일을 중지한다.
