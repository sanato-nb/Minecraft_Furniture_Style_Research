# TEX07-R007 — 콘크리트 7색 픽셀 노이즈의 무작위 순열 검증

날짜 2026-11-13 · Minecraft Java 1.21.11 · **1-1-07 전용**. 새 사용자 제공 고유 PNG **0개**; 기존 7개 PNG의 **새로운 통계적 판단 근거 7행**을 확보. 이전 R006 기록을 수정하지 않으며 전체 프로젝트 `v38` 및 다른 재질 단계는 불변.

## 출처와 재현 확인

1. GitHub 사용자 제공 `1.21.11/assets/minecraft/textures/block/{white,black,red,blue,green,yellow,gray}_concrete.png`의 기존 7개 원본 바이트를 재해석. 7/7 PNG SHA-256이 R006 및 R003 원장과 일치. 모든 원본 PNG 16×16 RGBA 디코딩, 알파 255. 이들은 새 파일이 아니며 **1,792 고유 픽셀은 과거 연구에서 계승**.
2. R006 `7_SPATIAL_NOISE_EDGE_AUDIT.csv`의 `mean_Y_709`, `Y_std_population`, `luma_corr_wrap_x1/y1`, `best_nonzero_toroidal_corr`, `max_lr_seam_Y`, `max_tb_seam_Y`, `max_interior_adjacent_Y` 등 7행을 별도 Python 계산으로 모두 재현. 새 계측분에 중복 가산하지 않음.
3. 푸리에 자기상관 (`ifft2(abs(fft2(Y−mean))²)`)과 직접 순환 이동 내적의 16×16×7 결과를 교차 검사, 수치 차이 각 PNG 최고 **2.3×10⁻¹⁶ 이하**. FFT는 기존 순환 상관 계산의 독립적 재현 방법이다.

## 신규 문제: R006 최고 자기상관이 우연 이상의 규칙적인 무늬인가?

16×16 PNG가 256개 픽셀로 작으므로 서로 다른 주기 이동 255개를 모두 뒤져 얻는 **최댓값**이 0.2여도 우연인지 확인해야 한다. 원본 평균 RGB·팔레트 구성은 유지하면서 픽셀 위치만 무작위로 섞는 귀무분포와 비교했다. RGB 트리플릿 전체를 동시에 섞으므로 실제 색상 조합의 빈도는 변하지 않는다. `Y = 0.2126R + 0.7152G + 0.0722B`는 8비트 sRGB 코드값 기반 가중 휘도일 뿐 실제 화면의 선형 광량이 아니다.

색별 고정 RNG `default_rng(20261113+i)`, `i=0…6`, 각 **20,000회 순열** (`argsort(rng.random((1000,256)))`를 20배치), 전부 **140,000개의 16×16 배열**. 각 배열에서 사전 정의한 통계량 2개:
- **T1 최고 토러스 자기상관:** (0,0)을 뺀 **255개 이동 전부에서 최대값**. 255개 중 가장 높은 값만 골랐을 때의 선택 편향을 같은 최댓값의 귀무분포로 통제한다. 순열 검정은 그 값과 같거나 더 높은 20,000개 재배열 수를 이용한 `(exceedances+1)/20001` 우측 꼬리 경험적 p값.
- **T2 저주파 에너지 비율:** 평균을 제거한 2D DFT에서 주파수 축 각각 `|kx|<=2`, `|ky|<=2`의 5×5 영역 중 DC 1칸을 제외한 **24개 bin** 에너지 합 / 전체 비DC 에너지 합. 원본 저주파 에너지가 무작위 재배열보다 **높은 경우**만 사전 정의한 후보로 삼는다. (가로·세로 리샘플링이나 실제 mipmap 효과는 검증하지 않음.)

각 7색×2통계 = **14개 일측 검정**에 대해 Holm 가족별 다중검정 보정. 유의수준 0.05. 경험적 p는 모집단의 정확한 p가 아니라 20,000회 고정 시드 시뮬레이션의 추정치다.

- **T1/T2 14개 중 보정 전 p<0.05 건수 0**, Holm 보정 p<0.05 건수 0. Holm 보정 p값은 14개 모두 **1.0**. 따라서 이 두 통계량으로는 7개 원본 PNG에 **우연한 색상 재배열을 넘는 뚜렷한 정적 규칙성**이 있다고 판단하지 않는다.
- 가장 높은 T1 원본 점수는 **red 0.201963809**였지만, 무작위 팔레트 재배열의 **1,684/20,000개**가 그 이상이었음(`p=0.084245788`). 이어 gray 0.199827549 (`p=0.125043748`), yellow 0.182914638 (`p=0.191640418`). 단순히 `maxcorr=0.20`이라는 숫자로 결함을 판정할 수 없다.
- 원본 저주파 비율의 상위는 gray 0.130218655 (`p=0.090595470`)와 white 0.126030258 (`p=0.114594270`). 원본 black 저주파 0.036117406은 높은 값이 아니므로 **저주파 과다** 검정에서 `p=0.997850107`; 이는 검정 방향을 바꿔 흑색의 고주파 특성을 인증한다는 뜻이 아니다.
- **새로운 오류 확정 0건**. 이 음성 결과는 '반복 무늬가 없다'를 증명하지 않으며 임계 검출력이 낮을 수 있는 작은 샘플을 대상으로 한다. 16픽셀 주기의 동일 PNG 복제·게임 조명·면 방향·밉맵·리소스팩 등은 이 검정의 귀무모형에 포함하지 않는다.

## UV·상태·화면 검증과 분리

R003/R004에서 7색 공통 `cube_all` 체인, **7×6=42면 선언** 및 명시 UV 0 / 기본 [0,0,16,16] 파생 UV 42를 확인한 기존 기록은 보존. R007에서 **새 모델·면·명시 UV 0건**. 이번은 동일 PNG의 배열 위치 무작위화 검사로 **게임의 실제 UV 방향성 또는 렌더 화면을 계산한 것이 아니다**.

인게임 정적 캡처가 확보되지 않았으므로 **0/7** 유지. Mojang 공식 client.jar 전체 SHA-1·공식 메타데이터 인증은 사용자 지시에 따라 필수 항목에서 **제외**하며 공식 인증 성공으로 서술하지 않는다. 애니메이션 연구 전면 보류, Project Zomboid 변환 및 실제 가구 3D 모델 제작 금지.
