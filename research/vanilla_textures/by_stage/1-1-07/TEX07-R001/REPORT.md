# TEX07-R001 — 콘크리트·색면 7종 실제 원본 분석

Minecraft Java 1.21.11 / 2026-11-13. 범위는 정확히 `1-1-07` 7종. 자료는 비공식 `InventivetalentDev/minecraft-assets` 1.21.11 태그. 공식 Mojang client.jar 인증이나 인게임 관찰과 동일시하지 않음.

## A/B/C — 출처 검토·무결성·RGBA 계측

인수인계, 상태, 카테고리 계획, 버전 규칙, v4/150 픽셀 CSV, 150개 번호 원장을 순서대로 확인. 7개 경로·기존 SHA가 세 자료에서 일치. 비공식 미러에서 7개 **PNG 실제 Base64 바이너리**를 독립 취득하고 Python Base64 해제, SHA-256, Git blob SHA1, PNG 청크별 CRC32, IHDR/PLTE/IDAT/IEND, Pillow RGBA 디코딩을 직접 검증하여 **7/7 통과**. v4 SHA가 7/7 일치하지만 v4 기존 기록을 이번 분석 수량에 이중 합산하지 않음. 이전 v35–v38 선반 작업은 콘크리트 7종에 해당하지 않아 재사용 실적으로 산입하지 않음.

7장 모두 16×16, 총 **1,792개 RGBA 픽셀 전부 알파 255**. 흑백/유채 모든 색에 고유 RGB 3~10개. 각 PNG의 지배색·RGB 평균·명도 및 명도 분산은 `PIXEL_MEASUREMENTS.csv`에 기록함. 명도 Y는 `0.2126R+0.7152G+0.0722B`, 채도는 픽셀별 HSV S 평균(0–1). sRGB 선형화나 게임 셰이딩 효과는 포함하지 않음.

## D2 — 미세 분산과 단색 평면 경계

명도 표준편차 범위 0.5321~0.9952, 양방향 인접 픽셀 채널 차이 평균 범위 0.4917~1.1792. 끝선 좌우·상하 채널 차이 평균은 각각 약 0.417~1.000 / 0.500~1.083. **완전 단일 RGB가 아닌 약한 미세 변이의 색면**을 확인. PNG에 별도 프레임·모서리 선은 관찰되지 않았으며, `center_vs_border_delta`는 파일별 중앙 14×14 평균 vs 테두리 60픽셀 평균 RGB 색차다. 이 검사는 인게임 블록 간 접합 렌더나 반복 시점 조명 효과를 검증한 것은 아님.

## D3 — 가구 색면 가설과 관찰 구분

소스 관찰 사실: 7색 모두 완전 불투명, 16×16, RGB별 낮은 공간 분산, 단일 큐브 6면 같은 텍스처. 적용 가설: 도장된 캐비닛 문, 컬러 패널, 장식 색상 평면 등의 스타일 기준으로 시험 가능. 이 가설의 외관/실용성/가구 물성은 원본 이미지 및 인게임으로 검증한 사실이 아니며 실제 가구 제작은 작업 범위 밖.

## E — 정적 모델·블록상태·UV 체인

7/7 `blockstates/<name>.json`: 단일 빈 문자열 variant가 `minecraft:block/<name>` 참조. 7/7 `models/block/<name>.json`: `parent=minecraft:block/cube_all`, `textures.all=minecraft:block/<name>`. 7/7 `items/<name>.json`도 해당 블록 모델 참조. 공통 상속 `cube_all` (Git blob fa2f9e776173224b2b523b8b537c695b921267f6) → `cube` (1b9780b479aee527f79bde950656b82f1524128b) → `block` (f9c72559950abcb186b8e3959e135c0f2d542bdf)을 별도 조회했다.

`cube` 소스는 원소 1개 `from:[0,0,0], to:[16,16,16]`, 6면 각 `texture:#face` 및 `cullface` 명시. `cube_all`은 6면을 전부 `#all`로 연결. **JSON 면의 숫자 UV 지정은 0건**, 모델 기하에서 **전체 16×16 기본 UV 영역을 파생**한 기록은 42면. 각 면 256 원본 RGBA 텍셀 위치를 참조하여 42×256=**10,752 texel-uses**. 이는 1,792개 고유 원본 위치와 다르며 렌더링 픽셀 수가 아님. 방향별 최종 래스터, 회전·조명은 미검증. 면별 전수 출처는 `UV_FACE_AUDIT.csv`.

## F/G — 미검증 및 저장

공식 Mojang Java 1.21.11 `client.jar`와 비교한 경로 **0/7**, 인게임 정적 렌더 **0/7** (F=pending). 미러 원본 일치가 공식 JAR 인증을 증명하지 않는다. 애니메이션은 사용자 해제 전까지 전면 보류. 작성: `REPORT.md`, `SOURCE_LEDGER.csv`, `PIXEL_MEASUREMENTS.csv`, `UV_FACE_AUDIT.csv`, `SUMMARY.json`, `AUDIT_METHOD.md`; 단계 인수인계와 STATE만 별도 갱신. 원본 PNG/게임 JSON 파일은 재배포 권리 확인 전 복사하지 않음.
