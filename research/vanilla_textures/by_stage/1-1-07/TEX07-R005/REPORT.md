- 기준 변경 요청: **“공식 인증 빼”**

## 새 검증 기준 (이 버전 이후 적용)

본 단계의 완료 판정에 Mojang 공식 배포 JAR SHA-1·메타데이터 인증을 **요구하지 않는다**. 앞으로 공식 파일 서버 접속, JAR 본체 내려받기, 공식 SHA-1 검증을 이 단계의 후속 작업/완료 조건으로 취급하지 않는다.

계속 수행할 대상:
1. **사용자 제공 파일 직접 검증** — GitHub `1.21.11/`의 실제 PNG·JSON·블록 상태·모델, SHA-256/내용 확인.
2. **기존 추출 미러 교차 검증** — 필요할 때 기존 미러와 파일·내용 비교. 사용자 제공 파일이 우선한다.
3. **정적 텍스처·색상·RGBA·UV·상속·상태 연결 검사** — 기존 A~E 성과를 이어가고 새 증거만 누적한다.
4. **인게임 정적 렌더 검증** — 실제 게임 런타임 또는 진본 정적 스크린샷이 확보되면 해당 사실만 검증한다. 아직 확인되지 않았으면 미완료로 둔다.

**검증 항목에서 제외한다고 공식 진본이 인증됐다고 주장하지 않는다.** 공식 인증은 “미완료로 해결해야 하는 차단 과제”가 아니라 **연구 범위 제외(not applicable)** 로 관리한다.
