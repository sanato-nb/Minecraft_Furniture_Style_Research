# TEX07-R008 — 콘크리트 7종 텍스처/모델 애니메이션 소스 감사

**날짜:** 2026-11-13 · **단계:** `1-1-07` 전용 · **게임 자료:** 사용자 제공 Minecraft Java 1.21.11 추출본 · **연구 재개 원인:** 사용자의 “그럼 보류한 애니메이션하자” 지시. 인게임·공식 JAR 인증 제외 정책은 계속 적용.

## 결론

**7/7 정적 단일 텍스처**, 사용자 제공 파일에서 **재생할 애니메이션 정의 0/7**. 기존에는 검증하지 않은 애니메이션을 '보류'로 기록했지만, 이번에는 애니메이션 동작을 **소스 파일 수준에서 직접 검사하여 '이 대상들에서는 해당 없음'으로 판정**했다. 실제 Minecraft 런타임·커스텀 리소스팩·모드·게임 코드의 특수 움직임을 모두 배제하는 전역 결론은 아니다.

## 실제 확인한 원본

1. 사용자 제공 원본 `1.21.11/assets/minecraft/textures/block/`의 `white, black, red, blue, green, yellow, gray` 콘크리트 **7개 PNG 바이너리**를 다시 조회, Base64 디코딩 뒤 실제 PNG 청크 파싱. 각각 너비 16·높이 16, 비인터레이스 팔레트 PNG(color type 3), 정확히 `IHDR / PLTE / IDAT / IEND` 청크 **4개**, 청크 CRC32 4/4 유효, IEND 뒤 잔여 0바이트, APNG 관련 `acTL/fcTL/fdAT` 청크 0개. 너비에 맞는 **16×16 타일 칸 1개**뿐이므로 수직 프레임 시트가 아님. 원본 7개 Git blob SHA-1은 R003 원장과 일치하며, 이는 새로운 PNG 7개가 아니다.
2. `<color>_concrete.png.mcmeta` **7개의 정확한 대응 경로**를 GitHub `main`과 R003 **고정 추출본 커밋 `2a43897b8f605b4e0c96a272bca476ee6b70058e`**에서 각각 직접 조회. 모두 파일 부재(각 경로 404). 이 7개 PNG용 `animation.frames`, `frametime`, `interpolate` 등을 정의하는 동반 메타파일이 없다. '존재하지 않는 파일'을 '내용 비어 있음'이나 '0프레임'으로 바꾸어 기록하지 않았다.
3. 사용자 추출본의 원본 JSON **24개**를 재조회: 색별 `blockstates` 7개, 색별 `models/block` 7개, 색별 `items` 7개, 공유 모델 `cube_all.json`, `cube.json`, `block.json` 3개. 각 색 블록상태는 `variants[""]`의 **단일** 블록 모델을 참조, 모델은 `minecraft:block/cube_all`에서 해당 색의 `textures.all`을 지정, 아이템은 `minecraft:model` 형태로 동일 색 블록 모델을 참조. 공유 `cube_all → cube → block` 부모 체인에서도 **프레임 교체·시간값·모델 상태 전환 규칙이 정의되어 있지 않음**. `block.json`의 `display.rotation`은 정적 표시 변환이지 시간 기반 회전 애니메이션이 아니다.
4. 이전 R003/R004에서 확인한 큐브 **6면 × 7색 = 42개 면**과 파생 풀 UV는 **기존 근거를 재사용**. 이 개수는 새 프레임/새 모델/새 고유 텍스처 수와 혼동하지 않는다.

## 범위·해석·검증 한계

- '프레임 1개'는 **16×16 이미지 전체가 텍스처 칸 1개**라는 이미지 구조 설명이고, 애니메이션 메타데이터의 `frames` 배열이 1개라는 주장이 아니다. 아예 동반 애니메이션 메타데이터가 없다.
- '애니메이션 정의 없음'은 **확인한 사용자 제공 텍스처 및 JSON 파일**에 대한 판정이다. Minecraft 엔진의 내부 렌더 효과·플레이어의 손 휘두르기·월드 오브젝트 물리·외부 리소스팩에 관한 검증이 아니다.
- 실제 게임 실행, 인게임 스크린샷, 공식 Mojang client.jar 전체 SHA-1 검증은 **사용자가 제외했으므로 수행하지 않았고 완료되었다고 주장하지 않는다**.
- 본 단계에서 제시할 애니메이션 키프레임·프레임타이밍·보간 방식·프레임별 RGBA 차이는 **대상 없음(N/A)**. 임의로 가상의 애니메이션을 생성하지 않는다.
- 원본 PNG 7, 관련 JSON 24, 부재 확인 경로 7(각 `main`/고정 리비전에서 검사), 새 원본 경로 0, 새 애니메이션 정의 0. **이 단계 애니메이션 소스 연구 완료**.
- 다른 재질 범주에서는 애니메이션 텍스처가 존재할 수 있다. 이 조사로 다른 단계의 보류를 자동 해제·종료하지 않는다. 전체 `v38` 및 다른 단계의 상태 불변.
