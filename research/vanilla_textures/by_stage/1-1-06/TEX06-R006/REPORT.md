# TEX06-R006 — 유광도기 4방향 측면 UV·경계 픽셀 투영 검증

**2026-11-13 · 대상 1-1-06 (8 PNG 중 유광 2 PNG) · R005 계승 · 공통 v38 불변**

## 새로 조사한 것
사용자 제공 `1.21.11/`에서 `models/block/template_glazed_terracotta.json` 및 검정·흰색 유광 `blockstates/*.json`의 원본을 직접 재열람하였다. 로컬 source face의 UV rotation (north 90 / east 180 / south 270 / west 0), 상태별 모델 y (south 0 / west 90 / north 180 / east 270), full cube elements from[0,0,0] to[16,16,16], UV=[0,0,16,16]을 근거로 각 상태의 월드 측면 법선 및 가로 방향을 새로 계산했다.

PNG 두 파일의 Git blob SHA가 기존 R005와 같음을 재확인했지만 **이번에 PNG를 디코딩해 SHA256/CRC를 새로 계산하지는 않았다**. 개별 RGB는 R005 `TOP_SEAM_PIXEL_COORDS.csv` (Git blob `2bc30b7754348a05ad3494fb26e15ad51d408b90`)에서 원본 경계 좌표 60개/PNG의 이미 검증된 값을 **계승**하였다. R005 PNG 관측을 신규 RGB 측정으로 중복 가산하지 않는다.

## 이번의 신규 소스 기하 파생 및 RGB 문맥 비교
- **64행**: 2 PNG × 월드 측면(N/E/S/W) 4 × placed facing 4 × face UV 부호 가정 2. 모델 로컬 면→월드 면, face UV 회전, 원본 PNG NW 픽셀 좌표/계승 RGBA.
- **512행**: 2 PNG × 4 측면 × UV 부호 2 × 가로/세로 경계 2 × 4×4 facing 쌍. 각 경계는 16개 원본 RGB 픽셀쌍이므로 새 기하 맥락의 **8,192 경계 픽셀쌍 비교**이지만 **신규 고유 텍셀 측정 0**.
- **4,096개** 측면 2×2 조합 전수계산 (16가지 월드 측면/부호 조건 × 4^4 facing 조합), **16행** 최적 배치 보존.
- 오른손좌표 +X 동/+Y 위/+Z 남. +Y90:(x,y,z)→(z,y,-x). 외부를 보는 측면의 화면 +x(우측) 축 N:+X/E:+Z/S:-X/W:-Z, +y(아래쪽)=-Y로 정의. 면의 소스 UV가 화면에 CW `+rotation` 또는 CW `-rotation`으로 나타나는 **두 후보**를 모두 계산. 이 부호는 실제 게임 렌더로 검증되지 않았다.

| 텍스처 | 북·동·남·서 모든 측면, UV ± 후보별 최저 2×2 RGB L1 | MAE (4경계×16픽셀×RGB 3채널) | RGB가 동일한 픽셀쌍 |
|---|---:|---:|---:|
| 검정 유광 | 916 | 4.770833 | 28/64 |
| 흰색 유광 | 412 | 2.145833 | 44/64 |

모든 16개 그룹에서 위 최적값을 낸 facing 조합은 해당 그룹 내 1개이다. **최적 점수는 월드 면과 UV 회전 부호에 대해 불변**이나 실제 TL/TR/BL/BR facing은 달라진다. 따라서 기존 R002/R005 상단 최적값이 재현돼도 **그것만으로 게임의 측면 facing이나 UV 부호를 판별할 수 없다**는 것이 이번 분석의 핵심이다. 표의 MAE는 3채널 기준이며 0이 아니므로 완전한 이미지 경계 일치도 아니다.
