# TEX06-R003 — 사용자 제공 Minecraft 1.21.11 추출본 직접 검증

2026-11-13 | 단계 **1-1-06 도기·유광도기 8종 고정** | 이전 R001·R002 및 상위 프로젝트 v38 보존.

## A. 우선 출처와 역사적 연구 분리

사용자 제공 GitHub `1.21.11/` 폴더를 새 1차 **조사 대상**으로 지정. 사용자는 본인이 Minecraft Java 1.21.11 JAR을 직접 압축 해제해 업로드했다고 설명했다. GitHub `version.json`의 `id=1.21.11`, `world_version=4671`, `protocol_version=774`를 직접 확인했다. 이 파일은 공식 배포 압축 JAR의 SHA-1 인증이 아니다.

기존 R001 비공식 미러(고정 커밋 `7241a12cc2707abd7022f399c5d9033153e492e1`)의 실측/원장 및 R002 유광 무늬 512개 조합 결과를 보존. 원본 바이트가 같으므로 **새 텍스처 종 수는 0개**, 재계측한 RGBA 통계도 **0개**.

## B. 사용자 추출본 실제 PNG 바이너리 SHA·청크 검사

경로 `1.21.11/assets/minecraft/textures/block/<id>.png` **정확히 8개**를 GitHub에서 직접 base64로 취득, 바이너리 복원, SHA-256 **독립 재계산**. SHA256 구현이 표준 `abc` 테스트 벡터에 일치함을 확인. PNG 서명·IHDR(8/8 **16×16**) 및 **각 청크의 CRC32**를 확인했다.

`SOURCE_LEDGER.csv`에 파일별 전체 **SHA-256**, Git blob SHA, 컬러 타입, PNG 청크, 크기와 출처 경로 보존. **8/8 바이트 동일**하므로 기존 RGBA·팔레트·무늬 측정은 동일 입력 자료를 측정한 결과로서 유효하다. 단, 이번에 픽셀을 다시 디코딩하거나 기존 숫자를 신규 관찰 횟수에 합산하지 않았다.

## C/D. 픽셀·재질특화 측정 중복 금지

D1 일반 테라코타 6종/유광 2종의 명도·팔레트, D2 유광 2종의 2×2 회전 512개, D3 원본 UV/회전 분석은 **입력 PNG 파일의 실제 SHA256 동일성 확인 후 이전 근거를 재사용**했다. R002의 최적 경계 MAE, RGB 완전일치 수는 그대로 두었으며 신규 측정으로 계산하지 않았다. 이미지 평면의 최적 방향을 인게임 방향으로 승격시키지 않는다.

## E. 사용자 추출본 정적 모델·블록 상태·부모 자료 직접 확인

다음 파일 **20개 JSON**을 직접 읽고 구문·상속/모델·텍스처 슬롯·회전 선언을 검사했다: 8개 리프 모델, 8개 blockstates, 4개 공통 부모(`cube_all`, `cube`, `template_glazed_terracotta`, `block`). 모두 기존 비공식 미러와 Git blob SHA 동일.

- 일반 테라코타 6종: `cube_all` 부모 → 각 `all=minecraft:block/<id>`; 블록 상태는 방향 속성 없는 `variants[""]`.
- 유광 2종: `template_glazed_terracotta` → `pattern=minecraft:block/<id>`; 각 면 UV `[0,0,16,16]`.
- 유광 각 면 UV 회전: **down/up 0°, north 90°, south 270°, west 0°, east 180°**.
- 유광 블록 상태 모델 Y 회전: **facing=south 0°, west 90°, north 180°, east 270°**.
- 부모/상태/리프 파일별 경로, 원문 기반 관계, 해시: `STATIC_SOURCE_AUDIT.json` 및 `SOURCE_LEDGER.csv`.
- 확인된 것은 **정적 선언과 바이트 동일성**. 게임 렌더러가 실제로 표시하는 화면은 확인하지 않았다.

## F. 네 가지 검증 등급 (절대 합산하지 말 것)

| 검증 구분 | 현황 | 엄격한 의미 |
|---|---:|---|
| **1 사용자 제공 추출본 직접 검증** | **8/8** | 업로드된 PNG SHA/CRC 및 JSON 모델·상태 확인 |
| **2 과거 미러와 교차검증** | **8/8** | PNG·모델·상태·공통 부모 파일 해시 일치 |
| **3 Mojang 공식 원본 JAR 인증** | **0/8** | 압축 **원본 client.jar 자체 SHA-1**과 공식 메타데이터 대조 미실시 |
| **4 인게임 정적 검증** | **0/8** | Minecraft 실제 Facing·UV·광원·패턴 렌더 관찰 미실시 |

압축 해제된 파일들로는 원래 JAR ZIP 엔트리 순서, 압축 방식, 타임스탬프, 파일별 압축 스트림을 복원할 수 없으므로 **JAR 전체 SHA-1을 인증할 수 없다**. 추출 폴더 이름/버전 JSON/비공식 미러와의 동일성을 Mojang 인증으로 취급하지 않는다.

## G. 파일 저장·추가 작업

이번 실제 확인: 사용자 제공 **PNG 8 + 모델 8 + 블록 상태 8 + 공통 부모 4 + version.json 1 = 29개 경로**, 참고로 `META-INF/MANIFEST.MF`도 열었으나 내용 없음. R003 신규 고유 텍스처 **0**, 신규 RGBA 계산 **0**. 전용 불변 결과 폴더와 이 단계의 `STATE/HANDOFF`만 갱신.

다음 고유 버전 **TEX06-R004**는 *원래 압축된 JAR*의 SHA-1 공식 배포 인증 또는 실제 게임 정적 방향 렌더의 추가 증거가 확인될 때 작성. 애니메이션·키프레임·PZ 변환·가구 3D 제작 계속 보류.
