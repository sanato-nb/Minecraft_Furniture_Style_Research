# ADR-0001: 단일 저장소, 두 전문 하네스, 공통 연구 엔진

상태: **제안 (PR 검토 대기)**

- GitHub 저장소는 `sanato-nb/Minecraft_Furniture_Style_Research` 하나를 유지한다.
- Vanilla/Mods는 서로 다른 연구 프로필과 소관 범위를 갖는다.
- 해시, 출처, 작업 상태, 비용 제한, 증거 스키마는 공통 계층에서 재사용한다.
- 신규 모드/바닐라 업데이트는 연구 회차를 생성한다: NEW / INCREMENTAL / REVALIDATE / FRESH.
- 기존 고정 연구는 역사적으로 재현 가능해야 한다. 이력·고정 커밋·원래 경로를 검증 없이 재배치하지 않는다.
- 대용량 데이터와 원저자 저작물은 공개 Git 저장소에 불필요하게 재게시하지 않는다.
- 첫 구현은 단일 AI를 옵션으로 두는 단계적 혼합형. 현재 AI API 자동 호출은 비활성화한다.
