### 2.1 형상 검증 기준 및 범위

독립 투영 기준은 256×256 직교 카메라와 원본 큐브·요소 회전으로부터 계산한 2D 외곽 실루엣이다.

- 실루엣 가장자리 **2픽셀 허용 구간**을 사용한다. 픽셀 색이나 조명까지 정확히 동일하다는 주장이 아니다.
- 불투명 사례 23개에서 허용 구간 밖에 나타난 불투명 픽셀 0, 예측된 내부에서 누락된 불투명 픽셀 0.
- P06 투명 사례 2개는 의도적인 구멍이 있어 내부 불투명 픽셀 누락 조건을 사용하지 않고, 실루엣 외부로 벗어나는 픽셀이 없음을 확인했다.
- 이 검사는 **블록 모델의 형상 투영 정확성에 관한 근거**이지 Minecraft 클라이언트와의 전면적인 픽셀 일치 검증은 아니다.

### 2.2 P06 UV·투명성 확인 근거

투명 픽셀의 9픽셀 평행 이동 상관계수:

| 방향 | 오른쪽 아래 | 오른쪽 위 |
|---|---:|---:|
| `P06-north` | **0.9495** | -0.1366 |
| `P06-south` | -0.1365 | **0.9490** |

고정된 P06 원본의 북쪽 면 UV 90° 회전과 남쪽 면 기본 UV가 출력의 두 반대 대각 패턴으로 구분됨을 확인했다. 이것은 **P06에 한정된 방향성 검사**이지 25개 이미지 전 면에 대한 UV 정합 판정이 아니다.

## 3. 확인된 정확성 결함 및 아직 미확인인 부분

### T4-A — `UVLOCK_NOT_APPLIED`

**영향 사례:** `R03-inner`

- 원본 `1.21.11/assets/minecraft/blockstates/acacia_stairs.json`의 `facing=east,half=top,shape=inner_left` 항목은 `model=minecraft:block/acacia_stairs_inner`, `uvlock=true`, `x=180`이다.
- `prepare.py`는 `uvlock=true`를 렌더 입력에 전달한다.
- 그러나 `blender_batch.py`의 요소·면 UV 변환에는 `uvlock` 처리 경로가 없다.
- 그러므로 현재 출력이 원본 블록상태의 UV 고정 규칙을 준수한다고 판정할 수 없으며 **이 기능의 구현 누락은 확인됨**.
- 임의의 UV 회전값을 추측해 고치지 않았다. 후속 수정에는 독립적으로 확인 가능한 기대 UV와 재검증이 필요하다.

### T4-B — `PER_FACE_TEXTURE_ORACLE_NOT_COMPLETE`

**영향 범위:** 25개 PNG 전부

- 독립 실루엣 검증 + P06 방향성 검증은 완료했으나, 모든 렌더 면의 픽셀/텍스처 좌표를 Minecraft 표준 기준과 대조한 증거는 아직 없다.
- 이 공백을 '렌더링 25/25 성공'으로 메워서 전체 PASS를 주장하지 않는다.

### 기타 범위 경계

- Actions 한 Job 안에서 다른 Blender 프로세스로 12개 이후 재개: 확인.
- 서로 다른 GitHub Actions Job 또는 실행 회차 간 체크포인트 복원: 이번 TV-001에서 입증하지 않음.
- Minecraft 클라이언트 실행과 Blockbench 웹 직접 조작: 이번 계약에서 제외.
- AI 유료 API: 사용하지 않음.
- 바닐라 전체·가구 모드 전체 연구 완료: 이번 기술 검증의 대상이 아님.

## 6. 재작업 확대 방지 및 후속 후보

이번 TV-001의 사례 12개와 이미지 분모 25개를 늘리지 않는다. 종료 심사를 마친 뒤 아래 항목을 기존 오류/추가 검증의 **후속 후보**로 분리한다.

1. `R03-inner`의 `uvlock` 규칙을 확인 가능한 Minecraft/독립 기준에 맞춰 구현하고 고정 사례 재검증.
2. 동일한 25개 렌더링 면의 독립적인 텍셀·UV 기대값 검사 절차 수립.
3. 필요할 경우 별도 범위로 Job 간 체크포인트 복원 시험. (이번 T7의 증거로 승격 불가)

**우선순위 제안:** 검증된 기하 투영을 유지하면서 `uvlock`과 면별 UV 정확성 근거부터 보완한다. 새 바닐라 본 연구에 들어가기 전에 이 제한을 인지하고, 부정확할 수 있는 렌더 화면으로부터 근거 없는 디자인 특징을 확정하지 않는다.
