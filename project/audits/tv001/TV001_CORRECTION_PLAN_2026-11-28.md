# TV-001 후속 결함 보완 실행계획 (2026-11-28)

상태: 기존 계약 v1.1 안의 결함 보완 착수. 기존 CLOSED_PARTIAL 종료 기록은 역사 증거로 보존한다.
기준 head: c0ec53cef51da2537341ea75f0693bb312f04254.
원본 pin: 176f7f34de2336eb7984c4734e97b6eb156c19f4.
분모 고정: 사례 12개, PNG 25개, 카메라/원본/실행 조건 기존 계약 유지.

## 사전 조사
실제 blender_batch.py는 instance x/y를 적용하지만 uvlock을 소비하지 않는다. R03-inner에 영향. t4_independent.py는 독립 실루엣 및 P06 방향 검사만 수행하며 Minecraft 전면 UV 참조는 없다. t8_close.py는 P06 실패, 범위 불일치, T4 FAIL 등 일부 필수 조건을 최종 판정에 반영하지 않는다. T0 재사용 감사도 PARTIAL이다.

## 범위 및 순서
| 단계 | 작업 | 통과 기준 |
|---|---|---|
| A | T8 집계 결함 수정 | 범위 불일치, P06 실패, T4 FAIL 및 필수 기본 실패 시 FAIL; HOLD 유지; T0/정확성 미완료 시 PASS 금지; 회귀 테스트 |
| B | 원본 규칙 및 기대 UV 조사 | 실제 버전의 확인 가능한 기준, 면별 방향/좌표, R03-inner x=180/uvlock=true 기대값 기록. 근거 없으면 HOLD |
| C | UV 구현 수정 | B의 기준을 만족하는 구현, 원래 입력 12개 유지. 기존 UV 미적용과 차이를 독립 검증 |
| D | 고정 전량 회귀 검사 | 25개 PNG, 기존 형상 및 P06, 12→13→0 재개, 수정 UV 기대값 대조; 전면 미검증은 별도 기록 |
| E | T0 및 T8 재심사 | 재사용 대상 모듈 실제 확인, 각 단계별 결과 및 미검증 구분; 실행 로그와 해시 보존 |

A는 B의 결과와 독립적으로 수행한다. B 이후에는 검증된 Minecraft 기준을 확보하기 전 추정 UV 수정 금지. 전면 텍셀 정확성 증거 미확보 시 PARTIAL/HOLD를 유지한다. 기존 Job 간 체크포인트 복원은 별도 범위이며 이번에 추가하지 않는다.
실행은 기존 TV-001 Actions; 실패는 원인에 한해 수정, 같은 범위 재검증. 이전 보고서 및 main은 변경하지 않는다. 신규 연구는 이 보완 이후 품질조사 사전조사와 범위/계획 확정을 거친다.
