# RQ-001 기존 연구 자료 품질 사전 조사 및 범위 제안

상태: 사전 조사 완료(목록·대표 종료 문서·기존 스키마 확인), 정식 조사 범위/계획은 제안 단계. 본 품질 감사는 미실행.
원본 고정 main: 176f7f34de2336eb7984c4734e97b6eb156c19f4. 작업 PR head: bf9fa1b4ef2db658fdb7d7548174fbff5ff00288. 이전 31,330경로 전수 Git 트리 목록의 비원본 3,167경로를 다시 열거하고 SHA/크기/형식 원장을 생성했다.

- 기타 자료·문서·운영 코드 256경로. 합계 3,167경로, Git 트리 절단 없음.
- 별도 원본 트리 28,163경로: 이번 품질 감사의 전수 본문 재분석 대상에서 제외 제안. 단 등록 원장 4,768개에 대한 원본 재해시 검사는 별도 게이트로 포함.
- 역사 SQLite 9경로 / 고유 blob 8개. legacy-info가 직접 다루는 것은 3경로. data/v8과 research/v8은 동일 blob이지만 위치별 보존.
- 운영 카탈로그 스키마 v4: 8개 테이블. 문서의 25,387 등록 자산은 과거 고정 분모이지 전체 릴리스 분모가 아니다.
- 비원본 동일 blob 7그룹, 14경로. 동일 내용만으로 삭제/불필요 확정 금지.

## 제안 범위
A. 3,167개 비원본 경로 전수 본문 Git blob/크기 재계산, 형식별 읽기/검사(압축·JSON·CSV·SQLite·이미지·문서·코드), 실패/미지원 구분. 파일마다 원장 결과 1행.
B. SQLite 9경로(8 고유 blob) 읽기 전용 integrity_check/foreign_key_check, 테이블·컬럼·행수·키·참조 목록. 동일 blob도 경로별 연결 기록. 기존 DB 변경 금지.
C. 기존 카탈로그 4릴리스 25,387개 등록 재현 및 기존 원장과 대조; 바닐라 4,768개 실제 bytes 재해시. 외부 모드 원본은 동일 pin 확보 가능할 때만 독립 대조, 불가 시 HOLD. 기존 20,619개 모드 원장 등록과 실제 외부 원본 대조를 혼동하지 않음. 정확한 원본 확보 방법과 외부 범위는 실행 전 확정.
D. 기존 자료를 데이터 명세 14영역과 연결. 각 경로별 역할/증거 유형/검증 상태/재사용 분류(재사용 가능·재검증 필요·역사 참고·중복/불필요 후보) 및 근거. 다목적 파일은 복수 영역 허용. 의미적 추론 전수 정확성 인증 아님.
E. 미확인·상충·누락·중복 후보, 근거 연결 및 DB 상세 설계 인계표. 기존 자료 삭제/마이그레이션/신규 본 연구/렌더 확대 제외.

## 상세 실행계획에서 정해야 할 조건
고정된 TSV 기준으로 100~250파일 배치 또는 형식별 배치; Git Actions에서 읽기 전용 원본을 해시하고 결과만 아티팩트화. 압축/SQLite 크기와 메모리를 사전 확인해 스트리밍/임시 파일 방식 사용. 결과 원장은 path, source_pin, expected/actual digest, format, checks, evidence, status, classification, reason을 포함. 체크포인트는 배치별 입력 SHA와 결과 SHA, 분모·실행 수·통과 수를 분리. 중단 복원은 실제 검증 전 보장하지 않는다. 완료 조건은 전 경로에 검사 결과/분류 또는 명시적 HOLD/FAIL 기록과 DB/원장/14영역 대조 증거. 검증 실패·근거 부족을 자동 PASS하지 않는다.

본 문서는 제안이며 최종 범위·배치·상세 실행계획을 별도 확정한 뒤 실제 감사 시작. main 및 과거 자료 변경 없음.
