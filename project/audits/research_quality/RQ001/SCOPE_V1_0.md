# RQ-001 품질 조사 고정 범위 v1.0 (6-B)

사전 조사 커밋 c8db50c7cb2af583de38b69a438121b09d4e9e9b; 기준 main 176f7f34de2336eb7984c4734e97b6eb156c19f4. 기존 연구 자료의 재사용 적합성 감사이며 바닐라/모드 본 연구나 DB 이관이 아니다. 계약 v0.6 C1→C2→C3 준수. 이번 사용자 계속 진행 요청에 따라 이전 제안의 분모를 유지하고 세부 실행 기준을 확정한다.

## 포함 범위
| 게이트 | 고정 분모 | 검사 목적 |
|---|---:|---|
| D | 3,167 비원본 경로 | 실제 bytes, Git blob 및 형식 수준 읽기 검사 |
| E | 9 DB 경로 / 8 고유 blob | 읽기 전용 무결성·FK·테이블·컬럼·키·행수 |
| F | 25,387 등록 자산 / 4 릴리스 | 기존 원장→임시 카탈로그 재현 및 원본 pin·bytes 대조 |
| G | 14 데이터 영역 | 기존 근거의 존재·연결·공백·신뢰성 수준 |
| H | 3,167 비원본 경로 | 재사용·재검증·역사·중복 후보 분류 |
| I | D~H 전체 | 분모·해시·판정·보존의 독립 심사 |

원장 7개 Git blob과 SQLite 9경로 및 릴리스 pin은 [scope_lock.json](scope_lock.json)에 고정. 동일 blob은 경로별로 계산하고 7그룹/14경로는 중복 후보일 뿐이다. F의 바닐라 4,768개는 D 분모와 별개이며 외부 모드 20,619개는 동일 릴리스 확보가 필수. 원장 재현만으로 원본 검증을 인정하지 않는다.

## 명확한 제외
원본 트리 28,163개의 새 구조/디자인 전수 분석(단 F의 4,768개는 재해시), 새로운 모드/버전, 신규 렌더·게임 실행, 전체 의미/부품 정체 및 제작 기법 재연구, 운영 DB 스키마 변경·이관·삭제, main 병합 제외. 기존 인게임 관측은 역사 근거로 보존. 외부 원본은 임시 작업공간에서만 취급하며 재배포하지 않는다.

## 판정
D/E/F의 파일·행 단위 확인과 G/H의 근거 수준을 독립 기록. 파일 형식 PASS는 내용의 사실성 PASS가 아니다. H의 재사용 가능은 명시된 제한에서만 인정하며 근거 미확보 시 재검증 필요/역사 참고로 분류. 중복 후보는 별도 플래그로 유지. 모든 필수 검사 통과 시에만 전체 PASS; 확인 불가 HOLD, 불일치 FAIL, 제한 범위만 종료할 경우 PARTIAL. 종료 심사 이전 분모 확장 금지.
