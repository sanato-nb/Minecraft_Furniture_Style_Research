# H/I 분류 불일치 원인 및 수정

재실행 #46136769242 (job 140953704039)에서 기대 집계 assertion이 실제로 실패했고 I는 실행되지 않았다. 원인: H가 defaultdict(list)인 gmap의 존재하지 않는 경로를 `gmap[p]`로 읽어 빈 목록을 삽입한 뒤 `p in gmap`을 판정했다. 모든 경로가 근거 매핑 경로처럼 처리되어 버전별 역사 경로 규칙까지 도달하지 않았다. 읽기 전용 `get(p, [])`, 사전에 고정한 frozenset, 매핑 집합 불변 assertion으로 수정. 독립 I의 별도 경로 판정과 집계 회귀 검사는 유지. 예상 2268/11/14/874; 실제 재실행 전 PASS 금지. 원본·범위·분류 정책 변경 없음.
