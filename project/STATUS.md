# 하네스 개발 현황

이 문서는 하네스 개발 현황의 기준이다. 이전 연구의 증거와 인계 기록은 [기존 연구 기록 색인](HISTORY.md)에서 찾는다.

- 기존 1단계 고정 연구 범위 **5/5 종료 승인**: `docs/PHASE_1_SUMMARY.md`가 역사 연구의 기준이다.
- 기존 연구 원본·Git 고정 SHA·기존 `handoff/STATE.json`은 **이동/수정하지 않았다**.
- H0: 전체 Git 트리 32,148항목(파일 31,242개) 기록. 기준 커밋의 경로·모드·blob 보존을 새 CI 게이트에서 검사하고 1-3-F 인계 DB와 1-5-E 비교 DB의 기존 감사를 재실행한다.
- H1: 공통 정책, Vanilla/Mods 프로필, 공개 inbox 가이드, 읽기 전용 설정 검증·계획 출력, 1-3-D 고정 Mods 엔진 검사 진입점까지 도입했다.
- 최초 CI 기록은 `project/audits/H0_VERIFICATION.json`에 있다. 보강된 감사의 검증 방법 및 산출물은 [감사 자료 안내](audits/README.md)에 있다.
- Mods 런타임 재실행과 대표 배치 캡처는 [런타임 감사](audits/runtime/README.md)에 기록했다. 업데이트 추적과 원본 경로 이관은 후속 단계다.
- 기존 `main` 푸시 워크플로의 위험은 `project/audits/H0_MIGRATION_CLASSIFICATION.md` 참고; 이 PR에서 수정·실행하지 않았다.
- 이 작업은 PR #12에서 검토 중이며 `main` 병합은 사용자가 결정한다.

## H2 공통 연구 DB

- 버전·자산·연구 회차 SQLite 등록·조회와 4개 연구 모드의 기준 릴리스 검증을 구현했다.
- 기존 원장에서 고정 버전 4개와 자산 25,387개를 가져오고, 역사 SQLite 3종을 읽기 전용으로 조회할 수 있다.
- [DB 사용법과 연결 범위](RESEARCH_DB.md)

## H3 공통 연구 엔진

- DB에 등록한 연구 회차로 원본 검증, 증분 범위 계산, 기존 1-2-G·1-3-F·1-5-E 감사 재실행을 수행한다.
- 검증 결과와 실패 및 재시도 이력을 DB에 남긴다. H2 운영 DB는 버전 2로 이관할 수 있다.
- 바닐라 4,768개 원본과 Macaw JAR 3,999개 자산 검증을 확인했다. [공통 연구 엔진 사용법](RESEARCH_ENGINE.md)

## H4 연구 작업 재개와 AI 호출 제어

- 원본 검사 체크포인트를 최대 64개씩 SQLite에 저장하고 같은 작업 ID로 재개한다.
- 요청 미리보기, 승인 해시, 요청 크기·출력 토큰 한도, 중복 전송 차단을 적용한다. AI 답변은 추론으로 별도 기록한다.
- 실제 원본 검사 재개와 모의 API 응답을 검증했다. [실행과 승인 방법](RESEARCH_WORKFLOW.md)

## H5 연구 확장 모듈

- 바닐라·모드 배포 메타데이터를 비교하고, 회차별 검증 범위와 통과율을 집계한다.
- 기준 캡처의 SHA-256 및 픽셀을 자동 비교하고, 통과한 서로 다른 연구 대상의 정적 관찰을 교차 집계한다.
- 승인한 동일 범위 요청의 AI 응답을 재사용하고, 모델별 사용 토큰과 재사용 회수를 집계한다. [확장 모듈 사용법과 범위](RESEARCH_EXTENSIONS.md)

## H6~H7 통합·실전 검증

- Adorn 7.6.0의 4,340개 자산을 신규 등록하고 체크포인트에서 이어서 검증했다.
- 7.6.1 증분에서 사라진 경로 1,503개를 확인했고, 별도 FRESH 회차로 남은 2,837개를 처음부터 재검사했다.
- 바닐라 교차 비교, JAR 원본 텍스처 픽셀 대조와 승인 해시 차단을 확인했다. [실전 검증 결과와 재현 명령](audits/h67/README.md)
- H7 후속 런타임에서 Adorn 두 버전의 등록 상태 41,211개와 충돌 상자 175,032개가 일치했다. 사라진 최상위 경로 1,503개는 조건부 오버레이의 동일 파일로 확인했다. [엔진·로그·시각 확인](audits/adorn_runtime/README.md)
