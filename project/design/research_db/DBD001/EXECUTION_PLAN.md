각 검사는 실제 실행 여부와 PASS/FAIL/HOLD/PARTIAL을 별도 기록한다. SQL 제약만으로 보장 불가한 의미 검증은 애플리케이션 책임과 회귀 테스트를 명시하고, 검증되지 않은 기능을 통과로 표시하지 않는다. 임시 SQLite, Python 3.12, Ubuntu GitHub Actions 단일 Job 20분 상한. 외부 모드 다운로드/게임/Blender/유료 AI API 불필요. 원본과 운영 DB를 쓰지 않고 테스트 디렉터리에만 생성. 배치/체크포인트는 고정 해시와 입력 동일성, 커밋 후 복원, 중복 처리 금지 설계를 포함한다. 테스트 산출물은 30일 아티팩트 및 영구 요약/해시/재현 코드로 보존한다. 실제 운영 도입은 별도 승인과 실행계획 이후. 범위 밖 새 연구는 후속 후보 기록만.
