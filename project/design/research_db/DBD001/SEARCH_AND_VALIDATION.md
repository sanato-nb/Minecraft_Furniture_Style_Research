# DBD-001 7-G 검색 및 검증 계약 v1.0

설계 전용 구현 `design_contract.py`와 합성 fixture `design_tests.py`는 운영 API가 아니다. 고정 T01~T16에 대응하는 시험의 제한을 각 결과에 기록한다. 실제 데이터베이스 이관, Minecraft 모델의 진실성, 렌더링 정확성, 대량 성능을 여기서 입증하지 않는다.

검색: parameter binding으로 용어(label, term_kind), 릴리스, 측정 metric/unit/min_value를 제한한다. claim의 같은 snapshot/object/key 최신 revision을 선택한다. confirmed_only 기본 true. 최신 범위별 assessment의 실제 선택 결과와 근거 실물 SHA를 재검사하며, CONFIRMED/PASS·유효 SUPPORT 및 링크 근거·기법 승인·충돌 여부를 확인한다. 불완전/후보는 confirmed_only=false에서 명시적으로 usable=false. 수치 필터는 동일 단위만 비교; 임의 단위 환산 없음. JSON 반환은 버전, 필터, 주장/조건/한계/원본 경로, 근거 메타데이터, 측정, 판정 및 반례를 함께 포함. 원본 바이너리 노출 없음. 단일 fixture의 서로 다른 두 근거 body는 기법 승인 최소 조건을 시험하기 위한 예이며 실제 독립 모델 사례 증명은 연구 검수자의 책임이다.

시험은 SQL 제약과 별도 계약 함수의 양성/음성 경로를 확인한다. 조회 결과는 데이터베이스 권한 있는 환경에서 읽는 설계용 결과이며, 외부 공개 시 locator/권리 상태에 대한 추가 정책이 필요하다. 현재 입력 식별자 검증, 원본 파서/의미적 정확성, 전체 운영 트랜잭션 통합, 대규모 검색 성능, 실제 외부 보존 위치 복구는 구현·검증되지 않았다. 이 범위가 필요한 시험은 PARTIAL로 남기며 전체 PASS로 승격하지 않는다.

## 7-H 보완
판정/집계/선택 이력은 UPDATE/DELETE/REPLACE 금지. 저장된 선택의 최신성 및 집계 일치 재확인. 고정 scope에 포함된 것만으로는 부족하여 해당 원본과 필수 검사 단위가 연결돼야 확정 검색된다. 권리 제한/미확정 원본 및 claim 근거는 후보 검색에서도 행 전체 제외, 제한 측정 근거는 측정 결과 제외. 외부 접근 권한/인증·전체 민감 데이터 제거는 별도 운영 계약. 재현 근거에는 fixture_oracle 지문도 포함. 백업은 모든 사용자 테이블의 타입 보존 논리 행 해시·app_id·user_version까지 비교하며, 이 구현은 소규모 설계 시험에 한정한다.

## H-B01/02 후속 교정
범위 잠금 이후 분석 snapshot/object 생성과 render_output 연결을 합성 fixture에서 재현한다. 최신 시도에 결과가 없거나 미완료인 경우 기존 PASS 검색을 차단하며 완료된 다른 task의 결과도 해당 요구 항목에 사용할 수 없다. 고정 16개 시험의 분모 및 기존 PARTIAL 한계는 유지한다.

## H-B03 후속 교정
기법 지지 원본은 등록 SHA256/SHA1/GIT_BLOB_SHA1에 대해 실제 바이트를 다시 해시하고 승인 manifest는 동일한 SHA256 실물 지문을 유지한다. 검색에서는 관련 claim의 원본·근거·기법 승인·단계, 선택된 판정과 참조/PNG/log, 범위 manifest/plan의 제한·미확인 권리를 확인한다. 제한된 관련 주장/판정은 후보 검색에서도 해당 행을 제외한다. 원시 저장 locator와 관계의 자유문 사유는 export에서 제외한다. 릴리스 provenance에 제한 기록이 존재하면 차단하되 fixture의 provenance 부재를 운영 인증으로 간주하지 않는다. 실제 호출자 인증, 전체 비공개 필드 및 자유문 검수, 실제 운영 권한 정책은 별도 승인 단계이며 T11/T13 PARTIAL 유지.
