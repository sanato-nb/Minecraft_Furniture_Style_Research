# INT-3 의미 분석 1차: 부품 후보·기하 형식·표본별 역할 인계 독립 감사

검수 기준일: **2026-11-21**, 소스: 고정 1-3-C/PARTS.csv.gz + 1-3-F SQLite + 1-3-E 상태 표본 + 1-5-E 비교 판정 + 기존 INT-3 관계 지식 DB.

**실제 판정:** `PASS_SOURCE_SCOPED_GEOMETRY_AND_ROLE_CANDIDATES`.

이 결과는 **원본 연구에서 근거가 있는 만큼만 의미 관계를 연결**한 성과다. 모드 파일 이름을 통해 새 역할·스타일을 추측하거나 1,911개 요소를 전부 기능별로 분류했다고 주장하지 않는다.

## 1. 원본 C와 F 교차 확인 결과

`research/furniture_mods/phase_1-3/C/PARTS.csv.gz`의 **전체 1,911개** 행을 실제 gzip 해제 후 읽고, 각각의 제공자 모델 키·요소 번호를 1-3-F `element`와 교차 대조했다. 분류·후보명·후보 근거가 동일한지, 원본 좌표로 다시 계산한 치수·중심이 C 원장과 일치하는지 대조했다. 이를 통과하지 못하면 INT-3에 등록하지 않는다.

| 기하 유형 (C 기존 명칭 그대로) | 원본 요소 |
|---|---:|
| ELONGATED | 639 |
| SLAB | 526 |
| SOLID | 467 |
| PLANE | 279 |
| **합계** | **1,911** |

기하 종류는 **형태 계측 결과**이지 다리·좌판 등 가구 기능이 아니다. 해당 요소의 소스 좌표, 중심, 적용 텍스처 슬롯, 영두께 축, 역방향 좌표 축, 기하 체적을 함께 저장해 추후 새로운 가구 구조 비교에 사용할 수 있게 했다.

## 2. 실제 근거가 있는 부품 후보 45개

| 원장 부품 후보 | 요소 수 | 한계 |
|---|---:|---|
| LEG_OR_LOWER_POST | 16 | 다리 또는 하부 기둥 **후보** |
| BACKREST_ASSEMBLY | 16 | 등받이 조립 **후보** |
| LOWER_FRAME | 7 | 하부 프레임 **후보** |
| SEAT_LAYER | 6 | 좌판 층 **후보** |
| **합계** | **45** | **시각 검증 완료 0개** |

1-3-C 원본 분석 스크립트는 **Another Furniture 두 의자 템플릿, Handcrafted 의자 원형, Macaw 의자 원형**의 요소 번호를 기하·면 슬롯 근거로 특정했을 뿐이다. 45개는 `GEOMETRY_AND_FACE_SLOTS`라는 **부품 후보 근거 등급**을 가진다. 텍스처 슬롯과 위치는 확인했지만 그 부품의 실제 렌더 또는 사용 기능이 검증됐다는 뜻이 아니다.

나머지 **1,866개 요소**는 `UNDETERMINED`·`GEOMETRY_ONLY`로 유지했다. 미검수 요소가 곧 부품이 없거나 의미가 불명확한 이상 모델이라는 뜻이 아니며, 아직 역할을 판정할 증거가 충분하지 않다는 의미이다.

## 3. 가구 표본의 역할 후보 94개를 별도로 보존

기존 1-3-E에서 F의 `sample_part`에 연결된 **47개 상태 표본**, **94개의 부품 역할 주장**을 `historical_sample`과 `sample_part_candidate`에 분리했다. 상판·손잡이·물 표면·침대 프레임·선반·화분 테두리 등 서로 다른 유형의 역할을 포함한다.

이들 94개는 **원래 사례 ID·규칙 인덱스·제공자 요소·기록된 판단 근거**와 함께 유지한다. 45개 의자 역할 후보와 서로 다른 표본 단위이며, 둘을 중복 제거해서 '검증된 139개 고유 부품'이라고 계산하지 않는다.

## 4. 자동 검수 대기열과 금지한 자동 확정

| 신규 검토 큐 | 건수 | 현재 상태 |
|---|---:|---|
| 원본 의자 부품 후보의 실제 렌더·의미 시각 확인 | 45 | PENDING |
| 1-5 후보 비교 14건의 적용 조건·반례 확인 | 14 | PENDING |
| **합계** | **59** | 시각/조건 검토 결과 승인 0 |

`verified_material_style`은 **0행**이다. PNG 리소스 이름이나 모드 이름만으로 나무 재질·광택·현대적 스타일·사용 기능을 확정하지 않았다. 역할이 실제로 확정된 `ai_approved_semantic_part` 조회 역시 **0행**이다.

원본 라이선스 및 재배포/AI 학습 사용 승인 또한 이번 의미 분석으로 변경하지 않았다. `ai_training_eligible_model`은 계속 **0개**다.

## 다음 연구 과제

1. **INT-3 시각 검수:** 원본 요소 45개를 렌더·원래 가구 배치 형태로 확인해 각 좌판/다리/등받이 주장이 맞는지 판정. 이 단계에서 실제 이미지를 보지 않으면 시각 확인 성공으로 표기하지 않는다.
2. **표본 범위 확장:** 94개 표본 역할의 카테고리별 검증. 원본 1-5의 21개 판정을 보편적인 스타일/설계 치수로 승격시키지 않는다.
3. **재료/스타일 의미 학습:** 실제 원본 PNG와 렌더 근거 및 권리 확인이 되는 경우에만 사용 가능. 사물의 RGB 통계, 텍스처 슬롯 이름, 기하학적 형태만으로 재료의 현실 물성을 확정하지 않는다.
4. **가구 생성 PoC:** 제삼자 에셋을 무단으로 훈련시키지 않고 직접 작성한 새 모델의 구조·면·UV와 실제 인게임 검증을 위한 별도 시험을 추진한다.

**현재의 완료 범위는 INT-3 의미적 근거 관리·원본 후보 검수 큐 생성이며, 완성된 스타일 온톨로지나 가구 생성 AI가 아니다.**
