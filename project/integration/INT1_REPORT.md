## 분모 및 검증 구분

1. 3,167개는 고정 기준의 **연구 결과·문서·도구 파일 목록**이다. 자산의 미가공 원본 바이트를 전수 재검사한 기록이 아님.
2. `1.21.11/`의 추출 자산은 INT-1 목록 밖에 둔다. H2는 Vanilla 4,768개, Another 2,994개, Handcrafted 13,626개, Macaw 3,999개 = 25,387개의 등록 자산 원장을 별도로 관리한다. 이 숫자를 3,167개에 더하지 않는다.
3. 기존 1단계 `5/5 종료`는 각 단계가 승인한 고정 연구 범위 기준이다. AI 학습 품질·부품 의미·권한·대규모 재현 정확도는 별도 단계에서 심사한다.
4. PR #17의 공통 1-3-C 엔진은 새 브랜치에 합치지 않았다. `main` 기준 분석 도구와 PR #17을 섞어 동일 엔진이라고 주장하지 않는다.
