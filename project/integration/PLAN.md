# 기존 1단계 연구 통합·독립 검수 실행계획 (INT-0 ~ INT-7)

작성 기준: 2026-11-21. **최종 목적: AI가 새로운 마인크래프트 가구 모델·텍스처를 직접 만들고 검증할 수 있는 재사용 가능한 연구 지식 구축.** 과거 1-1~1-5 연구의 '고정 범위 완료'는 새로운 AI 제작 적합성 승인을 의미하지 않는다.

## 공통 계약

- 과거 연구 산출물·원본·기준 Git SHA·역사 DB는 **수정/이동/삭제/덮어쓰기 금지**. 수정 정보는 새 증거/정정 연결로 기록.
- 신규 파일은 `project/integration/`, 도구는 `scripts/integration/` 또는 검증된 범용 `src/mcfr/`, 테스트는 `tests/harness/`에 격리한다.
- `main`에 직접 푸시하지 않고 별도 브랜치·PR로 검토. PR #17의 1-3-C 공통 엔진은 미병합 코드이므로 독립적으로 버전·SHA를 기록한다.
- 검사 결과에는 항상 (a) 원본 동일성 (b) 정적 계산 (c) 인게임 관찰 (d) AI 해석 (e) 법적 이용 권한을 분리한다. 한 범위의 PASS를 다른 범위로 자동 승격하지 않는다.
- 오류나 누락을 발견해도 과거 성과를 임의로 지우지 않는다. 감사 실패/보류/정정의 별도 레코드를 남긴다.
- 기존 모델 경로 수, 실제 기하 원형 수, 상태 인스턴스, 면 인스턴스, 원본 PNG 수는 **서로 다른 분모**이며 합산하지 않는다.

## INT-0: 기준·원본 고정 (현재 작업)

입력: `main@176f7f34de2336eb7984c4734e97b6eb156c19f4`, `docs/PHASE_1_SUMMARY.md`, 고정 감사 보고서, H2 SQLite, 역사 DB 스키마.

수행: 별도 브랜치 생성, `INT0_BASELINE.json`으로 정본 및 고정 SHA 기록, 별도 미병합 PR과 기초 사용 권한 범위 명시. 기준 변경은 별도 버전과 재감사로만 허용.

종료 게이트: 원본 기준 커밋·정본 링크·스키마·별도 브랜치·불변 보존 정책을 모두 특정하고 재현 가능.

산출물:

## INT-2: 기존 연구별 독립 재감사

1. 1-1: 지정 PNG 150종을 실제 디코딩하고 SHA·PNG 구조·CRC·RGBA 및 기존 재질 분류 근거 재검토. 기존 Git blob 일치만으로 픽셀 수치 일치를 주장하지 않는다.
2. 1-2: 공식 버전/원본 4,768개와 모델 기하·상태·UV·사이드카의 계산 검산. `cube_mirrored` 과거 F 출처 공백과 G 보완 정보를 분리해 추적한다.
3. 1-3: 모델 16,572개와 상태 1,158개를 당시 고정 원본에서 독립 재실행. 1-3-C 기하·회전 AABB를 별도 산식으로 검산. 동적 렌더·부모 누락·미해결 108경로를 이유별 관리.
4. 1-4: 592,312면과 원본 화소 근거 585,969면/미근거 6,343면의 정확한 분모·링크·PNG/UV 계산 재현. 미근거를 자동 오류/성공으로 변경하지 않는다.
5. 1-5: 21판정(규칙 후보14·반례/조건부7)을 개별 출처·관측값·후속 런타임 근거로 재대조. 보편 제작 규칙으로 곧바로 승격 금지.

각 항목은 PASS, PARTIAL, FAIL, BLOCKED와 `source_sha`, `analyzer_sha`, `audit_execution_id`, 미해결 원인을 기록한다. 검증 불가한 외부 JAR/런타임 입력은 미실행으로 명시한다.

## INT-3: 비파괴 통합 DB 구축

H2의 `release`/`asset` 기반 원본 키와 역사 1-3-F의 model/geometry/element/face/texture/state/option 및 1-5-E의 study_case/finding/handoff를 별도 **증거 참조 테이블**로 연결. 결합키는 최소 `release_key + resource/path + source_sha`를 사용하고, 모델/부모/기하 제공자/상태 적용을 다른 개체로 취급한다.

기존 압축 SQLite를 직접 수정하지 않고 새 검증 DB에 복제/뷰를 구축. 관계·카디널리티·FK·중복/고아 참조·집계 불변식을 검사한다.

## INT-4: 단계 간 교차검증

모델→부모→요소→면→텍스처→PNG 원본→블록상태→실제 렌더 근거→연구 판정의 연결을 순차 대조. 모드/버전/로더가 다른 증거는 의도 없이 섞지 않는다. 런타임 후속 결과는 기존 정적 스냅샷에 날짜·범위를 붙여 연결하되 덮어쓰지 않는다.

## INT-5: 시각·의미 검증

1-5의 대표 모드 상태 47개·바닐라 대조군 15개부터 시작하고 위험성이 높은 연결형/투명형/특수렌더를 우선한다. 실제 렌더·고정 카메라·텍스처 픽셀과 정적 계산을 분리한다. 부품 의미(좌판·등받이·손잡이 등)는 형상 분류만으로 확정하지 않는다.

## INT-6: AI 제작용 지식 계층

사례별 입력 조건·부품 관계·좌표/회전/텍스처·출처·증거 유형·반례·권한·검증 버전을 연결한다. 먼저 **검증된 사례 검색과 생성기/렌더 검증 루프**로 제작 성능을 측정하고, 별도 모델 파인튜닝은 성능·권리·비용 근거가 있을 때 검토한다. 같은 기하 계보가 학습/평가 양쪽에 섞이지 않도록 분리한다.

## INT-7: 최종 독립 감사

원본과 과거 증거 불변성, 임의 표본이 아닌 합의된 분모에 대한 전체 정합성, 미해결 항목 격리, 실험 재현, 생성 결과의 독립 검증을 심사한다. **통합률 / 독립검수 수행률 / AI 활용 승인률**을 각각 분모 명시 후 산정한다. 저작권·라이선스 검토는 품질 등급과 독립된 필수 게이트다.

## 승인 레벨

- `A`: 동일 원본·정적 계산 및 해당 용도의 시각/런타임 검증까지 확인.
- `B`: 출처·정적 계산 완료; 시각/런타임 미확인. 구조 지식으로만 제한 사용.
- `C`: 부분 검수 또는 미해결 근거. 참고만 가능.
- `D`: 불일치/오류. AI 사용 차단.
- `H`: 미검수·원본 접근 불가·이용 권한 미확인. 사용 보류.
