# INT-4 — 모델링 연구 전용 H03/H05 종료 기준 간소화 및 재판정

작성일: 2026-11-25 (KST)  
기준: [원래 INT-4 D/F 독립 재감사 Draft PR #110](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/pull/110) head `7d0f7592520fa1a1f35b196391edda25de3e8499`.

## 1. 사용자 요청과 변경 목적

가구 모델링 연구가 실제로 필요로 하는 **원본 3D 모델·부모 상속·블록상태·텍스처/UV·대표 원본 F2 외형 근거**로 모델링 범위의 종료 여부를 판단한다. 더 이상 전체 GPU 면→화면 픽셀별 인과, 모든 게임플레이 시퀀스, 각 역사 프레임의 새 로그/수동 육안 재승인을 **고정된 70개 모델링 질문 전부의 필수 종료 조건**으로 사용하지 않는다.

**기존 엄격한 감사 기준과 과거의 HOLD/CONDITIONAL 원장을 수정하거나 통과로 가장하지 않는다.** 새 별도 게이트를 `MODELING_H03`, `MODELING_H05`로 명명한다. 원래 `H03`/`H05`와 별개의 판단 축이다.

## 2. 완화된 모델링 종료 게이트

| 구분 | 모델링 전용 PASS에 요구하는 근거 | 의도적으로 포함하지 않는 검증 |
|---|---|---|
| MODELLING_H03 | F70 V5의 62개 역사 모델·8개 위험 질문이 모두 모델링 전용 통과이고, 해당 모델/상태·원본 UV·실게임 F2 증거와 이유가 각 행에 기록되어야 함 | 모든 런타임 버전/상태, 모든 GPU 렌더러 면별 픽셀 인과, 수면/파괴/물리 전체 |
| MODELLING_H05 | 각 사례 원본 실행 ID·PNG SHA가 기존 엄격 F 원장에 정확히 일치하고, 20 ZIP/91 PNG 무결성 및 21 게임 로그의 기존 독립 감사 결과가 확인되어야 함 | 이번에 모든 원본을 새로 다운로드·수동 장면 판정했다는 허위 기록, 70건 전체 개별 로그 줄 강제 |
| 기존 H03/H05 | 원래 엄격한 전체 F 계약 적용 | 변경하지 않음 |

※ 정확한 출력 키는 코드의 `modeling_H03` / `modeling_H05`다. '모델링 전용 통과'는 선택한 연구 질문/가구/버전에만 한정한다.

## 3. 증거 재연결 및 수량

- 모델링 전용 기존 통과: **역사 가구 62/62, 위험 질문 8/8, 합계 70/70**. 신규 F2 촬영 없이 H23 V5 확정 원장을 계승하되, 별도 모델링 결과와 구 엄격 F70 원장의 **70개 정확 ID·실행 ID·이미지 SHA** 일치를 검사한다.
- 기존 감사의 원본 ZIP **20/20** SHA 및 CRC, 원본 F2 PNG **91/91** SHA/디코딩, 게임 로그 **21개** 인덱스(20개 캡처 JSON과 로그 SHA 연계)를 재사용한다.
- 원래 F 전체의 미해결 근거 등급 **6 / 38 / 26**을 그대로 기록한다. 6건은 정확 서버 상태 메타 부족, 38건은 사례별 로그 줄 없음, 26건은 프레임 인과 미승인이다. 이 사실을 숨기지 않는다.
- 원래 F 엄격 **70/70 CONDITIONAL, 0/70 무조건 PASS**, 원래 **H03 HOLD**, **H05 CONDITIONAL**, 전체 H 최종 무조건 종료 **0**.
- INT-5 부품 의미 승인 **0**, INT-6 학습·재배포 권리 승인 **0**, 전체 GPU 면→화면 픽셀 무조건 승인 **0**. 제삼자 리소스 원본 JSON/PNG/JAR/스크린샷 새 게시 없음.

## 5. 종료 판정과 인계
