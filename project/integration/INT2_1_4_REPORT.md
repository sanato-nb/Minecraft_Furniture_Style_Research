1. **다른 모든 가구 모델의 592,312면 전체 독립 UV·원본 픽셀 재계산**은 후속 감사 대상. 이번에 전수 확인한 원본 PNG 2,001개와 독립 원본 UV 1,794면을 혼동하지 않는다.
2. 예외 6,343면의 개별 원본·게임 런타임 의미 검증은 별도. 특히 슬롯 미결합과 자식에서 결합되는 경우를 구분해야 한다.
3. 실제 GPU 아틀라스/UV lock, tint, 필터링, 애니메이션 타이밍, 게임 동작·심미·AI 가구 제작 능력은 미검수.

## 4. 추가 독립 재검수: UV 예외 원본 화소 및 모델 결합 맥락

기존 C_followup의 보충 UV 영역 1,306행을 153개 실제 원본 PNG에서 다시 읽고, 원래 UV의 점·선·프레임·클리핑을 독립적으로 재계산했다. **1,306행 전부 RGBA·알파·색상·영역 SHA까지 일치**했다. 해당 원장에서는 고유 영역 1,298그룹이 모델 적용 면 74,260건의 보충 원본 화소 근거와 연결돼 있다. 원본 스프라이트와 교차하지 않는 2면 역시 별도로 재확인했다.

1-3-F의 고정 SQLite를 읽어 새 Python 관계 탐색으로 텍스처 슬롯 미결합 면 6,202건을 다시 분류했다. 자식 모델이 같은 제공자·슬롯에 실제 텍스처 경로를 결합한 맥락이 **6,196면**, 그런 자식 연결이 확인되지 않은 경우 **6면**으로 역사 후속 원장과 일치했다. 8개 누락 PNG ID의 원본 Git 경로 부재와 영향 면 139개도 독립 확인했다. 이는 *정적 DB·원본 파일 경로* 검증이지 인게임 결함 판정이 아니다.

## 5. 추가 독립 재검수: 일반 및 애니메이션 UV 전 영역 실측

기존 Entry02의 11개 UV 영역 압축 원장을 입력으로, 고정 원본 PNG **2,171개**를 직접 열고 각 UV를 0~16 좌표에서 이미지/애니메이션 프레임 픽셀 좌표로 다시 계산했다.

| 검수 단위 | 원본 독립 재검산 |
|---|---:|
| 일반·애니메이션 픽셀 영역/프레임 | **29,957행 전부 일치** |
| 고유 일반 사각형 UV 그룹 | 27,778개 |
| 측정한 각 영역의 원본 픽셀 총합 | 2,127,316 |

이전 감사의 전체 비영면적 그룹 29,083에는 **일반 사각형 27,778 + 예외 UV 1,298 + 실제 면에서 참조되는 누락 PNG 그룹 7**이 함께 들어 있었다. 이번에는 그 분모를 별도로 기록한다.

두 검수를 합하면 과거 1-4가 585,969면에 연결했던 **사각형/보충 UV 원본 영역의 PNG 픽셀 데이터를 독립적으로 재현**했다. 그러나 585,969개 면의 개별 연결을 모델 상태에서 전부 다시 생성한 것은 아니다. 개별 면의 *어떤 텍스처/UV가 채택되는지*를 전량 재구성하는 검사는 후속 범위로 남아 있다.
