## 1. 원본 입력과 정량 검증 결과

- 원본 연구 범위 45요소·229면 중 **HC11210/HC13 original elements 0..11 (12개), MACAW67/MACAW1424 elements 0..11 (12개) 총 24개**를 기존 실제 GitHub Actions ZIP 아티팩트 ID별로 **24개 직접 재다운로드**하여 검증.
- 모든 24 ZIP **CRC 정상**, 각 압축에 Minecraft Fabric **원본/소스1개 임시제거 2개 독립 게임 클라이언트**, 남·북×원본 이전·반복·다른 상태·AIR의 네 상태, 원본 F2 `16×24=384장` 개별 PNG SHA256 및 `2×24=48개` Minecraft 원본 client.log SHA256 검증.
- 화면 해상도 `1024×684`, ROI `(350,275,675,620)`, RGB 채널 최대 차 임계 `24`; 원본/제거 후 실제 PNG를 Pillow+NumPy로 새로 디코딩하여 **각 원본 인덱스별 남/북 화면 변화 픽셀·변화 점의 실제 XY bounding box**를 계산. 임시 제거 전/복구 시간 A/A·다른 상태·AIR 음성대조 모두 픽셀0, 원본 전경 바깥 변화0; 기존 B17/B18 자동 감사 원장 수치와 원본 24요소 모든 뷰 일치.
- [24요소 개별 ZIP SHA/원본 실험 artifact ID/남북 픽셀·bbox 및 B19 추가 측면 근거](INT5_B26_HC_MACAW_24_ORIGINAL_F2_SCREEN_SPACE_ELEMENT_REMOVAL_EVIDENCE_V1.csv). 원본 렌더 화면의 변경 위치를 확인할 수 있는 **스크린 공간 증거**로만 해석하며 실제 GPU face/UV 픽셀의 배타 귀속을 증명한다고 말하지 않는다.

## 2. 화면에서 직접 관찰한 부품 외형 가설과 주의

- **Handcrafted HC11210**: 실게임 원본 청록 의자. idx0/1/7/8 제거 시 의자 하부 가느다란 수직 기둥처럼 보이는 부분이 남·북에서 달라짐. idx2/9/10/11 제거 시 등받이 가로대·세로살처럼 보이는 부분에 화면 변화. idx6은 좌판 높이 주변 수평 부위 변화. 이 외형 관찰과 B3 역할 문자열은 **상호 부합 가능성**은 있지만, 착석 기능·하중 지지와 소재 성분 확정은 증명하지 않음.
- **Macaw MACAW67**: 실게임 원본 갈색 골격·주황색 부분이 있는 의자. idx0 제거 시 주황색 **넓은 좌판/등받이 표면처럼 보이는 영역 일부**가 사라지고 아래 원본 픽셀이 드러남. idx2..5는 서로 다른 하부 수직 기둥 모양 픽셀 변화, idx7·8 등은 등받이 양측 기둥, idx11은 좌판 아래쪽 수평부로 보이는 화면 변화. 색상은 **실제 PNG RGB의 관찰 색**일 뿐 재질이 가죽·나무 등 무엇인지 승인한 결과가 아님.
- 사진/원본 Java bytecode·모드 식별정보와 화면 범위 외에 부품 역할을 자동 확정하지 않는다. `LEG_OR_LOWER_POST`, `SEAT_LAYER`, `LOWER_FRAME`, `BACKREST_ASSEMBLY`는 모두 기존 **B3 original_role_hypothesis**이다.

## 3. 기존 B17에서는 화면 변화 없었던 HC idx3·4 실제 측면 복구

- 원본 HC index3: B17 남·북 실제 변화 `0/0`, [B19 실제 네 방향 원본 artifact ID 15046624386](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/actions/runs/45664823385) 재개봉해 **동 452픽셀 / 서 0픽셀**, 변경 위치 bbox `[488,465,530,476]`을 실제 PNG에서 별도 재계산.
- 원본 HC index4: B17 남·북 `0/0`, B19 artifact ID `15046724979` 재개봉해 **동 0 / 서 390픽셀**, bbox `[495,424,532,434]`을 별도 재계산. 두 원본의 이 측면 픽셀은 원본 GPU 얼굴 픽셀 소유의 유일 인과나 물리적 기능 승인이 아니다.
- **HC 12/12, Macaw 12/12** 각각 남/북 또는 B19 동/서 원본 제거 개입에서 최소 한 관찰 방향에 변화. B19 45원본 요소 전체 원형 렌더 인과 `43/45` 집계를 중복 증가시키지 않는다.

## 4. 재사용 및 안전 경계

- 두 모델 각각 12개 요소를 한 번에 배열한 **실제 F2 원본·임시 제거·변화 마스크 접촉시트**를 분석했으나 저작권·권리 근거 없이 GitHub에 원본 PNG/스프라이트나 수정 모드 JAR를 업로드하지 않았다. 접촉시트와 인접 원본 증거는 사용자에 대한 임시 작업 자료로만 제공한다.
- 원본 모델의 `source`와 `role_hypothesis`를 출처 SHA 및 원본 아티팩트 ID에 연결한 숫자·bbox/증거 분류 CSV만 Git에 저장. B24 45요소/229면 출처와 B23 원본 source5 10실험·320 F2 결과를 수정하지 않는다.
- INT5 외형 위치 확인은 **이번 B26 24/45 추가 완료**, 엄격 개별 face/UV GPU 독점 pix 0, 개별 부품 기능/재질/스타일 최종 승인 **0/45**, INT6 제삼자 AI 학습·배포권리 승인0, `H03 HOLD`, `H05 CONDITIONAL`, `F70 0/70` 유지.
- 남은 별도 시각 재개봉 대상은 AF121 10요소·AF123 10요소·HC idx12 쿠션 1요소. 각 원본 모델의 최신 실제 F2 및 서포트/접힘 상태를 혼동하지 않고 동일한 기하·UV/출처 규칙으로 검사해야 한다.
