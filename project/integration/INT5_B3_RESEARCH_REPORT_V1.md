# INT-5-B3 — 개별 요소 텍스처 역할 단서와 실게임 장면 독립 교차검증

작성일: 2026-11-25 KST · 직계 [INT-5-B2 Draft PR #114](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/pull/114) head `957b2b3a6f3db2b1087cc72b5458cf09b819d2d8`.

## 1. 목적·정확한 종료 범위

이번 작업은 **가구 3D 모델링 재사용 지식의 부품 역할 가설**을 정교화한다. 단순한 이름/그럴듯함으로 부품을 승인하지 않고, 원본 229개 소스 면의 실제 PNG 경로·face UV·element index, 직접 개봉한 Minecraft F2 16개 원본 장면, 기존 B2의 45개 부품 좌표/원본 SHA를 **각 요소의 정확한 키로 다시 검증**했다.

**INT-5-B3는 '원본 텍스처 역할 단서와 가구 조립체 외형의 양립 가능성' 연구가 완료되었다는 판정이다.** 개별 JSON 요소에 대응하는 실제 게임 픽셀의 고유 식별, 착석·지지 기능, 머티리얼·스타일의 최종 승인은 이 보고서가 승인하지 않는다.
