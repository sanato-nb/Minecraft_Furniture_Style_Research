# INT-3 가구 부품별 양시점 진단 검수판

이번 범위: **1-3-C/F 원본 신원과 부품 후보가 검증된 4개의 의자 모델에서 45개 요소를 각각 강조한 독립적인 기하 투영도를 작성**.

## 기존 PR #29와의 역할 분리

- PR #29에서 원본 AF/HC/Macaw JSON을 독립 재개봉해 SHA를 확인하고 네 의자 전체 조립 PNG를 만들어 **부품군 단위의 형태·배치가 타당**하다는 1차 검토를 완료했다.
- 이번 확장에서는 원본 1-3-C/F에 보존된 동일 모델 SHA를 사용해 **부품 하나만 강조한 45종 SVG(전체 조립 상태의 양방향 90개 시점 + 부품 단독 45개 시점, 총 135개 관찰 화면)**을 별도 생성한다. 원본 모델 JSON 재수집/다운로드와 PNG 접촉시트 생성기는 그대로 PR #29의 기존 구현을 사용한다. 여기서는 '어느 원본 요소가 후보 역할로 해석됐는지'를 빠르게 재검토하는 **부품별 검수 도구**를 추가한다.
- 기존 PR #29의 관찰 CSV를 재작성·승격하지 않는다. 이 그림만으로 새로운 시각 확정 판정을 만들지 않는다. 첫 실행본을 직접 확인하던 중 일부 요소가 조립 상태에서 한쪽 각도로 완전히 가려지는 점을 발견했으므로 **부품 단독 시점**을 반드시 함께 제공한다. 분리 화면은 실제 가구 배치가 아니다.

## 실제 실행

- 원본 모델 제공자 4, 모델 전체 요소 45, 강조 검수 요소 45, 조립 상태 양방향 요소 투영 90, 단독 분리 시점 45, 전체 조립 방향별 8.
- 각 요소의 원본 `source_from / source_to / pivot / angle / axis / rescale`를 다시 적용하여 생성한 회전 후 바운딩박스를 원본 1-3-F 회전 후 바운딩박스와 수치 비교한다. 달라지는 경우 생성 불가.
- 부품 후보 라벨은 1-3-C 원장과 1-3-F의 기존 역할 근거가 모두 일치한 경우에만 사용한다.
- 기본/넣은(tucked) AF 의자, Handcrafted 의자, Macaw 의자 원형을 포함한다.
- 색상·기하학적 화면은 연구용 진단 시각화일 뿐, 실제 Minecraft 텍스처·GPU 모델 베이크·UV lock·게임 스크린샷·기능/물성 증거가 아니다.
