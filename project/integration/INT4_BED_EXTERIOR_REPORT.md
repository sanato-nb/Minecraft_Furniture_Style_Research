# INT-4 Handcrafted 수면 외부 렌더와 발판 윗면 UV 검증

[PR #47](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/pull/47)에서 관찰한 Handcrafted 4.0.3의 실제 수면을 Minecraft 1.21.1에서 다시 재현했다. 원본 릴리스 모드와 검증된 Mojang 서버 JAR로, 루프백에만 바인딩하는 일회용 Fabric 서버를 실행했다. 침대를 사용하는 플레이어와 촬영하는 관전자는 서로 다른 실제 클라이언트다.

## 원본 텍스처 외부 관찰

| 상태 | 서버 판독 | 관전자 F2 |
|---|---|---|
| 설치 전 | 두 좌표 모두 공기 | 빈 바닥 |
| 설치 직후 | 발·머리 `occupied=false` | 흰색 오크 침대 |
| 수면 중 | 발·머리 `occupied=true`, `SleepTimer > 0` | 플레이어가 누운 침대. 사선과 정수직 두 시점 |
| Escape로 기상 | 발·머리 `occupied=false`, `SleepTimer=0` | 플레이어가 자리에서 일어난 뒤 같은 위치의 침대 |

사선 카메라와 조명 조건을 유지했다. 밤이 지나지 않도록 시간과 수면 비율을 제어했다. 정수직 F2를 찍기 직전 두 블록의 점유 상태를 서버가 다시 판독했다. 수면 중 F2에는 플레이어 모델이 일부를 가리므로, 원본에서 확인한 84면 중 각각의 가시성을 이 사진만으로 판단할 수 없다.

## 실제 픽셀 대조

- 대상은 북향의 흰 오크 침대 발(S37) 점유 모델에서 **요소 인덱스 5(0부터), `up` 면**이다. 원본 Git과 런타임 JAR의 모델·부모·텍스처 바이트를 대조했다.
- 원본 UV는 `[6.125, 7.875, 4.125, 7.5]`, 면 회전은 `180°`다. `#0 → #frame`을 따라 128×128 오크 프레임 PNG를 확인했다.
- 관전자에게만 진단 팩을 적용한 별도 실행에서 네 쌍의 텍셀, 총 8개를 빨강·초록·파랑·노랑으로 덮었다. 원본 모델, 서버 모드 및 플레이어의 리소스는 그대로 사용했다. 준비 과정에서 진단 팩의 우선순위가 모드보다 낮은 실행은 증거에서 제외했다.
- 정수직 화면의 10블록 바닥 폭을 기준으로 화면 배율을 측정하고, 발판 윗면의 높이와 UV를 사용해 네 표식의 화면 좌표를 계산했다. 발에 가려지지 않는 좌우 위치를 골랐다. 원본 화면에서 표식이 미검출되고 진단 화면에서 네 예상 위치가 모두 검출되는지 확인했다.

[결과 JSON](INT4_BED_EXTERIOR_RESULT.json)에 원본·런타임 해시, 서버 상태 전환, 각 F2의 SHA-256 및 좌표별 RGB를 기록했다. 색상 분류는 셰이더와 조명으로 달라지는 절대 RGB를 기대하지 않고 표식의 상대 채널 비율로 검사한다.

| 표식 | 실제 원본 화면 RGB | 진단 화면 RGB |
|---|---|---|
| `nw_red` | `[477, 440]` → `[175, 136, 84]` | `[477, 440]` → `[226, 17, 17]` |
| `ne_green` | `[547, 440]` → `[166, 128, 81]` | `[547, 440]` → `[18, 216, 17]` |
| `sw_blue` | `[477, 452]` → `[166, 128, 81]` | `[477, 452]` → `[18, 17, 212]` |
| `se_yellow` | `[547, 452]` → `[161, 124, 74]` | `[547, 452]` → `[226, 199, 17]` |

## 적용 범위

실제 외부 렌더는 이 침대 한 사례의 수면과 기상을 재현했다. UV 검증은 **발판 윗면 1개, 표식 위치 4개**를 다룬다. 나머지 면, 가려진 면, 다른 방향·모드·버전과 원본 RGB의 픽셀 단위 재현은 후속 범위다. INT-4 전체 완료 판정과 INT-5 의자 부품 45개의 개별 역할 판정은 별도로 남아 있다.
