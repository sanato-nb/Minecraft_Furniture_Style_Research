# INT-3 실제 Minecraft F2 사진의 타 실험 바닥 간섭 제거 결과

## 이전 사진의 실제 오류 원인
PR #33의 F2 촬영 16장은 실제 게임 사진이 맞다. 다만 Minecraft 1.21.1의 AF123 및 HC11210 사진 8장은 다른 의자에 부착한 7×7 smooth_stone 실험 바닥을 원경에 함께 촬영했다.
이전 월드는 AF121 z=40, AF123 z=54, HC11210 z=68에 시험 바닥을 두고 각각 카메라를 대상 남쪽에서 북향으로 설정했다. 그러므로 사진에 공중에 떠 있는 것처럼 보이는 회색 판은 의자의 3D 모델 부품이 아니다.
기존 F2 SHA별 검수 화소 수와 테스트 배치 좌표는 INT3_PR33_BACKGROUND_INTRUSION_BASELINE.json에 원본 그대로 보존했다.

## 배치만 바꾼 실제 재촬영
원본 의자 자식 모델 4개, 16개 상태와 y 회전, AF 접힌 의자의 oak 상단 반블록 지지 조건은 그대로 유지했다. 1.21.1의 세 가구군만 모두 z=40에 놓고 그룹별 X 오프셋 -64/0/+64로 분리했다. 다른 플랫폼은 보수적 수평 90도 카메라 시야 원뿔 밖이다.
이후 기존 Fabric 클라이언트/서버에서 새 평지 실험 월드를 만들고 F2 실제 사진 16장을 다시 촬영했다. 출처: https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/actions/runs/44899073690

| 연구 대상 | PR #33 배경 바닥 혼입 | PR #34 재촬영 후 |
|---|---:|---:|
| AF121 일반 의자 | 0/4 | 0/4 |
| AF123 접힌 의자 | 4/4 | 0/4 |
| HC11210 의자 | 4/4 | 0/4 |
| Minecraft 1.21.1 합계 | 8/12 | 0/12 |

파란 하늘에 섞인 회색 플랫폼 유사 화소의 이전 최댓값은 45,355픽셀, 재촬영 후 0픽셀이다. 대상 가구가 화면 중앙에 남아 있다는 색상 픽셀 검사도 12/12 통과(최소 1,664픽셀).
Minecraft 1.21.11 Macaw 4/4도 실제 사진 및 서버 상태 검증을 통과했다. 이 버전의 하늘에는 구름이 있으므로 1.21.1용 회색 하늘 임계값을 적용하지 않았고, 가구 전경의 최소 색상 근거는 688픽셀이었다.

## 검증 코드와 범위
- src/mcfr/chair_runtime_fixture.py : 실제 테스트 월드만 일렬로 재배치, 동적 forceload
- src/mcfr/chair_capture_isolation_audit.py : F2 원본 SHA·배경 회색 화소·가구 전경 확인
- tests/knowledge/test_chair_capture_isolation.py : 원본 16상태, 카메라 시야 분리, 격자 검증
- .github/workflows/integration-int3-runtime-chairs.yml : 실제 게임 재촬영과 화소 검사 자동화
- INT3_ISOLATED_F2_FINAL_SUMMARY.json : 고정 촬영 결과 SHA/상태 인계

## 부품 45개와 기존 지식 DB의 경계
1-3-C/F 원장 부품 후보는 AF1393 10개, AF1394 10개, HC13 13개, MACAW1424 12개, 총 45개다. 이 후보는 16개의 전경이 분리된 게임 사진과 모델 키로 연결할 수 있지만, 개별 요소에 대한 실제 baked mesh 또는 픽셀 영역 확인은 아직 아니다. 후보 45건 모두 시각 승인 0이고, 기존 59건 의미 검수 대기열은 유지한다.
특히 AF 실행 릴리스 4.0.2와 연구 원본 4.0.3 사이에는 블록상태 원본 SHA 차이가 있다. 8개 선택 상태의 모델 이름과 방향 일치만 검증했으므로, 부모 모델 JSON/기하가 실제 런타임과 완전히 일치한다고 단정하지 않는다.
실제 Minecraft UV lock·AO/조명 효과, 개별 의자 부품 의미, 재료·기능·스타일, 제삼자 원본을 AI 학습에 사용하기 위한 권리는 별도 검증 전까지 보류한다.
