## 2. 새로운 **실제** 양쪽 카메라 촬영

동일한 의자 블록의 상태와 위치를 고정하고 **카메라만 반대편으로 이동**했다. 각 카메라에서 모델1 → 모델3 → 모델1 복원 → 공기(AIR) 네이티브 F2를 4장씩 촬영했다.

| 원본 관측 | 남쪽 카메라 (+Z, 등받이 뒤쪽) | 북쪽 카메라 (-Z, 의자 좌석 앞쪽) |
|---|---|---|
| spectator camera | `-87.5 122.3 45.5 180 20` | `-87.5 122.3 35.5 0 20` |
| 등받이 원본 법선의 카메라 쪽 후보 | **south** | **north** |
| model1 → model3 F2 RGB 변경 픽셀 | **808** | **692** |
| model1 → 복원 model1 시간 대조 | **0** | **0** |
| model1 → AIR 의자 전경 차이 픽셀 | **3,552** | **4,216** |
| model3 → AIR 의자 전경 차이 픽셀 | **3,432** | **4,144** |
| 변경 픽셀 중 의자 전경 밖 | **0** | **0** |
| 모델1↔모델3 화면 변화 경계 | x493..530, y433..461 | x494..529, y409..435 |
| 실제 원본 F2 / exact game server state | 4장 / 4개 | 4장 / 4개 |

- 위 화면 RGB 차이 판정은 1024×684 **원본 마인크래프트 F2**의 ROI x350..674, y275..619, 채널 차이 24 이상이라는 기존 H12 기준을 동일하게 사용했다.
- 기존 H12와 이번 H15 **남쪽 4장 각각의 PNG SHA256이 모두 바이트 단위로 정확하게 일치**했다. 이는 동일 환경에서 해당 화면 조합이 재현되었음을 입증한다.
- 새로 확보한 **북쪽 카메라 4장**은 남쪽과 다른 방향의 원본 화면이다. 원본을 직접 열어보니 전면 좌석과 등받이 안쪽이 드러나고, 두 모델의 등받이 가로색·띠 구성이 달라졌다. 양쪽 모두 모델1 복원 화면은 첫 모델1과 동일하고 AIR에서는 의자가 사라졌다.
- 실제 게임 실행은 **이번 H15에서 새로 1회**, 네이티브 F2 **8장**이다. H12·H14 이전 화면을 신규 촬영으로 중복 계산하지 않았다.

## 4. 연구 결과의 정확한 범위

**확인 완료**

- 배포 게임 원본에서 같은 north-facing 의자 블록을 같은 좌표에 두고 카메라만 남북으로 이동했을 때 **양쪽 모두 실제 가구 등받이의 모델1↔모델3 외관 차이가 재현**된다.
- 남쪽 화면 808픽셀 / 북쪽 화면 692픽셀 변화, 양쪽 A-B-A 시간 대조 0픽셀, 공기 전경 바깥 변화 0픽셀.
- 원본 모델에서 카메라 방향상 남쪽/south, 북쪽/north 면 후보가 각각 대응한다. 선행 H11의 텍셀 겹침 2면·원본 PNG 54변경 텍셀과 교차 증거가 추가됐다.

**아직 승인하지 않음**

- 실제 게임 GPU가 특정 화면 픽셀마다 **어떤 면의 어떤 UV 위치·어떤 원본 텍셀을 샘플링했는지** 직접 추적한 것은 아니다. CPU 기하학적 법선 후보와 두 방향 화면의 차이를 GPU 픽셀 인과로 과잉 주장하지 않는다.
- 광원·깊이·렌더 컬링/투명도·샘플링 내부, 모든 의자 방향/모드/버전 일반화, 모드 개발자의 의도는 검증 범위 밖이다.
- 기존 **F70 조건부 70/70, 무조건 최종 승인 0/70**. H03 **HOLD**, H05 **CONDITIONAL**, H 전체 무조건 종료 0. INT5 가구 의미 승인 **0**, INT6 자산 학습·재배포권 승인 **0**. 이 H15 국소적 모델링 증거만으로 전체 승인 상태를 올리지 않는다.
