# INT-4 점유 상태 침대의 UV 실측 범위 확대

PR #48의 Handcrafted 4.0.3 북향 흰색 오크 침대를 Minecraft 1.21.1에서 다시 재현했다. 수면하는 플레이어와 독립 관전자, 원본 JAR, 고정 야간과 조명 조건을 유지했다. 관전자만 원본 텍스처와 색 표식을 넣은 텍스처로 나눠 촬영했다.

| 영역 | 점유 S37 부모 요소¹ | 면 | 원본 UV | 면 회전 | 관전자 시점 |
|---|---:|---|---|---:|---|
| 발판 윗면 · 재현 | 5 | `up` | `[6.125, 7.875, 4.125, 7.5]` | 180° | 정수직 |
| 발판 바깥면 | 5 | `south` | `[4.125, 7.875, 6.125, 8.125]` | 0° | 남쪽 정면 |
| 머리판 윗면 | 6 | `up` | `[9.25, 2.75, 7.25, 2.375]` | 180° | 정수직 |
| 이불 옆면 | 11 | `east` | `[10.625, 2, 12.625, 2.375]` | 0° | 동쪽 정면 |

¹ 요소 인덱스는 0부터 센다. 머리판 윗면은 S37 발 블록이 제공하는 연장 기하다. S38 머리 블록의 쿠션은 다른 원본 부모가 제공한다.

네 면마다 플레이어에 가리지 않는 표식 지점 4개를 골랐다. 표식 하나는 텍셀 2개이며 전체 32텍셀을 관전자용 리소스 팩에서만 덮었다. 오크 프레임과 흰 이불 원본 PNG는 Git 원본과 런타임 JAR가 바이트 단위로 일치했다. 진단 팩의 우선 적용, 원본·진단 PNG와 서버 로그 SHA, 각 추가 시점의 `occupied=true`를 검사했다. 정수직 화면에 보이는 10블록 바닥 폭으로 유효 초점거리를 구한 뒤, 각 면의 높이·깊이와 원본 UV 방향으로 화면 좌표를 계산했다.

이 결과의 분모는 점유 상태의 두 원본 부모가 선언한 **S37의 84면과 S38의 6면**이다. 중첩 및 가림을 제거한 화면의 가시 면 개수는 계산하지 않았다. 이 회차의 실측 판정은 선택한 4개 면의 16개 표본 지점에 한정한다. 점유 모델에 남은 86개 선언 면의 화면 대응과 INT-5 의자 부품 45개의 역할 판정은 미검증이다.

[결과 JSON](INT4_BED_UV_FACES_RESULT.json)에서 카메라별 상태 로그, 모델·텍스처 출처, 표식 텍셀 위치, 계산한 화면 좌표, 실제 RGB, PNG SHA를 확인할 수 있다.
