- **INT-4: 교차 검증 일부 진행**. 이번 범위는 의자 4종의 원본·상태·F2 이미지 증거 연결이며, 1-1~1-5 전수 사례의 전체 모순 조사 종료가 아니다.
- **INT-5: 45개 개별 역할의 실제 시각 판정 대기**. F2 사진 SHA만으로 좌판/다리 등 역할을 승인하지 않는다.
- INT-6: AI 제작용 데이터 활용/학습 승인 0.
- INT-7: 독립 최종 감사 아직 실시하지 않음.
