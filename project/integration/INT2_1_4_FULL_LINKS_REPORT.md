# INT-2 / 1-4 전 모델 면→텍스처→UV 원본 연결 독립 재검수

검수일: **2026-11-21**. 결과: **PASS_ALL_592312_FACE_LINKS_RECONSTRUCTED_FROM_ORIGINALS**.

## 목표와 검수 방법

기존 1-4 PNG·UV 원장의 가장 큰 남은 검수 항목이었던 **모델별 592,312개 원본 면이 어느 텍스처 슬롯, 원본 PNG 및 UV 좌표에 연결되는지**를 원본에서 직접 다시 계산했다. 기존 1-4·1-3 분석기의 계보/슬롯/face 분석 기능은 호출하지 않았다.

새 감사기 \`scripts/integration/audit_int2_full_face_links.py\`는 고정 upstream 원본 모델·부모 JSON을 재해석한다.

1. 고정 Git/JAR에서 3개 모드의 모델 JSON **16,572개**와 공식 바닐라 부모 보조 모델 **7개**를 실제 다시 연다. 원문 SHA를 원본 신원 원장과 대조한다.
2. 해당 모델의 \`parent\`를 원본에서 다시 따라가고, 기하 제공자 \`elements\`와 텍스처 맵을 부모→자식 순서로 합성한다.
3. **매 면**의 원본 \`texture\` 슬롯 별칭·미결합·순환을 평가하고, 버전별 자원 ID를 정규화한다. 부모에서 받은 \`face\`의 로컬 방향·UV 선언·UV 회전·cullface·tintindex를 보존한다.
4. \`uv\`가 없는 면은 Java 1.21.1 공식 원본 바이트코드에서 이전에 검증한 기본 UV 공식을 **독립적인 신규 함수**로 재계산한다. 두 UV 축의 반전과 원본 PNG 프레임의 축별 픽셀 밀도를 계산한다.
5. 이미 독립 재디코딩을 완료한 1-4 Entry02의 버전별 PNG 프레임 메타데이터를 사용해 면 상태를 분류한다.
6. **그다음에만** 역사 1-3-F의 \`geometry\`, \`lineage\`, \`face\`, \`element\`, \`model_slot\`, \`effective_face_texture\`와 면별 비교한다. F의 \`model\`, \`texture\` 테이블은 고정 버전별 자원 신원/ID 등록부로만 사용한다. 기존 연결 결과로 신규 연결을 생성하지 않는다.

## 독립 재계산한 면의 분류

| 판정 범위 | 면 수 |
|---|---:|
| 일반 PNG 원본의 정적 화소 사각형 | 506,614 |
| PNG 애니메이션 프레임의 사각형 | 5,095 |
| UV가 0면적·선·점인 면 | 69,118 |
| UV가 원본 텍스처 0~16 범위를 벗어나는 면 | 5,144 |
| 텍스처 슬롯 미결합 | 6,202 |
| 고정 원본 PNG 경로 누락 | 139 |

두 PNG disposition의 원본 면 상태가 기존 1-4 Entry02 원장과 정확히 일치했다.

- 새 PNG 후보: 정적 459,594 / 애니메이션 5,095 / UV 면적 0인 면 63,814 / 범위 밖 UV 5,144.
- 기존 PNG 근거: 정적 47,020 / UV 면적 0인 면 5,304.
- 소스의 영면적/경계/클리핑 UV는 기존 원본 화소 샘플링 방식대로 별도 증거를 해석해야 한다. 이 행들을 일반 사각형의 유효 PNG 영역이라고 표시하지 않는다.
- 슬롯 미결합 6,202·PNG 누락 139는 **그대로 보존한 예외**이며, 이 검수에서 자동 수리하거나 런타임 게임 오류라고 단정하지 않았다.

## 기존 1-3·1-4·1-5과 연계할 수 있는 신뢰 수준

- **1-3**: 원본 geometry 제공자·상속·유효 face 수가 모델 전체에서 재현된다.
- **1-4**: 원본 PNG 2,001개 및 원본 UV 영역(일반·애니메이션 29,957행, 보충 1,306행) 화소는 이전 독립 재측정에서 통과했다. 이제 그 UV 영역에 연결되는 **원본 모델별 면 전체 592,312개**의 관계도 독립 재계산했다.
- **1-5**: 표본 62개 비교 사례·21개 판정은 이전 독립 재계산에서 일치했다. 14개 후보/7개 반례·제한 인계를 유지한다.
- 따라서 INT-3에서는 정적 구조·원본 PNG·UV·비교 반례의 연결을 **지식 DB에 입력할 수 있는 출처 검증 자료**로 사용할 수 있다. 다만 유효조건과 원본 라이선스/학습 사용 권리는 반드시 함께 기록해야 한다.

## 여전히 미승인·추가 검증 대상

1. Minecraft 게임 엔진의 실제 모델 베이크·GPU 아틀라스·\`uvlock\`·tint·투명 면 가림·셰이더·애니메이션 프레임 순서의 **최종 화면**은 이번 신규 실행에서 관측하지 않았다.
2. 69,118개 영면적 UV와 5,144개 범위 밖 UV는 오류라고 획일 분류하지 않는다. 이미 검증된 C의 점·선·경계·클리핑 원본 화소 결과와 함께 해석한다.
3. 원본 모드 업데이트에 의한 새로운 모델은 이번 고정 버전 검수의 대상이 아니다.
4. **AI 가구 제작용 학습 자료로 무조건 공개·재배포하거나 모델 가중치 훈련에 사용하도록 승인하지 않았다.** 원본 에셋별 저작권·학습 허용 범위는 따로 판정해야 한다.
5. 'AI가 새 가구를 실제 생성해 게임에서 동작시킨다'는 **생성·실행 평가**는 아직 미착수. 이것은 연구 데이터 재감사이며 AI 제작 완성 선언이 아니다.

**후속 순서:** INT-3의 증거 통합 DB 설계와 실제 추출, 출처/라이선스·버전·예외·적용조건까지 데이터 행에 붙이고, 작은 새 가구 생성 PoC의 성공/실패를 별도 측정한다.
