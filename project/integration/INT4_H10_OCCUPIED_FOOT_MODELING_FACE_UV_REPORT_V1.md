# INT-4-H10 — Handcrafted 침대 foot 점유 전후 상세 요소·면 UV 연구

## 검증 범위

이 문서는 `terrarium-earth/Handcrafted@8d21d1665916850c3fa3bdaf1370c50ec2ca7035`에 있는 두 **원본 모델 JSON**의 직접 구조 비교를 기록한다. 부모 파일은 `bed_single.json`(Git blob `01dcc76679443d37f3efa45d974e2acbc071cfc1`)과 `bed_single_occupied.json`(Git blob `296e103447bfaaa6dd5d3a20d39169c1612474bc`)이다. 원본 PNG/JAR 또는 모델 내용을 Git에 복사하지 않는다.

두 모델은 공통 요소 11개를 유지한다. 비점유 모델은 12요소·72면, 점유 모델은 14요소·84면이다. 원본 요소 레코드 단위로 **1개 제거, 3개 추가**되므로, 단순히 2개 요소만 더해지는 구조로 오인하면 안 된다.

## 변경된 요소의 좌표·회전

| 원본 요소 변화 | from | to | 회전축 / 각도 | 원본 면 수 |
|---|---|---|---|---:|
| 제거 | `[0,3,-10]` | `[16,9,-3]` | Y / 0° | 6 |
| 추가 A | `[0,7.25,-4]` | `[16,13.25,3]` | X / 22.5° | 6 |
| 추가 B | `[0,4.25,-4]` | `[16,7.25,3]` | X / 22.5° | 6 |
| 추가 C | `[1,8,-3]` | `[15,11,13]` | Y / 0° | 6 |

두 회전 요소의 origin은 `[8,11.5,-1.5]`이며, 제거된 요소와 추가 C의 origin은 `[8,1.75,6]`이다. 좌표 범위가 블록 영역 밖으로 나오는 요소가 있으므로, 단독 블록을 기준으로 촬영할 때 이웃 영역의 시각적 영향을 가구 구조로 잘못 분류하지 않도록 주의한다.

## 면 UV와 텍스처 슬롯

변경 요소는 모두 원본에서 6면을 선언하고 있고, 면 레코드 총 **24개(제거6·추가18)**를 비교 대상으로 기록한다. 변경 요소의 면 슬롯은 모두 `#1`이다. 예를 들어 제거 요소와 추가 A의 `north` UV는 `[10.625,4.625,12.625,5.375]`로 동일하지만, 추가 B의 `north` UV는 `[10.625,6.25,12.625,6.625]`로 다르다. 따라서 '모델 요소가 바뀐다'와 '모든 면 UV가 바뀐다'는 다른 명제다.

`src/mcfr/int4_h10_hc_bed_occupied_f2_capture.py`는 동일 카메라에서 `occupied=false/true/air`를 네이티브 F2로 비교하도록 구성되어 있다. F2 검증을 통과해도 **어느 화면 픽셀이 어느 모델 면의 UV에 대응하는지**를 자동으로 승인하지 않는다.

## 모델링 범위 및 연구 판정

- **확인 완료:** 원본 Git 모델 JSON에서 발 부분의 점유상태별 실제 요소·면 구조와 면별 UV 출처에 변화가 있음.
- **별도 실게임 판정 필요:** 점유 true 상태가 Fabric 게임 서버에서 유지되며 F2에서 재현되는지, 같은 시점의 외형 차이가 원본 모델 선택과 대응하는지.
- **검증 대상 제외:** 플레이어 수면·기상·파괴 전체 기능의 성공 여부. 이 작업은 3D 가구 모델·UV 연구가 목적이므로 게임플레이 기능 테스트를 수행할 이유가 없음.
- **현재 승인 경계:** F70의 무조건 최종 승인·H03/H05 최종 종료·INT5 의미·INT6 AI 학습/원본 재배포 권한은 이 정적 모델 비교로 변경하지 않음.

독립 재생성 산출은 `INT4_H10_OCCUPIED_SINGLE_FOOT_FOUR_ELEMENT_CHANGES_V1.csv`, `INT4_H10_OCCUPIED_SINGLE_FOOT_24_SOURCE_FACE_UV_V1.csv`, `INT4_H10_OCCUPIED_SINGLE_FOOT_FACE_UV_SOURCE_AUDIT_V1.json`로 구분하며, 해당 파일은 GitHub Actions의 SHA·행수 검증이 끝나야 공식 검수 통과로 표시한다.
