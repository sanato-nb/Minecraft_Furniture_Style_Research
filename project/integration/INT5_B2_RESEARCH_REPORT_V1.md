## 1. 실제 원본 파일·증거 검증

- **F2 16장:** Minecraft Java 1.21.1 **12장**(AF 기본/넣은/HC 3모델 × 4방향), 1.21.11 **4장**(Macaw 1모델 × 4방향). 실제 F2 파일을 **SHA-256·PNG CRC·압축 IDAT 스트림·해상도 1024×684·원본 캡처 JSON·서버 블록상태·선택모델·회전 Y**와 독립 대조. 원본 `client.log` **2개** 해시도 캡처 기록과 대조.
- **소스 UV 229면:** 원본 `INT3_229_ORIGINAL_FACE_UV_TEXTURE_EVIDENCE.csv`를 직접 재개봉·SHA256 확인하고 **원본 provider 키+element_index 45개**에 연결. 각 부품별 **원본 PNG 경로·해시·면 방향·UV·UV 회전**을 저장. 모델별 46+46+78+59=**229면**.
- **원본 PNG 8종:** 고유 source texture 경로 8개. Git blob SHA-1 **40자리 170면**, 바닐라 원본 PNG SHA-256 **64자리 59면**이 섞여 있으므로 해시 알고리즘을 분리해 보존. 이번 검증이 PNG 8개 원본을 새로 각각 재배포하거나 모두 새로 디코드한 것이 아니다. 원본 PNG를 조합한 **기존 UV 진단 접촉시트는 직접 개봉·해시 검증 및 시각 확인**했다.
- **실행 버전 한계:** Another Furniture 연구 Git 4.0.3 ↔ Fabric 4.0.2 blockstate 바이트 차이 유지. Handcrafted·Macaw 특정 블록상태 SHA 일치와 모든 부모 모델/런타임 베이크 동등성은 다른 주장이다.

## 5. 다음 연구 범위

1. 먼저 **AF123 tucked 의자의 가림**을 원본 선택 상태·테이블 위치와 구분할 수 있는 단독 실게임 장면/기존 독립 F2로 비교.

3. 실제 픽셀 대응이 확보된 **정확한 개별 요소/모델/버전**에만 제한적 의미 검증 결과를 새 행으로 추가. 원본 PNG/스크린샷을 무단으로 AI 학습·재배포 승인하지 않음.
