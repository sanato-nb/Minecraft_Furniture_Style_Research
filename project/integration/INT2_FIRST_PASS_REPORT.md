## 1-2 · 고정 원본과 보조 메타데이터

| 유형 | 재해시·검사 통과 |
|---|---:|
| BLOCK_MODEL_JSON | 2,390/2,390 |
| BLOCKSTATE_JSON | 1,168/1,168 |
| BLOCK_TEXTURE_PNG | 1,111/1,111 |
| **원본 소계** | **4,669/4,669** |
| 별도 PNG .mcmeta | **99/99** |
| **합계** | **4,768/4,768** |

JSON 3,558개는 직접 파싱했고, PNG 1,111개는 PNG CRC 및 Pillow decode까지 수행했다. 메타데이터 99개도 SHA·크기·JSON과 애니메이션 선언 여부를 검사했다(애니메이션 선언 54개, 비선언 45개). 모델 중 선언 parent를 가진 경로는 2,078개였다.

1-2-G의 역사적 F 출처 공백인 `sculk_mirrored`와 `stone_mirrored`의 총 4필드는 원본에서 다시 해시한 `cube_mirrored`의 SHA-1 `38f44bda128d10a5e09614e5ac155c956237681e` 및 **간접 부모 계보**(`cube_mirrored_all`을 경유)를 따라 대조해 일치했다. 기존 F의 빈 SHA 기록은 사후 변경하거나 원래 확인했던 것으로 소급 주장하지 않는다.

**이번에 재검수하지 않은 것:** 모델 2,390개 전체의 상속 후 형상·UV 기하 계산, 블록 상태 조합 의미·렌더 결과, 공식 배포 JAR 독립 인증, 실제 인게임 배치.

## 실행 이력 및 한계

처음 두 실행에서는 *새 감사기 자체*의 PNG 상수 이스케이프 오류 및 간접 부모 계보 1단계 오해가 자동 검사에 잡혔다. 둘 다 도구를 수정했고 성공 실행에서 전체 원본을 재검사했다. 이 초기 실패를 원본 이미지·기존 연구 오류로 오인하지 않는다.

- 재현: `python scripts/integration/audit_int2_vanilla.py --root . --out /tmp/int2-results`
- 회귀 테스트: `python -m unittest discover -s tests/integration -p 'test_*.py' -v`
- 원본 실행 CSV·JSON은 GitHub 저장본과 CI에서 재비교한다.
- 고정 150종의 검증 완료와 모든 바닐라 블록 텍스처·모든 모델링 기술의 연구 완료를 혼동하지 않는다.
- AI 학습용 승인은 여전히 보류한다(시각/의미 검증, 법적 활용 범위, 모델 생성 정확도 검증 필요).
