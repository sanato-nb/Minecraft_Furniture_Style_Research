# INT-5-B4 — Another Furniture 접힌 의자 상단 반블록 가림 인과 실게임 대조

작성일: 2026-11-25 (KST) · 직계 [INT-5-B3 PR #115](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/pull/115) head `51f1fa18d218bb076af93eaa457c65f5927de272`. 후속 [Draft PR #116](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/pull/116). 기존 GitHub 원본 및 `main`은 변경하지 않는다.

## 1. 정확한 핵심 문제

기존 B2/B3의 AF123(`acacia_10_tucked`) 화면에는 의자 앞쪽의 밝은 참나무 상단 반블록이 **좌면 일부를 가리는 현상**이 확인됐다. 이것은 단순한 배경 오브젝트가 아니다. `src/mcfr/chair_runtime_fixture.py` 원본 fixture에 명시된 것처럼 Another Furniture의 `tucked=true`는 **앞쪽 상단 반블록 같은 허용 지지 구조**가 필요하며, 이 블록 제거는 의자 상태를 `tucked=false`로 재설정할 수 있다. 따라서 '슬랩 제거 + 원래 `tucked=true`는 그대로'라고 가정하는 실험은 잘못이다.

이번에는 슬랩을 고정하고 의자만 제거/복원한 **같은 월드·같은 카메라·같은 게임 실행**의 실제 F2 대조와 반대 관찰 방향을 사용했다.

## 2. 실제 재현 환경과 8장 원본 네이티브 F2

- 공식 Java Minecraft **1.21.1**, Another Furniture **Fabric 4.0.2** 실 JAR 선택 모델을 재검증한 사례 `AF123_north`.
- 원본 의자 상태: `another_furniture:acacia_chair[facing=north,tucked=true,variant=10]`; 리소스 `another_furniture:block/chair/acacia_10_tucked`; Y 회전 **0°**.
- 테스트 의자 (-24,120,40), 상단 지지 반블록 (-24,120,39)의 `minecraft:oak_slab[type=top]`. 원본 fixture가 **슬랩 먼저, 의자 다음** 순서로 배치하며 게임 서버의 실제 16개 정확 상태(8사진×chair와 slab 확인)를 검사했다.
- **남쪽 카메라**(-23.5,122.3,45.5, yaw 180, pitch 20)와 **북쪽 카메라**(-23.5,122.3,34.5, yaw 0, pitch 20).
- 두 카메라에서 동일 순서: **A** 의자+반블록, **B** 반블록만(의자=air), **A 복원** 원래 법적 `tucked=true` 의자+반블록, **AIR** 의자와 슬랩 둘 다 없음. 실제 F2 **4×2=8장**, 한 게임 실행에서 획득.
- 원본 사진 **1024×684 PNG 8장**, 각각의 SHA256, 서버 콘솔의 chair/slab 검사 마커, `client.log` 원본 SHA256 독립 확인. 원본 ZIP GitHub Actions 아티팩트 **#14982648778**에 원형대로 보존, 새 GitHub 소스 커밋에 실게임 원본 PNG/모드 JAR를 복사하지 않음.

## 3. 직접 원본 사진 재개봉 및 실제 관찰

실제 성공 [Actions #45528207751](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/actions/runs/45528207751)을 수행한 후, 아티팩트 ZIP을 별도로 다운로드하고 ZIP CRC 및 8장의 원본 네이티브 F2를 실제 열어 보았다. **남쪽 관찰**에는 지지 슬랩 아래의 주황색 나무 의자 프레임과 다리/하부 구조가 넓게 드러난다. **북쪽 관찰**에서는 앞쪽 밝은 참나무 슬랩이 좌면 부근을 가리지만 의자 일부는 위/아래로 보인다. 반블록만 남긴 사진은 주황색 의자 조립체가 사라지고 원래의 슬랩만 보인다. AIR 사진에는 해당 두 물체가 모두 사라진다. 복원 후에는 같은 의자 형태가 되돌아온다.

이것은 **'상단 슬랩 존재가 실제 의자 표시 면적을 관찰 방향에 따라 제한한다'는 범위 한정 시각 결론**을 뒷받침한다. 다만 북·남의 카메라/투영이 서로 다르므로 화면 변화 픽셀 수의 비율을 곧바로 실제 좌판 **물리적 가림 비율**이나 부품별 픽셀 인과 비율로 바꾸지 않는다.

### RGB 화소 대조

비교 영역 `x=[350,675), y=[275,620)`, 채널별 색상 차이 임계값 **24**. 동일 카메라의 원본 PNG를 비교했으며 B와 AIR도 같은 방향/위치이다.

| 동일 카메라 단계 대조 | 남쪽 카메라 | 북쪽 카메라 | 근거 |
|---|---:|---:|---|
| **A↔B** 의자+슬랩 vs 슬랩만 | **2,656px** | **386px** | **슬랩 고정** 시 바뀌는, 화면에 노출된 의자 전경 영역 |
| **B↔AIR** 슬랩만 vs 둘 다 없음 | **3,890px** | **5,716px** | 의자 없는 상태에서 지지 반블록의 화소 영향 |
| **A↔AIR** 의자+슬랩 vs 빈 공간 | **5,738px** | **6,102px** | 합성된 두 물체의 화면 영역 |
| **A↔A 복원** 안정성 대조 | **0px** | **0px** | 정해진 ROI에서 시간 변화에 따른 차이 없음 |
| A↔B 차이 중 시간변화 제외 | **2,656px** | **386px** | 안정성 대조에서 설명되지 않는 의자 전경 |

**북측의 가시적인 의자 전경이 남측보다 작다**는 점이 실험으로 재현됐다. 다만 이 실험은 앞쪽 슬랩 뒤에 실제로 숨은 **좌판 element 4의 고유 픽셀이나 면**을 관찰한 것은 아니므로, 이전 B3에서 좌판이 가려져 있다는 상태는 **원인 분리 근거가 개선된 조건부**로 유지한다.

- **B4 적법한 접힌 의자의 화면 가림/표시 분리 실험**은 **2시점·실제 8장 원본 F2·서버 16개 상태·화소 대조 통과**로 범위 한정 완료.
- B3에서 확인한 원본 역할 지시 텍스처 **9/45**, 화면 그룹과 양립 8/45, AF tucked 좌면 가림 1, 공용 텍스처 35건은 그대로 유지하되, 이번 B4 실험의 슬랩 고정 픽셀 대조 결과를 가림 현상의 추가 근거로 연결한다.
- **개별 원본 JSON element 4→실제 F2 픽셀**, 좌판의 물리적 기능·착석, 전체 부품 45개의 기능/재질/스타일 최종 승인 **0/45**. 추후 동일 상태에서 개별 요소의 표시 픽셀을 분리하려면 실험용 **일시적인 단일 요소 자산/텍셀 변경**, 모델 원본·좌표·상태 변화 엄격 통제, 정확 소스 SHA/비교 PNG를 이용한 재검증이 필요하다.
