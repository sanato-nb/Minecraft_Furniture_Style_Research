# INT-3 / 45개 의자 부품 후보의 원본 기하 조립 시각 검토

**검토일: 2026-11-21. 실측 결론: 기하 조립상 후보 역할 45개가 그룹별로 타당하게 보이나, 실제 게임/텍스처/기능 검증 승인은 0개.**

## 검증의 독립성과 제한

이전 INT-3가 1-3-C의 부품 후보 45개를 정규화 DB에 저장했다. 이번에는 고정된 원본 모드 JSON을 GitHub Actions에서 다시 열고, 원본의 모델 좌표와 각 요소의 회전 피벗·각도·축·면을 검사한 뒤 **새로운 등각 기하 접촉시트 PNG**를 실제 생성했다.

- Another Furniture: 고정 Git 소스에서 두 원본 의자 템플릿을 다시 읽었다.
- Handcrafted: 고정 Git 소스에서 원본 의자 모델을 다시 읽었다.
- Macaw's Furniture: 공식 고정 SHA-256 JAR에서 원본 의자 모델을 다시 읽었다.
- 실제 원본 모델 **4개**, 기하 요소 **45개**와 원본 SHA를 다시 검산했다.
- 각 가구의 **+45도 / −135도** 양방향 등각 투영으로 좌판·하부 지지·등받이·프레임의 상대 위치를 검사했다.
- **검증 그림의 색상은 1-3-C가 이전에 제안한 역할 후보를 의도적으로 표시한 것**이다. 색상 일치 그 자체는 후보 역할의 독립 증거가 아니다. 형태·위치·접합 관계에서 *그룹별 타당성*을 본 것이며, 실제 원본 텍스처를 매핑하거나 Minecraft에서 구동하지 않았다.

## 실제 접촉시트의 육안 관찰

| 원본 모델 | 근거 있는 요소 수 | 시트에서 확인한 형태 배치 | 새 검토 결론 |
|---|---:|---|---|
| AF 기본 의자 | 10 | 네 모서리의 세로 지지 요소, 넓은 수평 좌판, 뒤쪽 세로/판형 등받이, 좌판 밑 가로 연결부 | **기하 배치상 타당** |
| AF 넣은(tucked) 의자 | 10 | 위 요소군의 비슷한 조립 구조를 유지하면서 Z 방향 배치가 달라짐 | **기하 배치상 타당** |
| HC 기본 의자 | 13 | 세로 지지 요소와 계층형 좌판, 뒤쪽 높은 등받이, 좌판 밑 가로 프레임이 결합 | **기하 배치상 타당** |
| Macaw 의자 원형 | 12 | 세로 다리 4개·좌판 층 2개·뒤쪽 가로 막대/세로 조립 요소가 의자 형태를 구성 | **기하 배치상 타당** |

**주의:** 양방향 그림에서 다른 부분과 겹치는 요소는 정확한 앞뒤/가림·텍스처 위치를 완전히 판정하기 어렵다. 이번 45개 행의 결과는 `GROUP_LEVEL_SHAPE_PLAUSIBLE`이며, **각 요소의 기능과 시각적 외관이 확정되었다는 `VISUAL_VERIFIED` 판정이 아니다**.

## 세분화한 45개 증거 행

기존 C의 각 요소 번호와 모델 SHA를 `INT3_45_CHAIR_GEOMETRY_REVIEW.csv`로 연결했다.

| C의 후보 역할 | 행 수 | 육안 검토 수준 |
|---|---:|---|
| LEG_OR_LOWER_POST — 다리/하부 지지 후보 | 16 | 모서리·세로 지지의 역할로 **형태상 타당** |
| SEAT_LAYER — 좌판 층 후보 | 6 | 수평 층/평면 구조로 **형태상 타당** |
| BACKREST_ASSEMBLY — 등받이 조립 후보 | 16 | 뒤쪽 세로 패널·막대 조합으로 **형태상 타당** |
| LOWER_FRAME — 하부 프레임 후보 | 7 | 좌판 하부 가로 연결 요소로 **형태상 타당** |
| **합계** | **45** | **원본 게임 시각/텍스처 검증 확정 0** |

CSV의 각 행에는 원본 모드·모델 리소스 ID·원본 모델 SHA·요소 번호·C의 후보 라벨·서술형 관찰·실제 접촉시트 SHA-256·검증 범위를 기록했다. 독립 감사기는 CSV와 고정 원본 F의 개별 요소를 다시 대조하고 **45개 후보가 기존 라벨에서 벗어나지 않았는지** 확인한다.

## 보존된 시각 증거

1. `scripts/integration/render_int3_chair_geometry.py` — pinned AF·HC Git 및 공식 Macaw JAR 모델 JSON에서 45개 요소/얼굴 면/피벗/회전을 직접 확인하는 기하 이미지 생성기.
2. `scripts/integration/audit_int3_geometry_review.py` — 사람이 검토한 근거 45행과 고정 원본, 실제 렌더 SHA를 교차 검사.
3. `project/integration/INT3_45_CHAIR_GEOMETRY_REVIEW.csv` — 형태 타당성에 한정한 45개 요소별 후보 검토 기록.
4. CI 아티팩트 `int3-45-original-chair-geometry-contact-sheet` — 고정 모델 4개를 양방향 렌더한 **INT3_45_CHAIR_GEOMETRY_CONTACT_SHEET.png** 및 생성/감사 JSON. 원본 PNG/JAR 및 모델 JSON 파일 본문은 포함하지 않았다.

## 연구 범위의 정직한 표시

- **완료:** 네 모델 45개 요소의 원본 신원·좌표·회전·면 개수 전수 교차검증, 기하 조립 접촉시트 생성, 두 각도에서 그룹 단위 기하 배치의 타당성 실제 육안 검토, 45행 기록 생성.
- **보류:** 모드 원본 PNG가 매핑된 텍스처 렌더링, 최종 Minecraft 블록 상태 회전/UV lock과 게임 내 가림·광원·충돌, 실제 의자 기능과 인체 사용 관계.
- **미승인:** 원본 재료/스타일 실제 판독, 45개 기능 역할의 *완전* 시각 승인, 14개의 1-5 후보 비교 규칙 일반화, 라이선스/모델 학습 승인.
- **다음 단계:** 텍스처가 직접 매핑된 합성 렌더(원본 라이선스 조건 고려), 실제 게임/스크린샷 참조, 기존 14개 비교 판정의 적용조건과 반례 시각 점검. 이미지가 없거나 판독이 애매한 항목은 계속 PENDING.

이 연구는 **가구 모델링을 이해하고 새로운 가구를 설계하기 위한 근거 분석**이며, 이미 검증된 치수·부품 역할을 규칙으로 자동 확대하지 않는다.
