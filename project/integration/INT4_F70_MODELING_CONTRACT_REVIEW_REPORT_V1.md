## 1. 별도 모델링 승인 계약

| 필수 판정축 | 역사 모델 62개 | 위험 질문 8개 |
|---|---|---|
| 원본과 버전 | 모델/선택 상태/부모 경로와 해시; 연구본/실행본 대응 | 질문에 해당하는 정확한 버전과 증거 범위 |
| 모델 형상 | 적용·요소·면 키 연결과 개수 일치; 특수 renderer는 실제 기하 추출 | 질문에 필요한 형상 변화만 |
| 텍스처·UV | 면별 원본 텍스처 해시, 좌표·DEFAULT/EXPLICIT, 정적/애니메이션/영면적 처리 | 질문에서 필요한 소스 면 또는 선택자 증거 |
| 블록 상태 | 정확한 선택자와 실제 상태/기존 캡처 근거 | 각 지정 단계, 상태 전후 또는 버전 비교 |
| 실제 외형 | 검증된 원본 native F2와 기존 직접 관찰 기록 연결 | 질문에 맞는 원본 실게임 상태·화면/시간/대조 기록 |
| 예외와 한계 | 미해결 렌더 기하·출처 충돌은 보류/조건부 | 제한된 질문을 통과해도 전체 모델·버전·동적 기능으로 일반화 금지 |

- 역사 모델 `PASS_MODELING_SCOPE`는 원본 형상·source UV 연구와 지정 상태의 실제 외형 기록을 연결한 **정확한 사례 범위만** 인정한다. 새 인게임 화면 육안 조사, 모든 텍스처의 실행 JAR 바이트 일치, 화면의 모든 면의 baked UV 또는 전체 GPU 샘플링을 주장하지 않는다.
- `CONDITIONAL_MODELING`: 소스/실행 릴리스 차이, 기존 캡처의 모델·부모 동일성 미확정. 원본 PNG와 로그가 확보되었다는 것만으로 이 차이를 해소하지 않는다.
- `HOLD_MODELING`: 필수 형상/UV 부재 또는 근거 충돌. V11은 공식 BED 등록 증거가 있지만 일반 JSON 0면이며 실제 특수 모델 기하와 UV 미확정.
- `PASS_RISK_QUESTION_SCOPE`: 특정 비교/전환/선택자 질문의 제한적 답이 기존 원본 증거로 확보된 것. 역사 모델 1개 승인과 동일 의미 아님.
- `CONDITIONAL_RISK_QUESTION`: 질문 자체의 해석에 필요한 인과 또는 출처가 미확정. R06은 실제 물 영역 시간차 변화까지 확인, 애니메이션 출처 인과가 미확정.
- 자연 설치·파괴·수면·충돌·물리 전체를 기본 모델링 계약에 강제하지 않음. 동일 출처를 갖는 경우 신규 F2 재촬영을 강제하지 않음. 실제 동적 메서드 계측과 GPU 픽셀 인과는 특정 모델링 질문에 필요할 때만 선별. 의미/기능/권리 판정과 혼동 금지.
