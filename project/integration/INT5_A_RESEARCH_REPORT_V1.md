작성일: 2026-11-25 KST · 직계 기준 [INT-4 모델링 범위 종료 Draft PR #111](https://github.com/sanato-nb/Minecraft_Furniture_Style_Research/pull/111) head `83e310f58f55eb8bae91c1820a83635c800a8177`.

## 1. 목표와 실제 수행 범위

INT-5의 목표는 **원본 데이터로 측정한 형상과 실제 화면에서 관찰한 외형·부품 역할을 구별하여 검증**하는 것이다. 이전 1-3-C/F가 정한 좌판·다리·등받이 등 이름은 원본 출처가 있는 **가설**이며, 확정 기능이 아니다. 이번 INT-5-A에서는 초기 후보의 정적 사실과 사용 금지 경계를 다시 계산했고, **새로운 원본 게임 F2 이미지의 직접 시각 판정은 수행하지 않았다**.

- 원본 `research/furniture_mods/phase_1-3/C/PARTS.csv.gz` **1,911개 요소**를 실제 재열람하고 `1-3-F/furniture_research.sqlite.xz`의 소스 좌표·모델 키·원본 SHA를 직접 읽음. 압축 원본의 SHA256을 선행 독립 감사 결과와 일치 확인.
- 원본 의자 제공자 모델 **4개**의 **45개 요소** 각각에서 **원본 from/to 좌표→치수·중심 재계산, 회전 후 AABB 재계산, 전체 모델 대비 중심 위치, 접촉/중첩하는 다른 요소의 AABB 수**를 계산. 요소별 회전과 source texture 슬롯 문자열·소스 모델 SHA 보존. 이는 렌더 화면상의 실제 접촉이나 기능 증거가 아닌 **기하 측정값**이다.
- 기존 47개 상태 표본의 **94개 역할 주장**을 원본 제공자·요소 키에 직접 연결. 그중 이번 45개 의자 원형 제공자·요소 키와 겹치는 표본 역할 기록은 **19행**으로 확인. **94개 표본 역할을 94개 고유 검증 부품으로 집계하지 않는다.**
- 기존 비교 판정 **21건**의 출처 독립 원장 두 개(`INT2_1_5_21_FINDING_CHECKS.csv`, `PHASE2_HANDOFF.csv`)의 정확 ID·사례·범주·조건·결론을 직접 비교. **후속 검토 후보 14개, 범용화 금지/반례 7개**를 분리.

| 모델 제공자 | 부품 후보 | 원본 부품 수 | 원본 요소 회전 및 AABB 정보 |

모든 대상 요소는 전체 조립체 안에서 **최소 하나 이상의 다른 요소 AABB와 접촉하거나 중첩하는 수치 관계**가 나타났다(AF 최소 2, HC 최소 2, Macaw 최소 1). 이는 실제 표면 접촉이나 지지 기능을 승인한 것이 아니며, 회전 후 **경계 상자** 기반 진단만 의미한다.

역사적 1-5 비교의 일반화 제한 7개는 **C01, C05, C09, C14, C15, C20, C21**이다. 제한·반례가 이미 존재하는 비교 결론을 범용 가구 제작 규칙으로 바꾸지 않는다.

## 3. 증거 등급과 남은 실측

1. **SOURCE_GEOMETRY_MEASURED_ROLE_HYPOTHESIS:** 원본 좌표·회전·모델·슬롯 데이터가 정확히 연결된 사실만 인정. 45개 모두 이 상태로 남김.
2. **SAMPLE_SPECIFIC_ROLE_CANDIDATE_ONLY:** 과거 표본 역할 주장은 원본 요소가 존재하고 출처가 맞는지까지 인정. 94개를 재승인한 기능 사실로 바꾸지 않음.
3. **REVIEW_SCOPED_CANDIDATE / RETAIN_NON_GENERALIZABLE_COUNTEREXAMPLE:** 21개 비교 판정 중 14개는 적용 조건과 실제 표현 비교 후 별도 판단, 7개는 영구 제한/반례로 보존.
4. **직접 시각 의미 검증:** 별도 INT-5-B가 실제 원본 텍스처·블록상태·네이티브 Minecraft F2 이미지의 표시 부위·가림과 정확 원본 제공자 요소를 결합해 **사례별로** 판단해야 함. 기존 두 각도 기하 SVG와 고정 F70 범위 통과만으로 부품 기능이 확정되는 것은 아님.
5. **권리 게이트:** 제삼자 PNG/JAR·모델을 AI 학습·배포 허가 자료로 자동 승격하지 않음(INT-6 별도 소관).

## 5. INT-5 진행 판정

**INT-5-A 원본 형상·의미 후보의 독립 데이터 감사 범위는 통과**. 그러나 **INT-5 시각적·의미적 최종 검증은 미완료**, 기능적으로 승인된 부품 **0/45**, 검증 대기 **45 역할 + 14 비교 조건**. 과거 표본 역할 94개는 별개 단위.

기존 INT-4 모델링 전용 70/70 종료는 유효. 구 엄격 H03 HOLD·H05 CONDITIONAL, INT-5 신규 의미 승인 0, INT-6 AI 학습/재배포 권리 승인 0, INT-7 최종 감사 미실행 상태 그대로 보존한다.
