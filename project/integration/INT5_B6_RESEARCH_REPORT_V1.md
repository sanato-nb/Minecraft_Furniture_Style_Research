## 3. AF123 index 4의 유일한 실제 인과 사례

- 소스 키: `AF123` / 연구 제공자 `AF1394` / 요소 인덱스 `4`, **6면**, 원래 역할 *가설* `SEAT_LAYER`.

- 공식 출시 JAR 원본 SHA-1 고정, 시험용 JAR에서 **단일 요소 4만 제거**, 10요소·46면 → 9요소·40면. 다른 비압축 리소스 멤버 변경 **0개**.
- 원본 B4 F2 8장/서버 상태 16쌍과 원본 로그 SHA가 B5의 참조 F2/로그 SHA에 정확히 일치한다.
- 실제 결과: **남쪽 화면 751픽셀 변화, 북쪽 0픽셀**. 의자 복원 반복·지지 슬랩만/빈 월드 대조에서 변경 **0픽셀**, 원래 의자 전경 외 변화 **0픽셀**.
- 판정: `PASS_SOURCE_ELEMENT_REMOVAL_CAUSES_REAL_SOUTH_F2_CHANGE` **범위 한정**. **원본 751픽셀 전체를 element 4가 독점한다는 판정이 아니며**, 차폐·AO·배경 노출 효과를 배제한 per-face GPU 픽셀 식별이나 착석 기능 증명도 아니다.

또한 기존 연구용 Git **4.0.3**과 실제 출시 Fabric **4.0.2**의 JSON/블록상태 동등성은 주장하지 않는다. 해당 실행판 원본을 직접 확인한 B5 테스트와 과거 B3 정적 모델을 출처별로 구별했다.
