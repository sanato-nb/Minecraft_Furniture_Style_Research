# Research Inbox — 요청 자료 수신함

**주의: 이 GitHub 저장소는 공개 저장소다. 파일을 커밋한 뒤 삭제하더라도 과거 Git 이력에 남을 수 있다.**

## 사용 절차
1. GPT가 자료 요청 ID (`REQ-YYYYMMDD-XXXX`), 대상 하네스, 파일 용도, 필요한 파일을 안내한다.
2. 저작권·재배포 권한·개인정보를 먼저 확인하고, **공개해도 되는 파일에 한해** `inbox/REQ-.../`에 업로드한다.
3. GPT/프로그램은 해시·내용·분석 증거를 대조한다. 원본 미확보는 미확보로 기록한다.
4. 계속 필요한 자료는 적합한 `registry/`, `research/campaigns/` 경로에 근거로 등록하거나 출처 링크만 남긴다.
5. 요청 자료의 보존 여부를 판단한 뒤 정리 기록을 남긴다. 자동 삭제는 사용하지 않는다.

재배포가 허용되지 않는 JAR·모드 텍스처·개인 로그는 공개 inbox에 올리지 않는다. 별도 접근 통제된 보관소/로컬에서 사용하고 해시·외부 출처·검증 결과만 저장한다.
요청 예시는 `inbox/REQUEST_TEMPLATE.json` 참고. 템플릿 자체는 작업 요청이 아니다.
